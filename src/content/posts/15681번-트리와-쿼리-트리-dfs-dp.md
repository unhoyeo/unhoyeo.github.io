<https://www.acmicpc.net/problem/15681>

간선에 가중치와 방향성이 없는 임의의 루트 있는 트리가 주어졌을 때, 아래의 쿼리에 답해보도록 하자.

- 정점 U를 루트로 하는 서브트리에 속한 정점의 수를 출력한다.

만약 이 문제를 해결하는 데에 어려움이 있다면, 하단의 힌트에 첨부한 문서를 참고하자.

```java
9 5 3
1 3
4 3
5 4
5 6
6 7
2 3
9 6
6 8
5
4
8
```

트리의 정점의 수 N과 루트의 번호 R, 쿼리의 수 Q가 주어진다. (2 ≤ N ≤ 10^5, 1 ≤ R ≤ N, 1 ≤ Q ≤ 10^5)

이어 N-1줄에 걸쳐, U V의 형태로 트리에 속한 간선의 정보가 주어진다. (1 ≤ U, V ≤ N, U ≠ V)

이는 U와 V를 양 끝점으로 하는 간선이 트리에 속함을 의미한다.

이어 Q줄에 걸쳐, 문제에 설명한 U가 하나씩 주어진다. (1 ≤ U ≤ N)

입력으로 주어지는 트리는 항상 올바른 트리임이 보장된다.

```java
9
4
1
```

Q줄에 걸쳐 각 쿼리의 답을 정수 하나로 출력한다.

---

## 아이디어

- dp[v] = 노드 v를 루트로 하는 서브트리에 속한 노드 수
- DFS로 각 노드의 **서브트리 크기**를 미리 계산
  - 일단 자기 자신을 포함 (dp[v] = 1)
  - 자식들의 서브트리 크기를 재귀적으로 더함
- 쿼리에서는 이미 계산된 dp[u]를 바로 출력

---

## ⏱️ 시간 복잡도

- DFS: **O(N)**
- 쿼리 처리: **O(1)** → Q번 수행: **O(Q)**
- 전체: **O(N + Q)**
- N ≤ 10^5, Q ≤ 10^5이므로 가능

---

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, R, Q;
    static List<List<Integer>> tree = new ArrayList<>();
    static int[] dp;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        R = Integer.parseInt(st.nextToken()); // 루트 번호
        Q = Integer.parseInt(st.nextToken());

        for (int i = 0; i < N + 1; i++) {
            tree.add(new ArrayList<>());
        }

        for (int i = 0; i < N - 1; i++) {
            st = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(st.nextToken());
            int v = Integer.parseInt(st.nextToken());
            tree.get(u).add(v);
            tree.get(v).add(u);
        }

        dp = new int[N + 1]; // 해당 노드를 루트로 하는 서브트리에 속한 노드 수

        // DFS로 서브트리 크기 계산
        dfs(R, 0);

        StringBuilder sb = new StringBuilder();
        while (Q-- > 0) {
            int u = Integer.parseInt(br.readLine());
            sb.append(dp[u]).append('\n');
        }

        System.out.println(sb);
    }

    static void dfs(int v, int p) {
        dp[v] = 1; // 자기 자신 포함
        for (int next : tree.get(v)) {
            if (next != p) {
                dfs(next, v);
                dp[v] += dp[next];
            }
        }
    }
}
```
