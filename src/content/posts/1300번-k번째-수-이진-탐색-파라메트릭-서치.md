<https://www.acmicpc.net/problem/1300>

세준이는 크기가 N×N인 배열 A를 만들었다. 배열에 들어있는 수 A[i][j] = i×j 이다. 이 수를 일차원 배열 B에 넣으면 B의 크기는 N×N이 된다. B를 오름차순 정렬했을 때, B[k]를 구해보자.

배열 A와 B의 인덱스는 1부터 시작한다.

```java
3
7
```

첫째 줄에 배열의 크기 N이 주어진다. N은 10^5보다 작거나 같은 자연수이다. 둘째 줄에 k가 주어진다. k는 min(10^9, N^2)보다 작거나 같은 자연수이다.

```java
6
```

B[k]를 출력한다.

---

**아이디어**

- 배열을 정렬한 다음 k번째 수를 구하면 되는 간단한 문제 같지만, **배열을 직접 만들거나 정렬하면 시간 초과가 발생한다.**
- 이 문제는 <strong>파라메트릭 서치(Parametric Search)</strong>를 활용해야 한다.
- 핵심은 <strong>"어떤 값 x에 대해 A[i][j] ≤ x인 원소의 개수는?"</strong>을 계산하는 방식으로 이진 탐색을 적용하여 k번째 수를 찾아야 한다.
  - i × j ≤ x → **j ≤ x / i**
  - 각 행 i에 대해 **(x / i)개의 값이 만족** (단, j ≤ N)
  - 따라서 각 행에서 **min(N, x / i)개씩 누적 가능**

- 이걸 누적해서 **전체 개수가 k 이상인지 확인**
- 이렇게 하면 이분 탐색으로 B[k] 값을 찾을 수 있다.

---

⏱️ **시간 복잡도**

- 이분 탐색: **O(log N×N)** → 약 30~40
- 각 mid마다 누적 계산: **O(N)**
- 전체 시간 복잡도: **O(N log N)** ≈ 10^5 \* 20 → 가능

---

**Java 코드**

```java
import java.io.*;

public class Main {
    static int N, k;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        N = Integer.parseInt(br.readLine());
        k = Integer.parseInt(br.readLine());

        long left = 1;
        long right = (long) N * N;
        long answer = 0;

        while (left <= right) {
            long mid = (left + right) >>> 1;

            if (countLessOrEqual(mid) >= k) {
                answer = mid;
                right = mid - 1; // 더 작은 값도 가능한지 탐색
            } else {
                left = mid + 1;
            }
        }

        System.out.println(answer);
    }

    // A[i][j] <= x인 수의 개수 세기
    static long countLessOrEqual(long x) {
        long count = 0;
        for (int i = 1; i <= N; i++) {
            count += Math.min(N, x / i);
        }
        return count;
    }
}
```

---

**예제 시각화**

```java
N = 3
k = 7
```

- left = 1, right = 9, mid = **5**
  - **5** 이하인 수의 개수? → count += min(3, **5** / i) (i는 1부터 3까지) → **6개**
  - k 이상인가? → false → left = mid + 1 = 6
- left = 6, right = 9, mid = **7**
  - **7** 이하인 수의 개수? → count += min(3, **7** / i) (i는 1부터 3까지) → **8개**
  - k 이상인가? → true → **answer = mid = 7**, right = mid - 1 = 6
- left = 6, right = 6, mid = **6**
  - **6** 이하인 수의 개수? → count += min(3, **6** / i) (i는 1부터 3까지) → **8개**
  - k 이상인가? → true → **answer = mid = 6**, right = mid - 1 = 5
- left = 6, right = 5 → while (left <= right) 탈출

따라서, **B[k] = 6**

---

**요약**

- **A[i][j] = i \* j**인 곱셈표를 직접 만들지 않고,
- **x 이하의 원소 개수를 세는 함수**를 이용하여,
- **k번째 수를 이진 탐색**으로 구하는 **파라메트릭 서치** 문제
