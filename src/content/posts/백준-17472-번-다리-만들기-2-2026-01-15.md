## 1. 섬 식별 (BFS)

- 격자판에서 연결된 땅들을 찾아서 각 섬에 번호(1번 섬, 2번 섬...)를 붙여 구분한다.

## 2. 간선(다리) 추출

- 모든 섬의 해안가에서 상하좌우 네 방향으로 다리를 놓아본다.
- **조건**: 다리의 길이는 2 이상이어야 하며, 중간에 다른 섬을 만나지 않고 목적지 섬에 닿아야 한다.
- 섬 A와 섬 B를 연결하는 여러 다리 중 가장 짧은 길이를 간선 가중치로 저장한다.

## 3. 최소 신장 트리(MST) 구하기

- 추출된 다리 정보들을 바탕으로 모든 섬을 연결하는 최소 비용을 구한다. (크루스칼 또는 프림 알고리즘 사용)
- **주의**: 모든 섬이 연결되지 않는 경우 -1을 출력한다.

## 오답

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, M, islandCount = 0;
    static int[][] map;
    static int[] dr = {-1, 1, 0, 0};
    static int[] dc = {0, 0, -1, 1};

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        M = Integer.parseInt(st.nextToken());

        map = new int[N][M];
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                map[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // 섬 번호 붙임
        markIslands();

        // 각 섬을 잇는 다리의 최소 길이(최소 2 이상) 구하기
        int[][] distance = new int[islandCount + 1][islandCount + 1];
        for (int[] d : distance) {
            Arrays.fill(d, Integer.MAX_VALUE);
        }

        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                if (map[i][j] != 0) {
                    buildBridge(i, j, map[i][j], distance);
                }
            }
        }

        List<List<Edge>> graph = new ArrayList<>();
        for (int i = 0; i < islandCount + 1; i++) {
            graph.add(new ArrayList<>());
        }

        for (int i = 0; i < distance.length; i++) {
            for (int j = 0; j < distance.length; j++) {
                if (distance[i][j] != Integer.MAX_VALUE) {
                    graph.get(i).add(new Edge(j, distance[i][j]));
                }
            }
        }

        // 3. MST 구현
        boolean[] visited = new boolean[islandCount + 1];
        PriorityQueue<Edge> pq = new PriorityQueue<>();
        pq.add(new Edge(1, 0));

        int sum = 0;
        int count = 0;

        while (!pq.isEmpty()) {
            Edge cur = pq.poll();
            int node = cur.node;

            if (visited[node]) {
                continue;
            }

            visited[node] = true;
            sum += cur.dist;

            if (++count == islandCount) {
                break;
            }

            for (Edge e : graph.get(node)) {
                if (!visited[node]) {
                    pq.add(e);
                }
            }
        }

        if (count != islandCount) {
            System.out.println(-1);
            return;
        }

        System.out.println(sum);
    }

    static void markIslands() {
        boolean[][] visited = new boolean[N][M];

        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                if (map[i][j] != 0 && !visited[i][j]) {
                    bfs(i, j, ++islandCount, visited);
                }
            }
        }
    }

    static void bfs(int i, int j, int num, boolean[][] visited) {
        Queue<int[]> q = new LinkedList<>();
        q.add(new int[]{i, j});
        visited[i][j] = true;
        map[i][j] = num;

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int cr = cur[0];
            int cc = cur[1];

            for (int d = 0; d < 4; d++) {
                int nr = cr + dr[d];
                int nc = cc + dc[d];

                if (nr < 0 || nc < 0 || nr >= N || nc >= M) {
                    continue;
                }
                if (visited[nr][nc] && map[nr][nc] == 0) {
                    continue;
                }

                q.add(new int[]{nr, nc});
                visited[nr][nc] = true;
                map[nr][nc] = num;
            }
        }
    }

    // 시작 섬에서 다른 섬으로 길이가 최소 2 이상인 다리 짓기
    static void buildBridge(int i, int j, int start, int[][] distance) {
        for (int d = 0; d < 4; d++) {
            int r = i;
            int c = j;
            int dist = 0;

            while (true) {
                r += dr[d];
                c += dc[d];

                if (r < 0 || c < 0 || r >= N || c >= M) {
                    break;
                }
                if (map[r][c] == start) { // 시작 섬
                    break;
                }
                if (map[r][c] != 0) { // 다른 섬 도착
                    if (dist >= 2) {
                        distance[start][map[r][c]] = Math.min(
                                distance[start][map[r][c]],
                                dist
                        );
                    }
                    break;
                }
                dist++;
            }
        }
    }

    static class Edge implements Comparable<Edge> {
        int node;
        int dist;

        public Edge(int node, int dist) {
            this.node = node;
            this.dist = dist;
        }

        @Override
        public int compareTo(Edge o) {
            return Integer.compare(this.dist, o.dist);
        }
    }
}
```

## 오답인 이유

- bfs()에서 방문 했거나 바다인 경우를 체크하는 조건에서 OR 연산자가 아니라 AND 연산자를 사용함

```java
if (visited[nr][nc] && map[nr][nc] == 0) // 오답 ❌
if (visited[nr][nc] || map[nr][nc] == 0) // 정답 ✅
```

- 프림 알고리즘에서 방문 체크를 하는 과정에서 다음 노드가 아니라 현재 노드만 계속 확인함

```java
if (!visited[node])   // 오답 ❌
if (!visited[e.node]) // 정답 ✅
```

## 1. 프림 알고리즘 이용 (섬의 개수가 적으므로 인접 리스트 대신 인접 행렬 사용)

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, M, islandCount = 0;
    static int[][] map;
    static int[][] adj;
    static int[] dr = {-1, 1, 0, 0};
    static int[] dc = {0, 0, -1, 1};

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        M = Integer.parseInt(st.nextToken());

        map = new int[N][M];
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                map[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // 1. 섬 식별 (BFS)
        boolean[][] visited = new boolean[N][M];
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                if (map[i][j] == 1 && !visited[i][j]) {
                    labelIsland(i, j, ++islandCount, visited);
                }
            }
        }

        // 2. 인접 행렬 초기화 (무한대 값으로)
        adj = new int[islandCount + 1][islandCount + 1];
        for (int i = 1; i <= islandCount; i++) {
            Arrays.fill(adj[i], Integer.MAX_VALUE);
        }

        // 3. 모든 다리 건설 시도 및 최소 거리 갱신
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                if (map[i][j] > 0) {
                    makeBridges(i, j, map[i][j]);
                }
            }
        }

        // 4. 프림 알고리즘 수행
        System.out.println(prim());
    }

    static void labelIsland(int r, int c, int id, boolean[][] visited) {
        Queue<int[]> q = new LinkedList<>();
        q.add(new int[]{r, c});
        visited[r][c] = true;
        map[r][c] = id;

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            for (int d = 0; d < 4; d++) {
                int nr = cur[0] + dr[d];
                int nc = cur[1] + dc[d];
                if (nr >= 0 && nc >= 0 && nr < N && nc < M &&
                        map[nr][nc] == 1 && !visited[nr][nc]) {
                    visited[nr][nc] = true;
                    map[nr][nc] = id;
                    q.add(new int[]{nr, nc});
                }
            }
        }
    }

    static void makeBridges(int r, int c, int startIsland) {
        for (int d = 0; d < 4; d++) {
            int nr = r + dr[d];
            int nc = c + dc[d];
            int dist = 0;

            while (nr >= 0 && nc >= 0 && nr < N && nc < M) {
                if (map[nr][nc] == startIsland) {
                    break; // 같은 섬
                }
                if (map[nr][nc] > 0) { // 다른 섬 도달
                    if (dist >= 2) {
                        int endIsland = map[nr][nc];
                        adj[startIsland][endIsland] = Math.min(adj[startIsland][endIsland], dist);
                        adj[endIsland][startIsland] = Math.min(adj[endIsland][startIsland], dist);
                    }
                    break;
                }
                // 바다일 경우 계속 전진
                dist++;
                nr += dr[d];
                nc += dc[d];
            }
        }
    }

    static int prim() {
        boolean[] visited = new boolean[islandCount + 1];
        PriorityQueue<Edge> pq = new PriorityQueue<>();
        pq.add(new Edge(1, 0)); // 1번 섬부터 시작

        int totalDist = 0;
        int count = 0;

        while (!pq.isEmpty()) {
            Edge cur = pq.poll();
            int node = cur.node;

            if (visited[node]) {
                continue;
            }

            visited[node] = true;
            totalDist += cur.dist;

            if (++count == islandCount) {
                break;
            }

            for (int next = 1; next <= islandCount; next++) {
                if (!visited[next] && adj[node][next] != Integer.MAX_VALUE) {
                    pq.add(new Edge(next, adj[node][next]));
                }
            }
        }

        // 모든 섬이 연결되었는지 확인
        return count == islandCount ? totalDist : -1;
    }

    static class Edge implements Comparable<Edge> {
        int node, dist;

        Edge(int node, int dist) {
            this.node = node;
            this.dist = dist;
        }

        @Override
        public int compareTo(Edge o) {
            return Integer.compare(this.dist, o.dist);
        }
    }
}
```

## 2. 크루스칼 알고리즘 이용

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, M;
    static int[][] map;
    static boolean[][] visited;
    static int[] dr = {-1, 1, 0, 0};
    static int[] dc = {0, 0, -1, 1};
    static int islandCount = 0;
    static PriorityQueue<Edge> pq = new PriorityQueue<>();
    static int[] parent;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        N = Integer.parseInt(st.nextToken());
        M = Integer.parseInt(st.nextToken());
        map = new int[N][M];

        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                map[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // 1. 섬 분리하기 (번호 매기기)
        visited = new boolean[N][M];
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                if (map[i][j] == 1 && !visited[i][j]) {
                    islandCount++;
                    labelIsland(i, j, islandCount);
                }
            }
        }

        // 2. 만들 수 있는 모든 다리 찾기
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                if (map[i][j] > 0) {
                    findBridges(i, j, map[i][j]);
                }
            }
        }

        // 3. 크루스칼 알고리즘으로 MST 구하기
        parent = new int[islandCount + 1];
        for (int i = 1; i <= islandCount; i++) {
            parent[i] = i;
        }

        int totalDist = 0;
        int usedEdges = 0;

        while (!pq.isEmpty()) {
            Edge edge = pq.poll();
            if (find(edge.u) != find(edge.v)) {
                union(edge.u, edge.v);
                totalDist += edge.weight;
                usedEdges++;
            }
        }

        // 모든 섬을 연결하려면 간선은 (섬 개수 - 1)개 필요
        if (usedEdges == islandCount - 1 && totalDist > 0) {
            System.out.println(totalDist);
        } else {
            System.out.println(-1);
        }
    }

    // BFS를 이용한 섬 번호 매기기
    static void labelIsland(int r, int c, int id) {
        Queue<int[]> q = new LinkedList<>();
        q.add(new int[]{r, c});
        visited[r][c] = true;
        map[r][c] = id;

        while (!q.isEmpty()) {
            int[] curr = q.poll();
            for (int i = 0; i < 4; i++) {
                int nr = curr[0] + dr[i];
                int nc = curr[1] + dc[i];
                if (nr >= 0 && nc >= 0 && nr < N && nc < M) {
                    if (map[nr][nc] == 1 && !visited[nr][nc]) {
                        visited[nr][nc] = true;
                        map[nr][nc] = id;
                        q.add(new int[]{nr, nc});
                    }
                }
            }
        }
    }

    // 각 칸에서 4방향으로 다리를 놓아보는 함수
    static void findBridges(int r, int c, int startIsland) {
        for (int i = 0; i < 4; i++) {
            int dist = 0;
            int nr = r + dr[i];
            int nc = c + dc[i];

            while (true) {
                if (nr < 0 || nc < 0 || nr >= N || nc >= M) {
                    break; // 지도 밖
                }
                if (map[nr][nc] == startIsland) {
                    break; // 자기 자신 섬
                }

                if (map[nr][nc] > 0) { // 다른 섬 발견
                    if (dist >= 2) { // 다리 길이 조건 충족
                        pq.add(new Edge(startIsland, map[nr][nc], dist));
                    }
                    break;
                }

                // 바다(0)인 경우 다리 연장
                dist++;
                nr += dr[i];
                nc += dc[i];
            }
        }
    }

    // Union-Find
    static int find(int x) {
        if (parent[x] == x) {
            return x;
        }
        return parent[x] = find(parent[x]);
    }

    static void union(int x, int y) {
        x = find(x);
        y = find(y);
        if (x != y) {
            parent[y] = x;
        }
    }

    static class Edge implements Comparable<Edge> {
        int u, v, weight;

        Edge(int u, int v, int weight) {
            this.u = u;
            this.v = v;
            this.weight = weight;
        }

        @Override
        public int compareTo(Edge o) {
            return this.weight - o.weight;
        }
    }
}
```
