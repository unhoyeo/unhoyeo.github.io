<https://www.acmicpc.net/problem/17404>

RGB거리에는 집이 N개 있다. 거리는 선분으로 나타낼 수 있고, 1번 집부터 N번 집이 순서대로 있다.

집은 빨강, 초록, 파랑 중 하나의 색으로 칠해야 한다. 각각의 집을 빨강, 초록, 파랑으로 칠하는 비용이 주어졌을 때, 아래 규칙을 만족하면서 모든 집을 칠하는 비용의 최솟값을 구해보자.

- 1번 집의 색은 2번, N번 집의 색과 같지 않아야 한다.
- N번 집의 색은 N-1번, 1번 집의 색과 같지 않아야 한다.
- i(2 ≤ i ≤ N-1)번 집의 색은 i-1, i+1번 집의 색과 같지 않아야 한다.

```java
3
26 40 83
49 60 57
13 89 99
```

첫째 줄에 집의 수 N(2 ≤ N ≤ 1,000)이 주어진다. 둘째 줄부터 N개의 줄에는 각 집을 빨강, 초록, 파랑으로 칠하는 비용이 1번 집부터 한 줄에 하나씩 주어진다. 집을 칠하는 비용은 1,000보다 작거나 같은 자연수이다.

```java
110
```

첫째 줄에 모든 집을 칠하는 비용의 최솟값을 출력한다.

## 아이디어

- 이전의 [RGB거리](/posts/1149번-rgb거리-dp/) 문제는 첫 번째 집과 마지막 집이 연관 없지만, 이 문제는 **첫 번째 집과 마지막 집도 달라야 한다**는 제약이 추가됨
- 따라서 첫 번째 집과 마지막 집이 이어진 **원형 구조**로 생각해야 함
- 원형 구조는 **단순 DP로 해결 불가능** → 첫 번째 집의 색을 **R, G, B 중 하나로 고정**하고 DP를 3번 수행
  - 각 경우에서 첫 번째 집의 색을 **고정**하고, 마지막 집의 색이 첫 번째 집과 **다른 색**이 되도록 처리
- dp[i][j] = i번째 집까지 칠했을 때, 마지막 집의 색이 j일 때의 최소 비용 (j가 0이면 R, 1이면 G, 2면 B)

```java
dp[i][0] = cost[i][0] + min(dp[i-1][1], dp[i-1][2])
dp[i][1] = cost[i][1] + min(dp[i-1][0], dp[i-1][2])
dp[i][2] = cost[i][2] + min(dp[i-1][0], dp[i-1][1])
```

- 단, 첫 번째 집의 색을 고정했을 때는 나머지 두 색 비용을 **INF**로 설정해서 선택되지 않게 함
- 최종적으로 다음 세 경우 중 최솟값이 정답
  - 첫 번째 집의 색이 R일 때, 마지막 집이 G 또는 B인 경우 중 최솟값
  - 첫 번째 집의 색이 G일 때, 마지막 집이 R 또는 B인 경우 중 최솟값
  - 첫 번째 집의 색이 B일 때, 마지막 집이 R 또는 G인 경우 중 최솟값

## 시간 복잡도

- 첫 번째 집 색상 고정 3가지 × N개의 집 × 3가지 색상 = **O(3 × N × 3) = O(N)**
- N ≤ 1,000이므로 가능

---

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    static final int INF = 1_000_000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int[][] cost = new int[N][3];

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int j = 0; j < 3; j++) {
                cost[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        int answer = INF;

        // 첫 번째 집 색상 고정
        for (int first = 0; first < 3; first++) {
            int[][] dp = new int[N][3];

            // 초기화
            for (int c = 0; c < 3; c++) {
                if (c == first) dp[0][c] = cost[0][c];
                else dp[0][c] = INF;
            }

            // DP 수행
            for (int i = 1; i < N; i++) {
                dp[i][0] = cost[i][0] + Math.min(dp[i - 1][1], dp[i - 1][2]);
                dp[i][1] = cost[i][1] + Math.min(dp[i - 1][0], dp[i - 1][2]);
                dp[i][2] = cost[i][2] + Math.min(dp[i - 1][0], dp[i - 1][1]);
            }

            // 마지막 집 색상은 첫 번째 집 색상과 달라야 함
            for (int last = 0; last < 3; last++) {
                if (last == first) continue;
                answer = Math.min(answer, dp[N - 1][last]);
            }
        }

        System.out.println(answer);
    }
}
```

## 같은 아이디어 다른 풀이 (처음 제출했던 풀이에서 INF만 수정)

```java
import java.io.*;
import java.util.*;

public class Main {
    static final int INF = 1_000_000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int[][] cost = new int[N][3];

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int j = 0; j < 3; j++) {
                cost[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        int[][][] dp = new int[N][3][3]; // dp[i][currentColor][firstColor]

        for (int i = 0; i < 3; i++) {
            Arrays.fill(dp[0][i], INF);
            dp[0][i][i] = cost[0][i];
        }

        for (int i = 1; i < N; i++) {
            for (int j = 0; j < 3; j++) {
                dp[i][0][j] = cost[i][0] + Math.min(dp[i - 1][1][j], dp[i - 1][2][j]);
                dp[i][1][j] = cost[i][1] + Math.min(dp[i - 1][0][j], dp[i - 1][2][j]);
                dp[i][2][j] = cost[i][2] + Math.min(dp[i - 1][0][j], dp[i - 1][1][j]);
            }
        }

        int a = Math.min(dp[N - 1][0][1], dp[N - 1][0][2]);
        int b = Math.min(dp[N - 1][1][0], dp[N - 1][1][2]);
        int c = Math.min(dp[N - 1][2][0], dp[N - 1][2][1]);

        System.out.println(Math.min(a, Math.min(b, c)));
    }
}
```
