<https://www.acmicpc.net/problem/11057>

오르막 수는 수의 자리가 오름차순을 이루는 수를 말한다. 이때, 인접한 수가 같아도 오름차순으로 친다.

예를 들어, 2234와 3678, 11119는 오르막 수이지만, 2232, 3676, 91111은 오르막 수가 아니다.

수의 길이 N이 주어졌을 때, 오르막 수의 개수를 구하는 프로그램을 작성하시오. 수는 0으로 시작할 수 있다.

```html
3
```

첫째 줄에 N (1 ≤ N ≤ 1,000)이 주어진다.

```html
220
```

첫째 줄에 길이가 N인 오르막 수의 개수를 10,007로 나눈 나머지를 출력한다.

---

? **아이디어**

- dp[i][j] = i자리 오르막 수 중에서 마지막 자리가 j인 수의 개수 (1 ≤ i ≤ N, 0 ≤ j ≤ 9)
  - 길이가 1인 오르막 수는 0 ~ 9 각각 하나씩 존재하므로, dp[1][0~9] = 1
- **이전 자리의 수는 현재 수보다 작거나 같아야 한다.**
  - 즉, 마지막 자리가 2인 경우 이전 자리는 0, 1, 2만 가능
- 예를 들어, 3자리이고 마지막 수가 2인 dp[3][2]인 경우를 보면 다음과 같다.

```java
00 2 → dp[2][0]: 2자리이고 마지막 수가 0

01 2
11 2 → dp[2][1]: 2자리이고 마지막 수가 1

02 2
12 2
22 2 → dp[2][2]: 2자리이고 마지막 수가 2
```

- 따라서 점화식은 다음과 같이 구할 수 있다.

```java
dp[i][j] = dp[i-1][0] + dp[i-1][1] + ... + dp[i-1][j]
```

- 최종 정답은 dp[N][0] + dp[N][1] + ... + dp[N][9]

---

⏱️ **시간 복잡도**

- N자리 각각에 대해 매번 10번 덧셈
- 각 덧셈 과정은 0~j 번 반복
- 따라서 **O(N × 10 × 10)**

---

? **Java 코드**

```java
import java.io.*;
import java.util.*;

public class Main {
    static final int MOD = 10_007;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        // dp[i][j] = i자리 오르막 수 중에서 마지막 자리가 j인 수의 개수
        int[][] dp = new int[N + 1][10];

        Arrays.fill(dp[1], 1);

        for (int i = 2; i <= N; i++) {
            for (int j = 0; j <= 9; j++) {
                for (int k = 0; k <= j; k++) {
                    dp[i][j] = (dp[i][j] + dp[i - 1][k]) % MOD;
                }
            }
        }

        int result = 0;
        for (int i : dp[N]) {
            result = (result + i) % MOD;
        }

        System.out.println(result);
    }
}
```

---

? **개선: 누적합을 활용한 최적화**

누적합을 사용하면 다음과 같이 내부 for문을 줄일 수 있다.

```java
for (int i = 2; i <= N; i++) {
    dp[i][0] = dp[i - 1][0];
    for (int j = 1; j <= 9; j++) {
        dp[i][j] = (dp[i][j - 1] + dp[i - 1][j]) % MOD;
    }
}
```
