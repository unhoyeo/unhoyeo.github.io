<https://www.acmicpc.net/problem/14725>

개미는(뚠뚠) 오늘도(뚠뚠) 열심히(뚠뚠) 일을 하네.

개미는 아무말도 하지 않지만 땀을 뻘뻘 흘리면서 매일 매일을 살길 위해서 열심히 일을 하네.

한 치 앞도(뚠뚠) 모르는(뚠뚠) 험한 이 세상(뚠뚠) 그렇지만(뚠뚠) 오늘도 행복한 개미들!

우리의 천재 공학자 윤수는 이 개미들이 왜 행복한지 궁금해졌다.

행복의 비결이 개미가 사는 개미굴에 있다고 생각한 윤수는 개미굴의 구조를 알아보기 위해 로봇 개미를 만들었다.

로봇 개미는 센서가 있어 개미굴의 각 층에 먹이가 있는 방을 따라 내려가다 더 이상 내려갈 수 없으면 그 자리에서 움직이지 않고 신호를 보낸다.

이 신호로 로봇 개미는 개미굴 각 층을 따라 내려오면서 알게 된 각 방에 저장된 먹이 정보를 윤수한테 알려줄 수 있다.

로봇 개미 개발을 완료한 윤수는 개미굴 탐사를 앞두고 로봇 개미를 테스트 해보기 위해 위 그림의 개미굴에 로봇 개미를 투입했다. 로봇 개미의 수는 각 개미굴의 저장소를 모두 확인할 수 있을 만큼 넣는다.

다음은 로봇 개미들이 윤수에게 보내준 정보다.

- KIWI BANANA
- KIWI APPLE
- APPLE APPLE
- APPLE BANANA KIWI

공백을 기준으로 왼쪽부터 순서대로 로봇 개미가 각 층마다 지나온 방에 있는 먹이 이름을 뜻한다.

윤수는 로봇 개미들이 보내준 정보를 바탕으로 다음과 같이 개미굴의 구조를 손으로 그려봤다.

```java
APPLE
--APPLE
--BANANA
----KIWI
KIWI
--APPLE
--BANANA
```

개미굴의 각 층은 "--" 로 구분을 하였다. 또 같은 층에 여러 개의 방이 있을 때에는 사전 순서가 앞서는 먹이 정보가 먼저 나온다.

우리의 천재 공학자 윤수는 복잡한 개미굴들을 일일이 손으로 그리기 힘들어 우리에게 그려달라고 부탁했다.

한치 앞도 모르는 험한 이세상 그렇지만 오늘도 행복한 개미들!

행복의 비결을 알기 위해 윤수를 도와 개미굴이 어떤 구조인지 확인해보자.

```java
4
2 KIWI BANANA
2 KIWI APPLE
2 APPLE APPLE
3 APPLE BANANA KIWI
```

첫 번째 줄은 로봇 개미가 각 층을 따라 내려오면서 알게 된 먹이의 정보 개수 N (1 ≤ N ≤ 1000)개가 주어진다.

두 번째 줄부터 N+1 번째 줄까지, 각 줄의 시작은 로봇 개미 한마리가 보내준 먹이 정보 개수 K (1 ≤ K ≤ 15)가 주어진다.

다음 K개의 입력은 로봇 개미가 왼쪽부터 순서대로 각 층마다 지나온 방에 있는 먹이 정보이며 먹이 이름 길이 t는 1 ≤ t ≤ 15를 만족한다. 먹이 정보는 알파벳 대문자로만 이루어져 있다.

```java
APPLE
--APPLE
--BANANA
----KIWI
KIWI
--APPLE
--BANANA
```

개미굴의 시각화된 구조를 출력하여라.

개미굴의 각 층을 "--" 로 구분하며, 같은 층에 여러개의 방이 있을 때에는 사전 순서가 앞서는 먹이 정보가 먼저 나온다.

최상위 굴을 포함하여 하나의 굴에서 개미굴이 여러개로 나뉠 때 먹이 종류별로 최대 한 번만 나올 수 있다.

## 아이디어

- **트리 구조**로 먹이 정보를 저장
- 트리의 각 노드에는 **최상위 노드 이름, 이름, 깊이, 자식 노드들** 정보 저장
  - 위 예시에서 --APPLE은 깊이도 같고 이름도 같기 때문에, 무조건 값이 다른 **최상위 노드**(APPLE, KIWI) 이름을 추가로 저장
  - 같은 노드인지 확인하기 위해 **equals(), hashCode() 메서드 재정의 → 자식 노드들 빼고 다 같으면 같은 노드로 처리**
- 노드를 삽입할 때,
  - **이미 존재하는 노드인 경우**, 그 노드를 **찾은 다음**에 자식 노드 삽입
  - 아니면 그냥 삽입 후 자식 노드 삽입
- **자식 노드들**을 알파벳 순으로 정렬해야 하기 때문에 **PriorityQueue** 이용

```java
import java.io.*;
import java.util.*;

class Node implements Comparable<Node> {
    String root, name;
    int depth;
    PriorityQueue<Node> nodes = new PriorityQueue<>();

    Node(String root, String name, int depth) {
        this.root = root;
        this.name = name;
        this.depth = depth;
    }

    public Node findNode(Node node) {
        for (Node n : nodes) {
            if (n.equals(node)) {
                return n;
            }
        }
        return null;
    }

    @Override
    public int compareTo(Node o) {
        return name.compareTo(o.name);
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Node node = (Node) o;
        return Objects.equals(root, node.root)
                && Objects.equals(name, node.name)
                && depth == node.depth;
    }

    @Override
    public int hashCode() {
        return Objects.hash(root, name, depth);
    }
}

class Main {
    static Node root = new Node("root", "root", -1);
    static StringBuilder result = new StringBuilder();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int K = Integer.parseInt(st.nextToken());
            String[] feeds = new String[K];
            for (int j = 0; j < K; j++) {
                feeds[j] = st.nextToken();
            }
            buildTree(K, feeds);
        }

        buildResult(root);
        System.out.println(result);
    }

    static void buildTree(int k, String[] feeds) {
        Node parent = root;
        for (int i = 0; i < k; i++) {
            Node child = new Node(feeds[0], feeds[i], i);
            if (parent.nodes.contains(child)) {
                parent = parent.findNode(child); // 이미 가지고 있는 child 줘야됨
            } else {
                parent.nodes.add(child);
                parent = child;
            }

        }
    }

    static void buildResult(Node node) {
        if (!node.name.equals("root")) {
            for (int i = 0; i < node.depth; i++) {
                result.append("--");
            }
            result.append(node.name).append('\n');
        }

        while (!node.nodes.isEmpty()) {
            buildResult(node.nodes.poll());
        }
    }
}
```

위 코드를 DFS를 활용하여 간단하게 만든 것은 다음과 같다.

```java
import java.io.*;
import java.util.*;

class Node implements Comparable<Node> {
    String name;
    PriorityQueue<Node> children = new PriorityQueue<>();

    public Node(String name) {
        this.name = name;
    }

    public Node findChild(String name) {
        for (Node child : this.children) {
            if (child.name.equals(name)) {
                return child;
            }
        }
        return null;
    }

    @Override
    public int compareTo(Node o) {
        return this.name.compareTo(o.name);
    }
}

public class Main {
    static Node root = new Node("root");
    static StringBuilder result = new StringBuilder();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int K = Integer.parseInt(st.nextToken());
            String[] feeds = new String[K];
            for (int j = 0; j < K; j++) {
                feeds[j] = st.nextToken();
            }
            buildTree(root, feeds, 0);
        }

        buildResult(root, 0);
        System.out.println(result);
    }

    static void buildTree(Node node, String[] feeds, int depth) {
        if (depth == feeds.length) {
            return;
        }

        String name = feeds[depth];
        Node child = node.findChild(name);

        if (child == null) {
            child = new Node(name);
            node.children.add(child);
        }

        buildTree(child, feeds, depth + 1);
    }

    static void buildResult(Node node, int depth) {
        if (!node.name.equals("root")) {
            for (int i = 1; i < depth; i++) {
                result.append("--");
            }
            result.append(node.name).append("\n");
        }

        while (!node.children.isEmpty()) {
            buildResult(node.children.poll(), depth + 1);
        }
    }
}
```

**Trie(트라이)**자료구조(자바에서는 **TreeMap**으로 구현)를 사용하여 푼 것은 다음과 같다.

```java
import java.io.*;
import java.util.*;

class Node {
    TreeMap<String, Node> children = new TreeMap<>();
}

class Trie {
    Node root = new Node();

    void insert(String[] foods) {
        Node node = root;
        for (String food : foods) {
            node.children.putIfAbsent(food, new Node());
            node = node.children.get(food);
        }
    }
}

public class Main {
    static StringBuilder result = new StringBuilder();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine().trim());
        Trie trie = new Trie();

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int K = Integer.parseInt(st.nextToken());
            String[] foods = new String[K];
            for (int j = 0; j < K; j++) {
                foods[j] = st.nextToken();
            }
            trie.insert(foods);
        }

        buildResult(trie.root, 0);
        System.out.println(result);
    }

    static void buildResult(Node node, int depth) {
        for (String food : node.children.keySet()) {
            for (int i = 0; i < depth; i++) {
                result.append("--");
            }
            result.append(food).append("\n");
            buildResult(node.children.get(food), depth + 1);
        }
    }
}
```

- 각 노드는 **TreeMap&lt;String, Node> children**을 가짐
- **TreeMap**을 사용하여 **사전순 자동 정렬**
- **putIfAbsent()**을 사용하여 **중복 방지하며 삽입**
- **DFS** 방식으로 트라이 탐색하며 개미굴 출력
