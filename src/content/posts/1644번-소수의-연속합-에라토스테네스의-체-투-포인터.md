<https://www.acmicpc.net/problem/1644>

하나 이상의 연속된 소수의 합으로 나타낼 수 있는 자연수들이 있다. 몇 가지 자연수의 예를 들어 보면 다음과 같다.

- 3 : 3 (한 가지)
- 41 : 2+3+5+7+11+13 = 11+13+17 = 41 (세 가지)
- 53 : 5+7+11+13+17 = 53 (두 가지)

하지만 연속된 소수의 합으로 나타낼 수 없는 자연수들도 있는데, 20이 그 예이다. 7+13을 계산하면 20이 되기는 하나 7과 13이 연속이 아니기에 적합한 표현이 아니다. 또한 한 소수는 반드시 한 번만 덧셈에 사용될 수 있기 때문에, 3+5+5+7과 같은 표현도 적합하지 않다.

자연수가 주어졌을 때, 이 자연수를 연속된 소수의 합으로 나타낼 수 있는 경우의 수를 구하는 프로그램을 작성하시오.

```java
41
```

첫째 줄에 자연수 N이 주어진다. (1 ≤ N ≤ 4,000,000)

```java
3
```

첫째 줄에 자연수 N을 연속된 소수의 합으로 나타낼 수 있는 경우의 수를 출력한다.

---

## 핵심 아이디어

- 주어진 자연수 N을 **연속된 소수의 합**으로 표현할 수 있는 경우의 수를 구해야 한다.
- 우선, **에라토스테네스의 체**로 **N 이하의 모든 소수 리스트**를 구한다.
- 해당 소수 리스트에서 **투 포인터**를 사용하여 **연속된 부분 합이 N이 되는 구간의 수**를 센다.
  - 합이 N 이상일 경우 → 정확히 N이면 경우의 수를 증가시키고, **left를 늘려서 합을 줄임**
  - 합이 N보다 작을 경우 → **right를 늘려서 합을 키움**

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        // N 이하의 모든 소수 리스트 구하기 (에라토스테네스의 체)
        List<Integer> primes = getPrimes(N);

        // 투 포인터로 연속된 소수 합 찾기
        int left = 0, right = 0;
        int sum = 0, count = 0;

        while (true) {
            if (sum >= N) {
                if (sum == N) count++;
                sum -= primes.get(left);
                left++;
            } else {
                if (right == primes.size()) break;
                sum += primes.get(right);
                right++;
            }
        }

        System.out.println(count);
    }

    public static List<Integer> getPrimes(int N) {
        List<Integer> primes = new ArrayList<>();
        boolean[] isNotPrime = new boolean[N + 1];

        for (int i = 2; i <= N; i++) {
            if (!isNotPrime[i]) { // i가 소수인 경우
                primes.add(i);
                for (int j = i * 2; j <= N; j += i) { // i의 배수는 소수가 아님
                    isNotPrime[j] = true;
                }
            }
        }

        return primes;
    }
}
```

## 시간 복잡도

- 소수 구하기: **O(N log log N)**
- 투 포인터 탐색: O(N)

---

## 에라토스테네스의 체란?

- <strong>"N 이하의 모든 소수"</strong>를 빠르고 효율적으로 찾는 고전적인 알고리즘
- 시간 복잡도: **O(N log log N)**
- 보통 **10^7** 수준의 N까지도 무리 없이 동작

## 핵심 개념

- 2부터 N까지의 모든 정수를 나열한다.
- **2는 소수**이므로 표시하고, **2의 배수를 모두 지운다.**
- 그다음 남아있는 수 중 **가장 작은 수**(3)를 소수로 표시하고, **3의 배수를 모두 지운다.**
- 이를 반복하여 **남아있는 수만 소수로 간주**한다.

## 알고리즘 흐름

- boolean[] isNotPrime = new boolean[N + 1] 배열을 선언하여 **i가 소수가 아니면 true로 표시**
- 2부터 N까지의 수 i에 대해,
  - **isNotPrime[i] == false**이면, **i는 소수**이므로
  - **i의 배수** j = i\*2, i\*3, ... 를 모두 **true**로 표시
- 이 과정을 마치면 isNotPrime[i] == false인 모든 i는 소수다.

```java
boolean[] isNotPrime = new boolean[N + 1];
List<Integer> primes = new ArrayList<>();

for (int i = 2; i <= N; i++) {
    if (!isNotPrime[i]) {
        primes.add(i);
        for (int j = i * 2; j <= N; j += i) {
            isNotPrime[j] = true;
        }
    }
}
```

---

## 더 최적화한 버전

- j = i \* 2 대신, **j = i \* i 부터 배수를 지우기 시작** → 이미 i 미만의 배수는 이전 단계에서 제거되었기 때문
- **짝수는 미리 제거 가능** (i=2 이후부터 홀수만 탐색) → 2배로 빨라짐
- 배열 접근을 최소화하도록 loop 최적화

```java
List<Integer> primes = new ArrayList<>();
boolean[] isNotPrime = new boolean[N + 1];

for (int i = 2; i * i <= N; i++) {
    if (!isNotPrime[i]) { // i가 소수인 경우
        for (int j = i * i; j <= N; j += i) { // i의 배수는 소수가 아님
            isNotPrime[j] = true;
        }
    }
}

for (int i = 2; i <= N; i++) {
    if (!isNotPrime[i]) primes.add(i);
}
```

- **i <= Math.sqrt(N)** 또는 **long 캐스팅**을 권장
