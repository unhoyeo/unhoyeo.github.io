<https://www.acmicpc.net/problem/14891>

총 8개의 톱니를 가지고 있는 톱니바퀴 4개가 아래 그림과 같이 일렬로 놓여져 있다. 또, 톱니는 N극 또는 S극 중 하나를 나타내고 있다. 톱니바퀴에는 번호가 매겨져 있는데, 가장 왼쪽 톱니바퀴가 1번, 그 오른쪽은 2번, 그 오른쪽은 3번, 가장 오른쪽 톱니바퀴는 4번이다.

![14891번 톱니바퀴 - 구현, 시뮬레이션](/images/tistory/144/img.png)

이때, 톱니바퀴를 총 K번 회전시키려고 한다. 톱니바퀴의 회전은 한 칸을 기준으로 한다. 회전은 시계 방향과 반시계 방향이 있고, 아래 그림과 같이 회전한다.

![14891번 톱니바퀴 - 구현, 시뮬레이션](/images/tistory/144/img_1.png)

![14891번 톱니바퀴 - 구현, 시뮬레이션](/images/tistory/144/img_2.png)

톱니바퀴를 회전시키려면, 회전시킬 톱니바퀴와 회전시킬 방향을 결정해야 한다. 톱니바퀴가 회전할 때, 서로 맞닿은 극에 따라서 옆에 있는 톱니바퀴를 회전시킬 수도 있고, 회전시키지 않을 수도 있다. 톱니바퀴 A를 회전할 때, 그 옆에 있는 톱니바퀴 B와 서로 맞닿은 톱니의 극이 다르다면, B는 A가 회전한 방향과 반대방향으로 회전하게 된다. 예를 들어, 아래와 같은 경우를 살펴보자.

![14891번 톱니바퀴 - 구현, 시뮬레이션](/images/tistory/144/img_3.png)

두 톱니바퀴의 맞닿은 부분은 초록색 점선으로 묶여있는 부분이다. 여기서, 3번 톱니바퀴를 반시계 방향으로 회전했다면, 4번 톱니바퀴는 시계 방향으로 회전하게 된다. 2번 톱니바퀴는 맞닿은 부분이 S극으로 서로 같기 때문에, 회전하지 않게 되고, 1번 톱니바퀴는 2번이 회전하지 않았기 때문에, 회전하지 않게 된다. 따라서, 아래 그림과 같은 모양을 만들게 된다.

![14891번 톱니바퀴 - 구현, 시뮬레이션](/images/tistory/144/img_4.png)

위와 같은 상태에서 1번 톱니바퀴를 시계 방향으로 회전시키면, 2번 톱니바퀴가 반시계 방향으로 회전하게 되고, 2번이 회전하기 때문에, 3번도 동시에 시계 방향으로 회전하게 된다. 4번은 3번이 회전하지만, 맞닿은 극이 같기 때문에 회전하지 않는다. 따라서, 아래와 같은 상태가 된다.

![14891번 톱니바퀴 - 구현, 시뮬레이션](/images/tistory/144/img_5.png)

톱니바퀴의 초기 상태와 톱니바퀴를 회전시킨 방법이 주어졌을 때, 최종 톱니바퀴의 상태를 구하는 프로그램을 작성하시오.

```java
10101111
01111101
11001110
00000010
2
3 -1
1 1
```

첫째 줄에 1번 톱니바퀴의 상태, 둘째 줄에 2번 톱니바퀴의 상태, 셋째 줄에 3번 톱니바퀴의 상태, 넷째 줄에 4번 톱니바퀴의 상태가 주어진다. 상태는 8개의 정수로 이루어져 있고, 12시방향부터 시계방향 순서대로 주어진다. N극은 0, S극은 1로 나타나있다.

다섯째 줄에는 회전 횟수 K(1 ≤ K ≤ 100)가 주어진다. 다음 K개 줄에는 회전시킨 방법이 순서대로 주어진다. 각 방법은 두 개의 정수로 이루어져 있고, 첫 번째 정수는 회전시킨 톱니바퀴의 번호, 두 번째 정수는 방향이다. 방향이 1인 경우는 시계 방향이고, -1인 경우는 반시계 방향이다.

```java
7
```

총 K번 회전시킨 이후에 네 톱니바퀴의 점수의 합을 출력한다. 점수란 다음과 같이 계산한다.

- 1번 톱니바퀴의 12시방향이 N극이면 0점, S극이면 1점
- 2번 톱니바퀴의 12시방향이 N극이면 0점, S극이면 2점
- 3번 톱니바퀴의 12시방향이 N극이면 0점, S극이면 4점
- 4번 톱니바퀴의 12시방향이 N극이면 0점, S극이면 8점

## 아이디어

- 각 회전 방법마다 **4개의 톱니바퀴가 어떤 방향으로 회전할지 배열에 저장**
- 기준 톱니바퀴를 중심으로 **왼쪽, 오른쪽을 탐색**하며 회전 여부를 결정
  - 왼쪽 톱니바퀴의 오른쪽 톱니(인덱스 2)가 현재 톱니바퀴의 왼쪽 톱니(인덱스 6)와 **극이 다르면 현재 톱니바퀴의 반대로 회전**
  - 오른쪽 톱니바퀴의 왼쪽 톱니(인덱스 6)가 현재 톱니바퀴의 오른쪽 톱니(인덱스 2)와 **극이 다르면 현재 톱니바퀴의 반대로 회전**
- 모두 결정되면 **한 번에 회전**
- 이 과정을 K번 반복

## 시간 복잡도

- K번의 명령마다 최대 4개의 톱니바퀴를 검사하므로, 전체 시간 복잡도는 **O(K)**

## 자바 코드 (char[][] 이용)

```java
import java.io.*;
import java.util.*;

public class Main {
    static char[][] gears = new char[4][8];

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (int i = 0; i < 4; i++) {
            gears[i] = br.readLine().toCharArray();
        }

        int K = Integer.parseInt(br.readLine());

        while (K-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int gearIdx = Integer.parseInt(st.nextToken()) - 1;
            int direction = Integer.parseInt(st.nextToken());

            int[] directions = new int[4];
            directions[gearIdx] = direction;

            for (int left = gearIdx - 1; left >= 0; left--) {
                if (gears[left][2] != gears[left + 1][6]) {
                    directions[left] = -directions[left + 1];
                } else {
                    break;
                }
            }

            for (int right = gearIdx + 1; right <= 3; right++) {
                if (gears[right - 1][2] != gears[right][6]) {
                    directions[right] = -directions[right - 1];
                } else {
                    break;
                }
            }

            for (int i = 0; i < 4; i++) {
                if (directions[i] == 1) rotateRight(i);
                else if (directions[i] == -1) rotateLeft(i);
            }
        }

        int score = 0;
        for (int i = 0; i < 4; i++) {
            if (gears[i][0] == '1') {
                score += (1 << i);
            }
        }

        System.out.println(score);
    }

    static void rotateRight(int gearIdx) {
        char last = gears[gearIdx][7];
        for (int i = 7; i >= 1; i--) {
            gears[gearIdx][i] = gears[gearIdx][i - 1];
        }
        gears[gearIdx][0] = last;
    }

    static void rotateLeft(int gearIdx) {
        char first = gears[gearIdx][0];
        for (int i = 0; i <= 6; i++) {
            gears[gearIdx][i] = gears[gearIdx][i + 1];
        }
        gears[gearIdx][7] = first;
    }
}
```

## 자바 코드 (List&lt;Deque&lt;Integer>> 이용)

```java
import java.io.*;
import java.util.*;

public class Main {
    static List<Deque<Integer>> gears = new ArrayList<>();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (int i = 0; i < 4; i++) {
            Deque<Integer> gear = new ArrayDeque<>();
            String line = br.readLine();
            for (int j = 0; j < 8; j++) {
                gear.add(line.charAt(j) - '0');
            }
            gears.add(gear);
        }

        int K = Integer.parseInt(br.readLine());

        while (K-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int gearIdx = Integer.parseInt(st.nextToken()) - 1;
            int direction = Integer.parseInt(st.nextToken());

            int[] directions = new int[4];
            directions[gearIdx] = direction;

            for (int left = gearIdx - 1; left >= 0; left--) {
                if (getRightCog(gears.get(left)) != getLeftCog(gears.get(left + 1))) {
                    directions[left] = -directions[left + 1];
                } else {
                    break;
                }
            }

            for (int right = gearIdx + 1; right <= 3; right++) {
                if (getLeftCog(gears.get(right)) != getRightCog(gears.get(right - 1))) {
                    directions[right] = -directions[right - 1];
                } else {
                    break;
                }
            }

            for (int i = 0; i < 4; i++) {
                if (directions[i] == 1) rotateRight(gears.get(i));
                else if (directions[i] == -1) rotateLeft(gears.get(i));
            }
        }

        int score = 0;
        for (int i = 0; i < 4; i++) {
            if (gears.get(i).peek() == 1) {
                score += (1 << i);
            }
        }

        System.out.println(score);
    }

    static int getRightCog(Deque<Integer> gear) {
        Iterator<Integer> it = gear.iterator();
        it.next(); // index 0
        it.next(); // index 1
        return it.next(); // index 2
    }

    static int getLeftCog(Deque<Integer> gear) {
        Iterator<Integer> it = gear.iterator();
        for (int i = 0; i < 6; i++) it.next();
        return it.next(); // index 6
        // 또는 return gear.toArray(new Integer[0])[6];
    }

    static void rotateRight(Deque<Integer> gear) {
        gear.addFirst(gear.pollLast());
    }

    static void rotateLeft(Deque<Integer> gear) {
        gear.addLast(gear.pollFirst());
    }
}
```

Deque은 **인덱스 기반 접근 메서드**를 제공하지 않기 때문에, 특정 인덱스의 요소를 조회하려면 다음과 같은 방법을 사용해야 한다.

## Iterator 사용

```java
static int getElementAt(Deque<Integer> deque, int index) {
    Iterator<Integer> it = deque.iterator();
    for (int i = 0; i < index; i++) {
        it.next();
    }
    return it.next();
}
```

- 시간 복잡도: **O(index)**
- 메모리 추가 사용 없이 순차 탐색
- 반복적으로 조회할 경우 이 방식이 toArray()보다 낫다.

---

## toArray()로 배열로 변환 후 접근

```java
static int getElementAt(Deque<Integer> deque, int index) {
    return deque.toArray(new Integer[0])[index];
}
```

- 시간 복잡도: **O(N)** (전체 복사 후 인덱스 접근 O(1))
- **내부 배열 전체를 복사**하기 때문에, 요소 수가 많을 경우 비효율적
- 성능이 중요한 경우에는 비추천

## 처음 제출한 풀이 (임시로 복사한 gears 배열 사용)

```java
import java.io.*;
import java.util.*;

public class Main {
    static char[][] gears = new char[5][8];

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (int i = 1; i <= 4; i++) {
            gears[i] = br.readLine().toCharArray();
        }

        int K = Integer.parseInt(br.readLine()); // 회전 횟수

        while (K-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int gearNum = Integer.parseInt(st.nextToken());
            int dir = Integer.parseInt(st.nextToken()); // 1: 시계, -1: 반시계

            char[][] tmp = copyGears();
            rotateGear(tmp[gearNum], dir);

            // 왼쪽으로 퍼지기
            int cur = gearNum;
            int curDir = dir;
            int left = gearNum - 1;
            while (left >= 1) {
                if (gears[cur][6] != gears[left][2]) {
                    rotateGear(tmp[left], -curDir);
                    cur = left;
                    curDir = -curDir;
                    left--;
                } else {
                    break;
                }
            }

            // 오른쪽으로 퍼지기
            cur = gearNum;
            curDir = dir;
            int right = gearNum + 1;
            while (right <= 4) {
                if (gears[cur][2] != gears[right][6]) {
                    rotateGear(tmp[right], -curDir);
                    cur = right;
                    curDir = -curDir;
                    right++;
                } else {
                    break;
                }
            }

            // 회전 적용
            gears = tmp;
        }

        // 점수 계산
        int score = 0;
        for (int i = 1; i <= 4; i++) {
            if (gears[i][0] == '1') {
                score += (int) Math.pow(2, i - 1);
            }
        }

        System.out.println(score);
    }

    static char[][] copyGears() {
        char[][] copied = new char[5][8];
        for (int i = 0; i < copied.length; i++) {
            copied[i] = gears[i].clone();
        }
        return copied;
    }

    static void rotateGear(char[] arr, int direction) {
        if (direction == 1) rotateRight(arr);
        else rotateLeft(arr);
    }

    // 시계 방향 회전: 오른쪽으로 한 칸 이동
    static void rotateRight(char[] arr) {
        char last = arr[7];
        for (int i = 7; i >= 1; i--) {
            arr[i] = arr[i - 1];
        }
        arr[0] = last;
    }

    // 반시계 방향 회전: 왼쪽으로 한 칸 이동
    static void rotateLeft(char[] arr) {
        char first = arr[0];
        for (int i = 0; i <= 6; i++) {
            arr[i] = arr[i + 1];
        }
        arr[7] = first;
    }
}
```
