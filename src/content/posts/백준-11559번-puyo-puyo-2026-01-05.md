<https://www.acmicpc.net/problem/11559>

이 문제는 전형적인 **시뮬레이션**과 **BFS**를 결합한 문제다.

뿌요뿌요의 핵심 로직인 '연결된 뿌요 찾기', '터뜨리기', '중력 처리'를 반복하면 해결할 수 있다.

## 1. 전체 루프 (연쇄 카운트)

- 더 이상 터질 뿌요 그룹이 없을 때까지 과정을 반복한다.
- 한 번의 루프가 끝날 때마다 연쇄를 1씩 증가시킨다.

## 2. 뿌요 찾기 및 터뜨리기 (BFS)

- 보드 전체를 탐색하며 **아직 방문하지 않은 뿌요**를 발견하면, 같은 색깔이 상하좌우로 **몇 개 연결되어 있는지** 확인한다.
- 연결된 개수가 **4개 이상**이라면 해당 뿌요들을 제거한다.

## 3. 중력 적용

- 터진 자리에 빈칸(.)이 생기면, 위에 떠 있는 뿌요들을 바닥부터 차곡차곡 쌓이도록 아래로 내린다.

## ❌ 틀린 풀이

```java
import java.io.*;
import java.util.*;

public class Main {
    static char[][] board = new char[12][6];
    static int[] dr = {0, 0, -1, 1};
    static int[] dc = {-1, 1, 0, 0};

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (int i = 0; i < 12; i++) {
            board[i] = br.readLine().toCharArray();
        }

        int totalChain = 0;

        while (true) {
            if (!pop()) {
                break;
            }
            applyGravity();
            totalChain++;
        }

        System.out.println(totalChain);
    }

    static boolean pop() {
        boolean isPopped = false;
        boolean[][] visited = new boolean[12][6];

        for (int i = 0; i < 12; i++) {
            for (int j = 0; j < 6; j++) {
                if (board[i][j] != '.') {
                    isPopped = isPopped || bfs(i, j, visited);
                }
            }
        }

        return isPopped;
    }

    static boolean bfs(int r, int c, boolean[][] visited) {
        boolean isPopped = false;
        Queue<int[]> q = new LinkedList<>();
        List<int[]> list = new ArrayList<>();

        int[] start = {r, c};
        q.add(start);
        list.add(start);
        visited[r][c] = true;

        while (!q.isEmpty()) {
            int[] cur = q.poll();

            for (int d = 0; d < 4; d++) {
                int nr = cur[0] + dr[d];
                int nc = cur[1] + dc[d];

                if (nr < 0 || nc < 0 || nr >= 12 || nc >= 6 ||
                        visited[nr][nc] ||
                        board[nr][nc] != board[r][c]) {
                    continue;
                }

                int[] next = {nr, nc};
                q.add(next);
                list.add(next);
                visited[nr][nc] = true;
            }
        }

        if (list.size() >= 4) {
            isPopped = true;
            for (int[] pos : list) {
                board[pos[0]][pos[1]] = '.';
            }
        }

        return isPopped;
    }

    static void applyGravity() {
        for (int i = 10; i >= 0; i--) {
            for (int j = 0; j < 6; j++) {
                if (board[i][j] != '.' && board[i + 1][j] == '.') {
                    int h = i + 1;
                    while (h < 11 && board[h + 1][j] == '.') {
                        h++;
                    }
                    board[h][j] = board[i][j];
                    board[i][j] = '.';
                }
            }
        }
    }
}
```

## ✅ 맞는 풀이

```java
import java.io.*;
import java.util.*;

public class Main {
    static char[][] board = new char[12][6];
    static int[] dr = {0, 0, -1, 1};
    static int[] dc = {-1, 1, 0, 0};
    static boolean isPopped;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (int i = 0; i < 12; i++) {
            board[i] = br.readLine().toCharArray();
        }

        int totalChain = 0;

        while (true) {
            isPopped = false;
            boolean[][] visited = new boolean[12][6];

            for (int i = 0; i < 12; i++) {
                for (int j = 0; j < 6; j++) {
                    if (board[i][j] != '.' && !visited[i][j]) {
                        bfs(i, j, visited);
                    }
                }
            }

            if (!isPopped) {
                break;
            }

            applyGravity();
            totalChain++;
        }

        System.out.println(totalChain);
    }

    static void bfs(int r, int c, boolean[][] visited) {
        Queue<int[]> q = new LinkedList<>();
        List<int[]> list = new ArrayList<>();

        int[] start = {r, c};
        q.add(start);
        list.add(start);
        visited[r][c] = true;

        while (!q.isEmpty()) {
            int[] cur = q.poll();

            for (int d = 0; d < 4; d++) {
                int nr = cur[0] + dr[d];
                int nc = cur[1] + dc[d];

                if (nr < 0 || nc < 0 || nr >= 12 || nc >= 6 ||
                        visited[nr][nc] ||
                        board[nr][nc] != board[r][c]) {
                    continue;
                }

                int[] next = {nr, nc};
                q.add(next);
                list.add(next);
                visited[nr][nc] = true;
            }
        }

        if (list.size() >= 4) {
            isPopped = true;
            for (int[] pos : list) {
                board[pos[0]][pos[1]] = '.';
            }
        }
    }

    static void applyGravity() {
        for (int i = 10; i >= 0; i--) {
            for (int j = 0; j < 6; j++) {
                if (board[i][j] != '.' && board[i + 1][j] == '.') {
                    int h = i + 1;
                    while (h < 11 && board[h + 1][j] == '.') {
                        h++;
                    }
                    board[h][j] = board[i][j];
                    board[i][j] = '.';
                }
            }
        }
    }
}
```

- 결국 두 코드의 핵심 차이는 **뿌요가 터졌는지 여부**를 관리하는 방식이다.
- 틀린 코드는 터짐 여부를 반환받아 **|| 연산자**를 통해 최종 판단하고, 맞는 코드는 **전역 변수**를 통해서 최종 판단한다.
- 결국 틀린 이유는 **|| 연산자의 동작 방식** 때문이다.

---

## ⚠️ || 연산자의 동작 방식 (자바의 단락 평가(Short-circuit evaluation) 규칙)

```java
isPopped = isPopped || bfs(i, j, visited);
```

자바의 논리 연산자 &&(AND)와 ||(OR)는 다음과 같이 동작한다.

1. **왼쪽 항**(isPopped)을 먼저 확인한다.
2. 만약 **왼쪽 항이 true**라면, **오른쪽 항(bfs(...))은 "실행조차 하지 않고"** 전체 결과를 true로 확정 짓는다.

즉, 한 번이라도 뿌요가 터져서 isPopped가 true가 되는 순간,

그 뒤에 나오는 다른 색깔의 뿌요들에 대해서는 **bfs 함수 자체가 호출되지 않았던 것이다.**

이는 논리 표현식의 결과를 판단하는 데 필요한 최소한의 연산만 수행하는 규칙으로,

왼쪽 피연산자의 값만으로 전체 결과가 결정되면, 오른쪽 피연산자는 평가하지 않아 성능을 향상시킬 수 있기 때문이다.
