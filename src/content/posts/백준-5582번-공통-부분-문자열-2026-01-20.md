<https://www.acmicpc.net/problem/5582>

이 문제는 <strong>최장 공통 부분 문자열(LCS, Longest Common Substring)</strong>을 구하는 문제다.

최장 공통 부분 수열(Longest Common Subsequence) 문제와 혼동하곤 하는데, 이 문제의 핵심은 <strong>"연속적이어야 한다"</strong>는 점이다.

---

두 문자열을 s1, s2라고 할 때, dp[i][j]를 **s1의 i번째 문자열과 s2의 j번째 문자열에서 끝나는 최장 공통 부분 문자열의 길이**라고 정의한다.

## 1. 두 문자가 같을 때

- 이전 문자들까지의 공통 길이에 1을 더한다.
- **dp[i][j] = dp[i-1][j-1] + 1**

## 2. 두 문자가 다를 때

- 연속적이어야 하므로 공통 부분 문자열이 끊긴다.
- **dp[i][j] = 0**

---

## ❌ 오답

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s1 = br.readLine();
        String s2 = br.readLine();

        int n1 = s1.length();
        int n2 = s2.length();

        int[][] dp = new int[n1 + 1][n2 + 1];

        for (int i = 1; i <= n1; i++) {
            for (int j = 1; j <= n2; j++) {
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = 0;
                }
            }
        }

        System.out.println(dp[n1][n2]);
    }
}
```

## 오답인 이유

- dp[i][j]는 s1의 i번째 문자와 s2의 j번째 문자에서 **딱 끝나는** 공통 부분 문자열의 길이다.
- 즉, 문제에서 요구하는 정답은 두 문자열의 **어느 지점에서든 발생할 수 있는** 가장 긴 길이다.
- 하지만 dp[n1][n2]는 오직 두 문자열의 **맨 마지막 문자들(s1의 끝과 s2의 끝)이 일치하며 끝날 때**의 길이만을 의미한다.
- 즉, 만약 두 문자열의 끝이 서로 다르다면 dp[n1][n2]는 무조건 0이 출력된다.
- 따라서 반복문을 돌면서 **dp[i][j] 값 중 최댓값을 계속 갱신**하고, 마지막에 그 최댓값을 출력해야 한다.

---

## ✅ 정답

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s1 = br.readLine();
        String s2 = br.readLine();

        int n1 = s1.length();
        int n2 = s2.length();

        // dp[i][j] : s1의 i번째, s2의 j번째 문자에서 끝나는 최장 공통 부분 문자열 길이
        int[][] dp = new int[n1 + 1][n2 + 1];
        int maxLen = 0;

        for (int i = 1; i <= n1; i++) {
            for (int j = 1; j <= n2; j++) {
                // 두 문자가 일치하면 대각선 왼쪽 위 값 + 1
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                    maxLen = Math.max(maxLen, dp[i][j]);
                }
                // 일치하지 않으면 0 (연속성이 깨짐)
                else {
                    dp[i][j] = 0;
                }
            }
        }

        System.out.println(maxLen);
    }
}
```
