<https://www.acmicpc.net/problem/1744>

길이가 N인 수열이 주어졌을 때, 그 수열의 합을 구하려고 한다. 하지만, 그냥 그 수열의 합을 모두 더해서 구하는 것이 아니라, 수열의 두 수를 묶으려고 한다. 어떤 수를 묶으려고 할 때, 위치에 상관없이 묶을 수 있다. 하지만, 같은 위치에 있는 수(자기 자신)를 묶는 것은 불가능하다. 그리고 어떤 수를 묶게 되면, 수열의 합을 구할 때 묶은 수는 서로 곱한 후에 더한다.

예를 들면, 어떤 수열이 {0, 1, 2, 4, 3, 5}일 때, 그냥 이 수열의 합을 구하면 0+1+2+4+3+5 = 15이다. 하지만, 2와 3을 묶고, 4와 5를 묶게 되면, 0+1+(2\*3)+(4\*5) = 27이 되어 최대가 된다.

수열의 모든 수는 단 한번만 묶거나, 아니면 묶지 않아야한다.

수열이 주어졌을 때, 수열의 각 수를 적절히 묶었을 때, 그 합이 최대가 되게 하는 프로그램을 작성하시오.

```
4
-1
2
1
3
```

수를 합이 최대가 나오게 묶었을 때 합을 출력한다. 정답은 항상 2^31보다 작다.

```
6
```

## ✅ 아이디어

- 수열에 음수, 0, 양수가 존재할 수 있다.
- 음수는 음수끼리 곱하면 최대가 된다.
- 만약 짝지을 음수가 없다면 0이랑 곱하는 것이 최대가 된다.
- 양수는 양수끼리 곱했을 때와 더했을 때 중 큰 값을 고르면 된다.
- 짝짓기는 int temp와 boolean flag를 이용 → false면 짝이 없으므로 temp에 저장, true면 짝이 있으므로 temp와 연산
- 연산이 다 끝난 후 temp에 값이 남아있으면 결과에 더하기

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int[] arr = new int[N];

        for (int i = 0; i < N; i++) {
            arr[i] = Integer.parseInt(br.readLine());
        }

        Arrays.sort(arr);

        int sum = 0, temp = 0;
        int i = 0, j = arr.length - 1;
        boolean nFlag = false, pFlag = false;

        while (i <= j) {
            if (arr[i] <= 0) {
                if (nFlag) sum += temp * arr[i];
                else temp = arr[i];
                nFlag = !nFlag;
                i++;
            } else {
                // 임시로 저장한 음수가 있는 경우
                if (nFlag) {
                    sum += temp;
                    nFlag = false;
                }
                if (pFlag) sum += Math.max(temp + arr[j], temp * arr[j]);
                else temp = arr[j];
                pFlag = !pFlag;
                j--;
            }
        }

        // 임시값 더하기
        if (nFlag || pFlag) sum += temp;

        System.out.println(sum);
    }
}
```

## ✅ 또 다른 아이디어

- **1은 무조건 더하는 것이 크고**, 1보다 큰 수들은 서로 곱하는 것이 더 크다.
  - 예: 1×5=5 < 1+5=6
- 0 이하 수들은 작은 수끼리 묶어야 한다.
  - 음수끼리 곱하면 양수가 된다.
  - 0은 음수와 곱해서 0으로 만들면 좋다.
- 수가 홀수 개일 경우 → 묶이지 못한 수는 그대로 더해야 한다.

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        List<Integer> plus = new ArrayList<>();
        List<Integer> minus = new ArrayList<>();

        int oneCount = 0, zeroCount = 0;

        for (int i = 0; i < N; i++) {
            int num = Integer.parseInt(br.readLine());
            if (num > 1) {
                plus.add(num);
            } else if (num == 1) {
                oneCount++;
            } else if (num == 0) {
                zeroCount++;
            } else {
                minus.add(num);
            }
        }

        // 양수는 내림차순, 음수는 오름차순 정렬
        plus.sort(Collections.reverseOrder());
        Collections.sort(minus);

        int sum = 0;

        // 양수 묶기
        for (int i = 0; i < plus.size(); i += 2) {
            if (i + 1 < plus.size()) {
                sum += plus.get(i) * plus.get(i + 1);
            } else {
                sum += plus.get(i);
            }
        }

        // 음수 묶기
        for (int i = 0; i < minus.size(); i += 2) {
            if (i + 1 < minus.size()) {
                sum += minus.get(i) * minus.get(i + 1);
            } else {
                // 0이 있으면 곱해서 없애고, 0이 없으면 그냥 더하기
                if (zeroCount == 0) {
                    sum += minus.get(i);
                }
            }
        }

        // 1은 무조건 더하기
        sum += oneCount;

        System.out.println(sum);
    }
}
```

## 전략 요약

- 1보다 큰 양수: 내림차순 정렬 → 큰 값끼리 곱
- 0 이하: 오름차순 정렬 → 작은 값끼리 곱
  - 짝수 개일 경우 모두 곱하고
  - 홀수 개일 경우 하나 남긴 후 나머지 곱
    - 남은 수가 0이면 버려도 좋음
- 1: 무조건 더함

## 시간복잡도

- 정렬: O(N log N)
- 연산: O(N)
- 총: O(N log N) → N ≤ 50이므로 충분히 빠름
