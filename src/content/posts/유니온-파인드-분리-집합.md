## 유니온 파인드(Union-Find)란?

**서로 연결되어 있는 것들**을 **하나의 그룹(집합)으로 묶어서** 관리하는 방식

- A와 B가 연결됨 → 한 그룹으로 묶음
- B와 C가 연결됨 → A, B, C가 같은 그룹이 됨
- D는 따로 떨어져 있음 → D는 또 다른 그룹

---

## 왜 필요한가?

<strong>분리 집합(Disjoint Set)</strong>을 효율적으로 관리하는 자료구조로, <strong>"두 원소가 같은 그룹에 속해 있는지 확인"</strong>하고, <strong>"두 그룹을 합치는 연산"</strong>을 빠르게 처리하기 위해 사용된다.

- **서로 연결되어 있는지**(예: 네트워크, 여행 가능 여부) 확인하는 문제에서 자주 등장
- **연결 여부를 탐색하지 않고도** 한 번의 Find로 판별 가능

---

## 유니온 파인드의 핵심 기능 2가지

1. **find(x)**
   - x가 속한 **집합의 대표(root)를 찾는다.**
   - 이때, **경로 압축**을 이용해 효율성을 높인다.
2. **union(x, y)**
   - **x가 속한 집합**과 **y가 속한 집합**을 **하나로 합친다.**
   - 이때, 랭크(또는 사이즈)를 기준으로 합치면 더 효율적이다.

---

## 예시 (멘토멘티 활동)

- 학생 5명이 있다고 가정
- 처음엔 다 각자 **자기 자신이 멘토임**

```
parent[1] = 1
parent[2] = 2
parent[3] = 3
...
```

- 이제 다음과 같이 **"2번이 3번이랑 같이 멘토멘티 활동해"** 라고 하면,

```java
union(2, 3)
```

- 둘이 **같은 그룹**으로 묶임
- 그리고 둘 중에 한 명을 다음과 같이 **멘토로 지정** (여기서는 2번을 3번의 멘토로 지정)

```
parent[3] = 2
```

## 유니온 파인드 기본 코드 (Java)

```java
int[] parent = new int[N];

// 초기화: 모든 노드가 자기 자신을 부모로 갖도록
for (int i = 0; i < N; i++) {
    parent[i] = i;
}

// Find: x의 루트 노드를 찾는다
int find(int x) {
    if (parent[x] != x) { // x의 루트가 x가 아닐 경우 (x가 루트가 아닐 경우)
        parent[x] = find(parent[x]); // 경로 압축: x의 루트의 루트를 찾는다
    }
    return parent[x];
}

// Union: 두 집합을 합친다
void union(int a, int b) {
    int rootA = find(a);
    int rootB = find(b);

    if (rootA != rootB) { // 둘이 다른 그룹인 경우
        parent[rootB] = rootA; // 한쪽 루트를 다른 쪽 루트로 연결
    }
}
```

## 핵심 포인트

- 시간복잡도: 거의 **O(1)** 에 가까운 속도 (아커만 함수 역함수 α(N) 수준)
- **N이 클 경우, 반복문 기반 find() 고려**
  - 재귀 기반 find() 구현 시 **스택 오버플로우** 발생 가능!
  - 스택 깊이 제한: 보통 수천~만 단위

```java
int find(int x) {
    while (x != parent[x]) { // x가 루트가 아닌 경우
        parent[x] = parent[parent[x]]; // x의 루트의 루트
        x = parent[x];
    }
    return x;
}
```
