<https://www.acmicpc.net/problem/1932>

```
        7
      3   8
    8   1   0
  2   7   4   4
4   5   2   6   5
```

위 그림은 크기가 5인 정수 삼각형의 한 모습이다.

맨 위층 7부터 시작해서 아래에 있는 수 중 하나를 선택하여 아래층으로 내려올 때, 이제까지 선택된 수의 합이 최대가 되는 경로를 구하는 프로그램을 작성하라. 아래층에 있는 수는 현재 층에서 선택된 수의 대각선 왼쪽 또는 대각선 오른쪽에 있는 것 중에서만 선택할 수 있다.

삼각형의 크기는 1 이상 500 이하이다. 삼각형을 이루고 있는 각 수는 모두 정수이며, 범위는 0 이상 9999 이하이다.

```java
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```

첫째 줄에 삼각형의 크기 n(1 ≤ n ≤ 500)이 주어지고, 둘째 줄부터 n+1번째 줄까지 정수 삼각형이 주어진다.

```java
30
```

첫째 줄에 합이 최대가 되는 경로에 있는 수의 합을 출력한다.

---

**아이디어**

- map[i][j] = 삼각형의 i행 j열의 수
- dp[i][j] = i행 j열에서 시작했을 때 아래로 내려가며 만들 수 있는 최대 합
  - dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + map[i][j]
  - 즉, 현재 위치에서 이동 가능한 아래의 두 위치 중 더 큰 값을 선택하여 현재 값과 더함
- 최종 정답은 삼각형의 꼭대기인 dp[1][1]

---

⏱️ **시간 복잡도**

- **O(n²)**
- n ≤ 500 이므로 가능

---

**Java 코드**

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());

        int[][] map = new int[n + 1][n + 1];

        for (int i = 1; i <= n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int j = 1; j <= i; j++) {
                map[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        int[][] dp = new int[n + 1][n + 1];

        for (int i = 1; i <= n; i++) {
            dp[n][i] = map[n][i];
        }

        for (int i = n - 1; i >= 1; i--) {
            for (int j = 1; j <= i; j++) {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i + 1][j + 1]) + map[i][j];
            }
        }

        System.out.println(dp[1][1]);
    }
}
```

## 만약 경로를 추적하려면?

- 경로 추적용 배열 path[][]를 추가
- dp[i][j]가 갱신될 때마다 → **path[i][j] = j or j+1** 기록 (왼쪽 또는 오른쪽)

```java
for (int i = n - 1; i >= 1; i--) {
    for (int j = 1; j <= i; j++) {
        if (dp[i + 1][j] > dp[i + 1][j + 1]) {
            dp[i][j] = dp[i + 1][j] + map[i][j];
            path[i][j] = j; // 아래쪽으로 이동
        } else {
            dp[i][j] = dp[i + 1][j + 1] + map[i][j];
            path[i][j] = j + 1; // 오른쪽 아래로 이동
        }
    }
}

StringBuilder sb = new StringBuilder();

int x = 1, y = 1;
sb.append(map[x][y]);

while (x < n) {
    y = path[x][y]; // 왼쪽 또는 오른쪽
    x++; // 아래로 이동
    sb.append(" -> ").append(map[x][y]);
}

System.out.println("경로: " + sb);
```

## 공간 복잡도를 O(n)으로 줄이기

- 기존의 dp[n+1][n+1] → O(n²) 공간 복잡도
- 하지만 DP 수행 시 **이전 행과 현재 행만 유지**하면 충분함
- 단, 경로 추적은 어려움

```java
int[] prev = new int[n + 1];

for (int i = 1; i <= n; i++) prev[i] = map[n][i]; // 마지막 행

for (int i = n - 1; i >= 1; i--) {
    int[] cur = new int[n + 1];
    for (int j = 1; j <= i; j++) {
        cur[j] = Math.max(prev[j], prev[j + 1]) + map[i][j];
    }
    prev = cur;
}

System.out.println(prev[1]);
```

## 탑다운 방식 (재귀 + 메모이제이션)

- **재귀적**으로 문제를 풀되, **이미 계산한 결과는 저장해두고 재활용**
- 단점: 재귀 호출 **오버헤드**

```java
dp = new int[n + 1][n + 1];
for (int[] row : dp) Arrays.fill(row, -1);
System.out.println(dfs(1, 1));

...

public int dfs(int x, int y) {
    if (x > n || y > x) return 0;

    if (dp[x][y] != -1) return dp[x][y]; // 이미 계산된 경우

    return dp[x][y] = Math.max(dfs(x + 1, y), dfs(x + 1, y + 1)) + map[x][y];
}
```
