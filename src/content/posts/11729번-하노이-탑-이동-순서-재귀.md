<https://www.acmicpc.net/problem/11729>

세 개의 장대가 있고 첫 번째 장대에는 반경이 서로 다른 n개의 원판이 쌓여 있다. 각 원판은 반경이 큰 순서대로 쌓여있다. 이제 수도승들이 다음 규칙에 따라 첫 번째 장대에서 세 번째 장대로 옮기려 한다.

1. 한 번에 한 개의 원판만을 다른 탑으로 옮길 수 있다.
2. 쌓아 놓은 원판은 항상 위의 것이 아래의 것보다 작아야 한다.

이 작업을 수행하는데 필요한 이동 순서를 출력하는 프로그램을 작성하라. 단, 이동 횟수는 최소가 되어야 한다.

아래 그림은 원판이 5개인 경우의 예시이다.

![11729번 하노이 탑 이동 순서 – 재귀](/images/tistory/228/img.png)

```java
3
```

첫째 줄에 첫 번째 장대에 쌓인 원판의 개수 N (1 ≤ N ≤ 20)이 주어진다.

```java
7
1 3
1 2
3 2
1 3
2 1
2 3
1 3
```

첫째 줄에 옮긴 횟수 K를 출력한다.

두 번째 줄부터 수행 과정을 출력한다. 두 번째 줄부터 K개의 줄에 걸쳐 두 정수 A B를 빈칸을 사이에 두고 출력하는데, 이는 A번째 탑의 가장 위에 있는 원판을 B번째 탑의 가장 위로 옮긴다는 뜻이다.

---

## 아이디어

- 핵심: "N개의 원판을 옮기는 과정은 **N-1개의 원판을 옮기는 과정**으로 분할할 수 있다"
- **N개**의 원판을 1번 장대에서 3번 장대로 옮기려면,
  1. **N-1개**의 원판을 **1번 → 2번(보조 장대)**으로 옮긴다
  2. **가장 큰 원판**(맨 아래 원판)을 **1번 → 3번**으로 옮긴다
  3. **N-1개**의 원판을 **2번(보조 장대) → 3번**으로 옮긴다

- **재귀 함수: hanoi(n, from, to, via)**
  - n==1일 때:
    - **from → to** 출력
  - 그 외:
    - hanoi(**n-1, from, via, to**) (from → via)
    - **from → to** 출력
    - hanoi(**n-1, via, to, from**) (via → to)
- 이동 횟수는 **(2^N) - 1**

---

## ⏱️ 시간 복잡도

- 이동 횟수 = 2^N - 1
- 따라서 전체 시간 복잡도는 **O(2^N)**
- N ≤ 20이므로 최악의 경우 약 10^6 → 충분히 가능

## Java 코드

```java
import java.io.*;

public class Main {
    static StringBuilder sb = new StringBuilder();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        // 이동 횟수 = 2^n - 1
        sb.append((1L << N) - 1).append('\n');

        hanoi(N, 1, 3, 2);

        System.out.println(sb);
    }

    static void hanoi(int n, int from, int to, int via) {
        if (n == 1) {
            sb.append(from).append(' ').append(to).append('\n');
            return;
        }
        // 1. n-1개를 from -> via
        hanoi(n - 1, from, via, to);

        // 2. 가장 큰 원판을 from -> to
        sb.append(from).append(' ').append(to).append('\n');

        // 3. n-1개를 via -> to
        hanoi(n - 1, via, to, from);
    }
}
```

## ⚠️ 오버플로우 주의: (1L << N) - 1

- 1 << N
  - 1이 **int** 타입 → 비트 연산 결과도 **int**
  - int는 **32비트**이므로 **N ≥ 31**이면 오버플로우 발생
- 1L << N
  - 1L이 **long** 타입 → 비트 연산 결과도 **long**
  - long은 **64비트**이므로 **N ≤ 63**까지 안전
