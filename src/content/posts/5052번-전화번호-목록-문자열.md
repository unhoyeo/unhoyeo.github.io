<https://www.acmicpc.net/problem/5052>

전화번호 목록이 주어진다. 이때, 이 목록이 일관성이 있는지 없는지를 구하는 프로그램을 작성하시오.

전화번호 목록이 일관성을 유지하려면, 한 번호가 다른 번호의 접두어인 경우가 없어야 한다.

예를 들어, 전화번호 목록이 아래와 같은 경우를 생각해보자

- 긴급전화: 911
- 상근: 97 625 999
- 선영: 91 12 54 26

이 경우에 선영이에게 전화를 걸 수 있는 방법이 없다. 전화기를 들고 선영이 번호의 처음 세 자리를 누르는 순간 바로 긴급전화가 걸리기 때문이다. 따라서, 이 목록은 일관성이 없는 목록이다.

```
2
3
911
97625999
91125426
5
113
12340
123440
12345
98346
```

첫째 줄에 테스트 케이스의 개수 t가 주어진다. (1 ≤ t ≤ 50) 각 테스트 케이스의 첫째 줄에는 전화번호의 수 n이 주어진다. (1 ≤ n ≤ 10000) 다음 n개의 줄에는 목록에 포함되어 있는 전화번호가 하나씩 주어진다. 전화번호의 길이는 길어야 10자리이며, 목록에 있는 두 전화번호가 같은 경우는 없다.

```java
NO
YES
```

각 테스트 케이스에 대해서, 일관성 있는 목록인 경우에는 YES, 아닌 경우에는 NO를 출력한다.

## 아이디어

- 총 n개의 번호가 있을 때,
  - 0번째 번호가 1번째 번호의 접두어인지 확인
  - 0번째, 1번째 번호가 2번째 번호의 접두어인지 확인
  - ...
- 2중 for문으로 i는 **1부터 n**까지, j는 **0부터 i - 1**까지 순차적으로 확인

## 첫 번째 시도 - 시간 초과

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine());

        StringBuilder sb = new StringBuilder();
        while (t-- > 0) {
            int n = Integer.parseInt(br.readLine());
            String[] phone = new String[n];

            for (int i = 0; i < n; i++) {
                phone[i] = br.readLine();
            }

            if (n == 1) {
                sb.append("YES").append('\n');
                continue;
            }

            boolean isConsistent = true;
            for (int i = 1; i < phone.length; i++) {
                for (int j = 0; j < i; j++) {
                    if (isPrefixOf(phone[j], phone[i])) { // j가 i의 접두어인가요?
                        isConsistent = false;
                        break;
                    }
                }
                if (!isConsistent) break;
            }

            sb.append(isConsistent ? "YES" : "NO").append('\n');
        }

        System.out.println(sb);
    }

    static boolean isPrefixOf(String prefix, String s) {
        int prefixLen = prefix.length();
        int sLen = s.length();

        if (prefixLen > sLen) return false;
        if (prefixLen == sLen) {
            return prefix.equals(s);
        }

        if (prefix.equals(s.substring(0, prefixLen))) return true;

        return false;
    }
}
```

- 접두어 확인 절차가 비효율적으로 진행된 것 같다.
- **사전순으로 정렬한 후, 이웃한 번호끼리 접두어 관계인지 검사**하면 훨씬 더 효율적일 것이다.
- PriorityQueue를 활용해서 풀어보자.

## 두 번째 시도 - 성공

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine());

        StringBuilder sb = new StringBuilder();
        while (t-- > 0) {
            PriorityQueue<Phone> pq = new PriorityQueue<>();
            int n = Integer.parseInt(br.readLine());

            for (int i = 0; i < n; i++) {
                pq.add(new Phone(br.readLine()));
            }

            if (n == 1) {
                sb.append("YES").append('\n');
                continue;
            }

            boolean isConsistent = true;
            Phone first = pq.poll();

            while (!pq.isEmpty()) {
                Phone second = pq.poll();
                if (isPrefixOf(first.phone, second.phone)) {
                    isConsistent = false;
                    break;
                }
                first = second;
            }

            sb.append(isConsistent ? "YES" : "NO").append('\n');
        }

        System.out.println(sb);
    }

    static boolean isPrefixOf(String prefix, String s) {
        int prefixLen = prefix.length();
        int sLen = s.length();

        if (prefixLen > sLen) return false;
        if (prefixLen == sLen) {
            return prefix.equals(s);
        }

        if (prefix.equals(s.substring(0, prefixLen))) return true;
        return false;
    }

    static class Phone implements Comparable<Phone> {
        String phone;

        public Phone(String phone) {
            this.phone = phone;
        }

        public int compareTo(Phone o) {
            return this.phone.compareTo(o.phone);
        }
    }
}
```

- 통과는 했지만, 같은 로직을 더 짧은 코드로 가능하다.
- 정렬은 **Arrays.sort()** 메서드, 접두어 관계 검사는 **String.startsWith()** 메서드를 이용하면 된다.

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine());

        StringBuilder sb = new StringBuilder();
        while (t-- > 0) {
            int n = Integer.parseInt(br.readLine());
            String[] numbers = new String[n];

            for (int i = 0; i < n; i++) {
                numbers[i] = br.readLine();
            }

            // 문자열 정렬: 접두어가 앞에 오도록
            Arrays.sort(numbers);

            boolean isConsistent = true;

            for (int i = 0; i < n - 1; i++) {
                // 현재 번호가 다음 번호의 접두어인지 확인
                if (numbers[i + 1].startsWith(numbers[i])) {
                    isConsistent = false;
                    break;
                }
            }

            sb.append(isConsistent ? "YES" : "NO").append('\n');
        }

        System.out.println(sb);
    }
}
```

- Arrays.sort() 메서드는 PriorityQueue에 비해 코드가 간결하다는 장점이 있지만, 속도가 상대적으로 느리다.
- 현재 코드도 충분하지만, 더 빠른 코드는 다음과 같다.

## 다른 방법: Trie(트라이) 구조 사용

- 전화번호를 하나씩 삽입하면서 다음을 체크
  - 이미 경로 중간에 다른 번호가 끝나 있거나,
  - 현재 번호가 끝난 후에도 다른 번호가 더 붙어 있다면
  - **일관성 위반!**

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine());

        while (t-- > 0) {
            int n = Integer.parseInt(br.readLine());
            String[] numbers = new String[n];

            for (int i = 0; i < n; i++) {
                numbers[i] = br.readLine();
            }

            Trie trie = new Trie();
            boolean isConsistent = true;

            for (String number : numbers) {
                if (!trie.insert(number)) {
                    isConsistent = false;
                    break;
                }
            }

            System.out.println(isConsistent ? "YES" : "NO");
        }
    }

    static class TrieNode {
        Map<Character, TrieNode> children = new HashMap<>();
        boolean isEnd;  // 하나의 번호가 끝나는 지점

        public TrieNode() {
            this.isEnd = false;
        }
    }

    static class Trie {
        TrieNode root = new TrieNode();

        // 번호 삽입 메서드, 중복 또는 접두어 관계 확인
        boolean insert(String number) {
            TrieNode current = root;
            for (int i = 0; i < number.length(); i++) {
                char c = number.charAt(i);

                // 경로가 없으면 새로 추가
                current.children.putIfAbsent(c, new TrieNode());
                current = current.children.get(c);

                // 중간에 다른 번호가 끝난 경우 → 접두어임
                if (current.isEnd) {
                    return false;
                }
            }

            // 현재 번호가 끝나는 위치에 이미 자식 노드가 있으면 → 현재 번호가 다른 번호의 접두어
            if (!current.children.isEmpty()) {
                return false;
            }

            current.isEnd = true;  // 현재 번호 종료 지점 표시
            return true;
        }
    }
}
```
