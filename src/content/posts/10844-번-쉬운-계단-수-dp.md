<https://www.acmicpc.net/problem/10844>

45656이란 수를 보자.

이 수는 인접한 모든 자리의 차이가 1이다. 이런 수를 계단 수라고 한다.

N이 주어질 때, 길이가 N인 계단 수가 총 몇 개 있는지 구해보자. 0으로 시작하는 수는 계단수가 아니다.

```java
2
```

첫째 줄에 N이 주어진다. N은 1보다 크거나 같고, 100보다 작거나 같은 자연수이다.

```java
17
```

첫째 줄에 정답을 **1,000,000,000으로 나눈 나머지**를 출력한다.

---

? **아이디어**

- 계단 수의 조건:
  - 인접한 자리의 숫자 차이가 1이어야 함
  - 단, 맨 앞이 0이면 안 됨
- 예를 들어,
  - 1 다음은 0 또는 2만 가능
  - 2 다음은 1 또는 3만 가능
  - 이런 식으로 계속 이어짐
  - 즉, **"마지막 숫자"**에 따라 다음 숫자가 정해진다!
  - 다음 숫자는 **(마지막 숫자 - 1)** 또는 **(마지막 숫자 + 1)**
- **dp[len][d] = 길이가 len이고, 마지막 숫자가 d인 계단 수의 개수**
  - 길이가 1일 때는 마지막 숫자가 0인 경우만 제외하고 1로 초기화
- 점화식:
  - dp[len][d] = **dp[len][d-1]** + **dp[len][d+1]**
  - 단, 마지막 숫자가 0 또는 9일 경우 인덱스 범위를 벗어나므로, 적절한 조치 필요
- ⚠️ 주의점:
  - 마지막뿐만 아니라 **모든 중간 연산에서 모듈러 연산**을 해줘야 정답이 보장됨
  - 안 그러면 long을 사용하더라도 오버플로우 발생

---

⏱️ **시간 복잡도**

- 길이 범위: 1 ~ N
- 각 길이마다 10번 연산: **O(N \* 10)**
- N ≤ 100이므로, 가능

---

? **Java 코드**

```java
import java.io.*;

public class Main {
    static final int MOD = 1_000_000_000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        // dp[len][d]: 길이가 len이고, 마지막 숫자가 d일 때의 경우의 수
        int[][] dp = new int[N + 1][10];

        for (int d = 1; d <= 9; d++) {
            dp[1][d] = 1;
        }

        for (int len = 2; len <= N; len++) {
            for (int d = 0; d <= 9; d++) {
                if (d > 0) dp[len][d] += dp[len - 1][d - 1];
                if (d < 9) dp[len][d] += dp[len - 1][d + 1];
                dp[len][d] %= MOD;
            }
        }

        int result = 0;
        for (int d = 0; d <= 9; d++) {
            result = (result + dp[N][d]) % MOD;
        }

        System.out.println(result);
    }
}
```

? **개선 아이디어**

- 배열 없이 DFS + 메모이제이션 방식으로도 풀이 가능
- dp[i]는 dp[i-1]만 참조하므로, 2차원 dp[][] 대신 1차원 배열 2개 prev[], cur[]만 사용해도 풀이 가능 (공간 최적화)

```java
for (int i = 2; i <= N; i++) {
    int[] cur = new int[10];

    for (int j = 0; j <= 9; j++) {
        if (j > 0) cur[j] += prev[j - 1];
        if (j < 9) cur[j] += prev[j + 1];
        cur[j] %= MOD; // 덧셈할 때마다 모듈러 연산
    }

    prev = cur;
}
```
