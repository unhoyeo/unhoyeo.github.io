<https://www.acmicpc.net/problem/20055>

이 문제는 시뮬레이션 유형으로, 문제에서 제시한 4가지 단계를 순서대로 정확하게 구현하는 것이 핵심이다.

컨베이어 벨트가 **원형으로 연결**되어 있으므로 **배열을 회전**시키거나 **인덱스를 조절**하는 로직이 필요하다.

## 1. 데이터 구조

- durability: 각 칸의 내구도를 저장하는 배열 (크기: 2N)
- hasRobot: 로봇이 해당 칸에 있는지 여부를 저장하는 배열 (크기: N)
  - 로봇은 위쪽 벨트(0 ~ N - 1 인덱스)에만 존재할 수 있으므로 N 크기면 충분하다.

## 2. 회전

- 내구도 배열과 로봇 배열을 모두 **시계 방향으로 한 칸 이동**시킨다.
- ⚠️ 주의: 로봇이 <strong>내리는 위치(N - 1 인덱스)</strong>에 도달하면 그 즉시 내려야 한다.

## 3. 로봇 이동

- 가장 먼저 올라간 로봇부터 이동해야 하므로, 내리는 위치와 가장 가까운 **N - 2 인덱스**부터 역순으로 탐색한다.
- 이동 조건: 다음 칸에 로봇이 없고, 다음 칸의 내구도가 1 이상이어야 한다.
- 이동 후 내구도를 1 감소시키고, 내리는 위치에 도달하면 즉시 내린다.

## 4. 로봇 올리기

- 올리는 위치(0 인덱스)의 내구도가 0이 아니면 로봇을 올리고 내구도를 1 감소시킨다.

## 5. 종료 조건 확인

- 내구도가 0인 칸의 개수가 K개 이상이면 종료한다.

## 틀린 풀이

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, K;
    static int[] durability;
    static boolean[] hasRobot;
    static int start, end;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        K = Integer.parseInt(st.nextToken());

        durability = new int[2 * N + 1];
        hasRobot = new boolean[2 * N + 1];

        st = new StringTokenizer(br.readLine());
        for (int i = 1; i <= 2 * N; i++) {
            durability[i] = Integer.parseInt(st.nextToken());
        }

        start = 1;
        end = N;

        int answer = 0;
        while (true) {
            answer++;

            // 1. 벨트와 로봇 회전
            rotate();

            // 2. 로봇 이동
            moveRobots();

            // 3. 로봇 올리기
            if (durability[start] > 0) {
                hasRobot[start] = true;
                durability[start]--;
            }

            // 4. 내구도가 0인 칸의 개수가 K개 이상이면 종료
            if (countZero() >= K) {
                break;
            }
        }

        System.out.println(answer);
    }

    static void rotate() {
        start = getIndex(start - 1);
        end = getIndex(end - 1);

        if (hasRobot[end]) {
            hasRobot[end] = false;
        }
    }

    static int getIndex(int idx) {
        if (idx < 1) {
            return 2 * N + idx;
        }
        if (idx > 2 * N) {
            return idx - 2 * N;
        }
        return idx;
    }

    static void moveRobots() {
        for (int i = 1; i <= N - 1; i++) {
            moveRobotIfPossible(end - i);
        }
    }

    static void moveRobotIfPossible(int i) {
        int cur = getIndex(i);
        int next = getIndex(cur + 1);

        if (hasRobot[next] || durability[next] < 1) { // ❌ 여기가 문제!
            return;
        }

        hasRobot[cur] = false;
        hasRobot[next] = true;
        durability[next]--;

        if (hasRobot[end]) {
            hasRobot[end] = false;
        }
    }

    private static int countZero() {
        int count = 0;
        for (int i = 1; i <= 2 * N; i++) {
            if (durability[i] == 0) {
                count++;
            }
        }
        return count;
    }
}
```

## 틀린 이유

- moveRobotIfPossible() 메서드에서 **현재 칸에 로봇이 있는지 여부**를 확인하고 있지 않기 때문이다.
- 만약 현재 칸에 로봇이 존재하지 않으면 아무 행동도 하면 안 된다.

- 인덱스를 이동시키는 것이 아닌, 배열을 이동시키는 풀이는 다음과 같다.

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, K;
    static int[] durability;
    static boolean[] hasRobot;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        K = Integer.parseInt(st.nextToken());

        durability = new int[2 * N];
        hasRobot = new boolean[N];

        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < 2 * N; i++) {
            durability[i] = Integer.parseInt(st.nextToken());
        }

        int answer = 0;
        while (true) {
            answer++;

            // 1. 벨트와 로봇 회전
            rotate();

            // 2. 로봇 이동
            moveRobots();

            // 3. 로봇 올리기
            if (durability[0] > 0) {
                hasRobot[0] = true;
                durability[0]--;
            }

            // 4. 내구도가 0인 칸의 개수가 K개 이상이면 종료
            if (countZeros() >= K) {
                break;
            }
        }

        System.out.println(answer);
    }

    static void rotate() {
        // 내구도 배열 회전
        int temp = durability[2 * N - 1]; // last
        for (int i = 2 * N - 1; i >= 1; i--) {
            durability[i] = durability[i - 1];
        }
        durability[0] = temp;

        // 로봇 배열 회전
        for (int i = N - 1; i >= 1; i--) {
            hasRobot[i] = hasRobot[i - 1];
        }
        hasRobot[0] = false; // 새로 들어온 칸
        hasRobot[N - 1] = false; // 내리는 위치 도달 시 즉시 내림
    }

    static void moveRobots() {
        for (int i = N - 2; i >= 0; i--) {
            if (!hasRobot[i] || hasRobot[i + 1] || durability[i + 1] < 1) {
                continue;
            }
            hasRobot[i] = false;
            hasRobot[i + 1] = true;
            durability[i + 1]--;
        }
        hasRobot[N - 1] = false; // 내리는 위치 도달 시 즉시 내림
    }

    static int countZeros() {
        int count = 0;
        for (int val : durability) {
            if (val == 0) {
                count++;
            }
        }
        return count;
    }
}
```
