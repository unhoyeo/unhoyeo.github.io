MySQL의 데이터 형식(Data Types)은 크게 **문자형, 숫자형, 날짜/시간형**으로 나뉘며, 각 데이터 타입은 용도와 저장 효율성에 따라 선택됩니다.

---

## 1. 문자열 타입 (String Types)

## 타입설명

|  |  |
| --- | --- |
| CHAR(n) | 고정 길이 문자열. n자보다 짧으면 공백으로 채움 (공간 낭비 가능) |
| VARCHAR(n) | 가변 길이 문자열. 최대 n자까지 저장 가능 (최대 65,535 바이트, 실제 저장은 인코딩과 함께 계산됨) |
| TEXT | 최대 65,535자 저장 가능. 긴 텍스트에 적합. 인덱싱 제한 존재 |
| TINYTEXT | 최대 255자 |
| MEDIUMTEXT | 최대 16MB |
| LONGTEXT | 최대 4GB |

> ✅ 일반 텍스트는 VARCHAR, 긴 텍스트는 TEXT 계열 사용

---

## 2. 숫자형 타입 (Numeric Types)

*정수형*

## 타입크기 (byte)값 범위 (SIGNED 기준)

|  |  |  |
| --- | --- | --- |
| TINYINT | 1 byte | -128 ~ 127 |
| SMALLINT | 2 byte | -32,768 ~ 32,767 |
| MEDIUMINT | 3 byte | -8,388,608 ~ 8,388,607 |
| INT / INTEGER | 4 byte | -2^31 ~ 2^31-1 |
| BIGINT | 8 byte | -2^63 ~ 2^63-1 |

> UNSIGNED 옵션을 사용하면 양수만 저장되며 범위가 두 배 증가.

*실수형*

## 타입설명

|  |  |
| --- | --- |
| FLOAT(m,d) | 소수점 이하 d자리까지 저장, m은 전체 자릿수 |
| DOUBLE(m,d) | FLOAT보다 정밀도가 높음 |
| DECIMAL(m,d) | 고정 소수점, 금융 계산 등에 사용 (정확도 중요 시) |

---

## 3. 날짜 및 시간 타입 (Date and Time Types)

## 타입설명

|  |  |
| --- | --- |
| DATE | ‘YYYY-MM-DD’ 형식의 날짜 (예: 2024-12-25) |
| TIME | ‘HH:MM:SS’ 형식의 시간 (예: 14:30:00) |
| DATETIME | 날짜 + 시간 (예: 2024-12-25 14:30:00), 타임존 없음 |
| TIMESTAMP | 날짜 + 시간, 타임존 반영 가능 |
| YEAR | 연도 (예: 2024) |

---

## 주의사항

- VARCHAR(255)는 UTF-8 인코딩 시 **최대 765바이트**까지 필요할 수 있음 (문자 하나가 최대 3바이트).
- TEXT 계열은 **인덱스 제한**이 있음 → 검색 성능이 떨어질 수 있음.
- 숫자형은 크기에 따라 **공간 및 성능 차이**가 있음 → 적절한 범위 선택이 중요.
- 날짜형은 시간대(Timezone) 반영 여부에 따라 DATETIME vs TIMESTAMP 구분 필요.
