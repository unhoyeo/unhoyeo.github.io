수빈이가 세상에서 가장 좋아하는 것은 소수이고, 취미는 소수를 가지고 노는 것이다. 요즘 수빈이가 가장 관심있어 하는 소수는 7331이다.

7331은 소수인데, 신기하게도 733도 소수이고, 73도 소수이고, 7도 소수이다. 즉, 왼쪽부터 1자리, 2자리, 3자리, 4자리 수 모두 소수이다! 수빈이는 이런 숫자를 신기한 소수라고 이름 붙였다.

수빈이는 N자리의 숫자 중에서 어떤 수들이 신기한 소수인지 궁금해졌다. N이 주어졌을 때, 수빈이를 위해 N자리 신기한 소수를 모두 찾아보자.

```java
4
```

첫째 줄에 N(1 ≤ N ≤ 8)이 주어진다.

```java
2333
2339
2393
2399
2939
3119
3137
3733
3739
3793
3797
5939
7193
7331
7333
7393
```

N자리 수 중에서 신기한 소수를 오름차순으로 정렬해서 한 줄에 하나씩 출력한다.

---

## 아이디어

- 한 자리 소수(2, 3, 5, 7)에서 DFS 시작
  - **5를 제외한 홀수(1, 3, 7, 9)** 중 하나를 다음 자리에 붙임 → **짝수나 5로 끝나는 수**는 소수가 될 수 없음
  - 매 단계마다 **현재 수가 소수인지 판별**하고, 소수라면 다음 자리 숫자를 붙여서 재귀 호출
  - 깊이가 N이 되면 출력
- 소수 판별:
  - 소수 = **"1과 자기 자신만을 약수로 가지는 1보다 큰 자연수"**
  - **1**은 소수가 아니고, **2, 3**은 소수
  - 그 뒤부터는 해당 수가 **특정 수로 나누어 떨어지는지** 확인해야 함 (나누어 떨어지면 소수가 아님)
    - 2를 제외한 짝수는 무조건 소수가 아님 → **짝수는 2만** 시도하고, **그 뒤부터는 홀수만** 시도하기
    - 해당 수의 제곱근보다 큰 숫자는 나누어 떨어질 수가 없음 → **해당 수의 제곱근까지만** 시도하기

---

## ⏱️ 시간 복잡도

- 깊이: N (최대 8)
- 분기: 약 4~5
- 소수 판별: **O(√num)**
- 전체: **O(5^N × √(10^N))**, 하지만 가지치기 때문에 빠름

---

## Java 코드

```java
import java.io.*;

public class Main {
    static int N;
    static StringBuilder result = new StringBuilder();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        N = Integer.parseInt(br.readLine());

        for (int i : new int[]{2, 3, 5, 7}) {
            dfs(1, i);
        }

        System.out.println(result);
    }

    static void dfs(int depth, int num) {
        if (depth == N) {
            result.append(num).append('\n');
            return;
        }
        for (int i : new int[]{1, 3, 7, 9}) { // 짝수, 5 제외
            int next = num * 10 + i;
            if (isPrime(next)) {
                dfs(depth + 1, next);
            }
        }
    }

    static boolean isPrime(int num) {
        if (num < 2) return false;
        if (num == 2 || num == 3) return true;
        if (num % 2 == 0) return false;
        for (int i = 3; i <= Math.sqrt(num); i += 2) { // 3부터 √num까지의 홀수
            if (num % i == 0) return false;
        }
        return true;
    }
}
```
