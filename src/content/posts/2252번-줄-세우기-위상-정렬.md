<https://www.acmicpc.net/problem/2252>

N명의 학생들을 키 순서대로 줄을 세우려고 한다. 각 학생의 키를 직접 재서 정렬하면 간단하겠지만, 마땅한 방법이 없어서 두 학생의 키를 비교하는 방법을 사용하기로 하였다. 그나마도 모든 학생들을 다 비교해 본 것이 아니고, 일부 학생들의 키만을 비교해 보았다.

일부 학생들의 키를 비교한 결과가 주어졌을 때, 줄을 세우는 프로그램을 작성하시오.

```java
3 2
1 3
2 3
```

첫째 줄에 N(1 ≤ N ≤ 32,000), M(1 ≤ M ≤ 100,000)이 주어진다. M은 키를 비교한 횟수이다. 다음 M개의 줄에는 키를 비교한 두 학생의 번호 A, B가 주어진다. 이는 학생 A가 학생 B의 앞에 서야 한다는 의미이다.

학생들의 번호는 1번부터 N번이다.

```java
1 2 3
```

첫째 줄에 학생들을 앞에서부터 줄을 세운 결과를 출력한다. 답이 여러 가지인 경우에는 아무거나 출력한다.

## ❌ 틀린 아이디어

- 키가 큰 사람은 가중치 1, 키가 작은 사람은 가중치 0으로 시작
- 체크 여부를 리스트로 관리
- 그 다음 줄부터
  - 둘 다 체크되지 않았다면, 키가 큰 사람은 가중치 1, 키가 작은 사람은 가중치 0
  - 키가 큰 사람이 체크되었다면, 키가 작은 사람은 가중치 키가 큰 사람의 가중치 -1
  - 키가 작은 사람이 체크되었다면, 키가 큰 사람은 가중치 키가 작은 사람의 가중치 +1
- 가중치를 기준 우선순위 큐로 학생들을 줄 세우기

```java
import java.io.*;
import java.util.*;

class Main {
    static int N, M;
    static List<Integer> list = new ArrayList<>();
    static PriorityQueue<Node> pq = new PriorityQueue<>();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken()); // 학생 수
        M = Integer.parseInt(st.nextToken()); // 키 비교 횟수

        for (int i = 0; i < M; i++) {
            st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());

            // 키: a < b
            if (!list.contains(a) && !list.contains(b)) {
                list.add(a);
                list.add(b);
                pq.add(new Node(a, 0));
                pq.add(new Node(b, 1));
            } else if (list.contains(a)) {
                list.add(b);
                pq.add(new Node(b, a + 1));
            } else {
                list.add(a);
                pq.add(new Node(a, b - 1));
            }
        }

        StringBuilder sb = new StringBuilder();
        while (!pq.isEmpty()) {
            Node cur = pq.poll();
            sb.append(cur.num).append(' ');
        }

        System.out.println(sb);
    }

    static class Node implements Comparable<Node> {
        int num, weight;

        public Node(int num, int weight) {
            this.num = num;
            this.weight = weight;
        }

        public int compareTo(Node o) {
            return this.weight - o.weight;
        }
    }
}
```

- list.contains() 메서드를 반복적으로 수행하면서 시간이 초과된거 같다.
- 방문 여부를 리스트 대신 배열로, 큐 대신 맵으로 다시 해보자.

```java
import java.io.*;
import java.util.*;

class Main {
    static int N, M;
    static Map<Integer, Integer> map = new HashMap<>();
    static boolean[] visited;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken()); // 학생 수
        M = Integer.parseInt(st.nextToken()); // 키 비교 횟수

        visited = new boolean[N + 1];

        for (int i = 0; i < M; i++) {
            st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());

            // 키: a < b
            if (!visited[a] && !visited[b]) {
                visited[a] = true;
                visited[b] = true;
                map.put(a, 0);
                map.put(b, 1);
                continue;
            }

            if (!visited[a] && visited[b]) {
                visited[a] = true;
                map.put(a, map.get(b) - 1);
                continue;
            }

            if (visited[a] && !visited[b]) {
                visited[b] = true;
                map.put(b, map.get(a) + 1);
                continue;
            }

            // 둘 다 이미 방문
            Integer bv = map.get(b);
            if (map.get(a) >= bv) {
                map.put(a, bv - 1);
            }
        }

        ArrayList<Map.Entry<Integer, Integer>> entryList = new ArrayList<>(map.entrySet());
        entryList.sort(Map.Entry.comparingByValue());

        StringBuilder sb = new StringBuilder();
        for (Map.Entry<Integer, Integer> entry : entryList) {
            sb.append(entry.getKey()).append(' ');
        }

        System.out.println(sb);
    }
}
```

- 숨겨진 테스트 케이스에서 막혔다.
- 내가 모르는 알고리즘을 사용해야 할 것 같다.

> 이 문제는 <strong>위상 정렬(Topological Sort)</strong>을 적용해야 하는 문제였다.

## 아이디어

- 각 학생은 **정점**으로, 각 키 비교 관계(A는 B보다 앞)는 **방향이 있는 간선**으로 해석
- 즉, **A → B** 라는 방향 그래프가 주어졌을 때, 가능한 정렬 순서를 구하는 문제
- **사이클이 없고, 모든 노드를 정렬**할 수 있어야 하므로 위상 정렬이 적합

## 자료 구조 및 알고리즘

- **진입 차수 배열 (int[] inDegree)**: 각 노드로 들어오는 간선 수
- **인접 리스트 (List&lt;List&lt;Integer>>)**: 연결된 노드 정보
- **Queue&lt;Integer>**: 진입 차수가 0인 노드를 넣고 처리

## ⏱️ 시간 복잡도

- **O(N + M)**
- N: 정점 수 (학생 수)
- M: 간선 수 (키 비교 수)

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, M;
    static List<List<Integer>> graph = new ArrayList<>();
    static int[] inDegree;
    static StringBuilder sb = new StringBuilder();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        M = Integer.parseInt(st.nextToken());

        inDegree = new int[N + 1]; // 어떤 정점으로 들어오는 간선의 수
        // 즉, "나보다 먼저 처리돼야 할 작업 수"

        // 인접 리스트 초기화
        for (int i = 0; i < N + 1; i++) {
            graph.add(new ArrayList<>());
        }

        // 그래프 입력 및 진입 차수 계산
        for (int i = 0; i < M; i++) {
            st = new StringTokenizer(br.readLine());
            int A = Integer.parseInt(st.nextToken());
            int B = Integer.parseInt(st.nextToken());

            graph.get(A).add(B);
            inDegree[B]++;
        }

        topologicalSort();
        System.out.println(sb);
    }

    static void topologicalSort() {
        Queue<Integer> q = new ArrayDeque<>();

        // 진입 차수가 0인 정점부터 처리 (바로 처리해도 되는 작업)
        for (int i = 1; i <= N; i++) {
            if (inDegree[i] == 0) {
                q.add(i);
            }
        }

        while (!q.isEmpty()) {
            int now = q.poll();
            sb.append(now).append(' ');

            // 해당 정점을 제거하고, 연결된 다음 정점의 진입 차수를 줄임 (선행 작업이 끝났다는 뜻)
            for (int next : graph.get(now)) {
                inDegree[next]--;
                // 다시 진입 차수가 0인 정점이 생기면 큐에 넣고 반복
                if (inDegree[next] == 0) {
                    q.add(next);
                }
            }
        }
    }
}
```

## 위상 정렬이란?

> **"어떤 작업들이 순서에 따라 진행되어야 할 때, 그 순서를 정하는 알고리즘"**

- 주로 **방향 그래프**에서 사용된다.
  - 정점(node): **작업** (학생의 키)
  - 간선(edge): **순서** (B보다 A가 먼저 와야 함)
- 즉, 정점 **A, B**와, 간선 **A → B**

---

## 위상 정렬의 동작 방식

- **A → B 간선일 경우, B의 진입 차수(어떤 정점으로 들어오는 간선의 수)를 1 늘림**
  - 즉, "B보다 먼저 처리해야 하는 작업의 수"를 1개 늘림
- **간선 입력이 끝난 후, 진입 차수가 0인 정점부터 큐에 넣음**
  - 바로 처리해도 되는 작업이기 때문에 먼저 처리함
- **큐에서 정점을 꺼내서 처리하고, 해당 정점에 연결된 다른 정점들의 진입 차수를 1 줄임**
  - 즉, 먼저 처리해야 하는 작업 1개가 이제 끝났다는 뜻
- **다시 진입 차수가 0인 정점이 생기면, 큐에 넣고 반복**

```
1: 1
```

```java
큐: [3, 4]
```

## ✔️ 큐에서 정점을 꺼내서 출력하고, 해당 정점에 연결된 다른 정점의 진입 차수 1 줄이기

```java
큐: [3, 4]

3을 꺼냄
출력: [3]

```

## ✔️ 진입 차수가 0이 된 정점을 다시 큐에 넣고 반복

```java
진입 차수가 0이된 정점 1을 큐에 넣음
큐: [4, 1]

4를 꺼냄
출력: [3, 4]
4에 연결된 정점은 2 → 2의 진입 차수 감소 (1에서 0이 됨)
진입 차수가 0이된 정점 2를 큐에 넣음
큐: [1, 2]

1을 꺼냄
출력: [3, 4, 1]
1에 연결된 정점 없음
큐: [2]

2를 꺼냄
출력: [3, 4, 1, 2]
2에 연결된 정점 없음
```

## 2025. 06. 20. 복습 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());

        int[] inDegree = new int[N + 1];
        List<List<Integer>> graph = new ArrayList<>();

        for (int i = 0; i < N + 1; i++) {
            graph.add(new ArrayList<>());
        }

        for (int i = 0; i < M; i++) {
            st = new StringTokenizer(br.readLine());
            int A = Integer.parseInt(st.nextToken());
            int B = Integer.parseInt(st.nextToken());

            graph.get(A).add(B);
            inDegree[B]++;
        }

        Queue<Integer> q = new LinkedList<>();
        StringBuilder sb = new StringBuilder();

        for (int i = 1; i <= N; i++) {
            if (inDegree[i] == 0) {
                q.add(i);
            }
        }

        while (!q.isEmpty()) {
            int cur = q.poll();
            sb.append(cur).append(' ');

            for (int next : graph.get(cur)) {
                inDegree[next]--;
                if (inDegree[next] == 0) {
                    q.add(next);
                }
            }
        }

        System.out.println(sb);
    }
}
```
