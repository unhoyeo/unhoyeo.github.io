<https://www.acmicpc.net/problem/1339>

민식이는 수학학원에서 단어 수학 문제를 푸는 숙제를 받았다.

단어 수학 문제는 N개의 단어로 이루어져 있으며, 각 단어는 알파벳 대문자로만 이루어져 있다. 이때, 각 알파벳 대문자를 0부터 9까지의 숫자 중 하나로 바꿔서 N개의 수를 합하는 문제이다. 같은 알파벳은 같은 숫자로 바꿔야 하며, 두 개 이상의 알파벳이 같은 숫자로 바뀌어지면 안 된다.

예를 들어, GCF + ACDEB를 계산한다고 할 때, A = 9, B = 4, C = 8, D = 6, E = 5, F = 3, G = 7로 결정한다면, 두 수의 합은 99437이 되어서 최대가 될 것이다.

N개의 단어가 주어졌을 때, 그 수의 합을 최대로 만드는 프로그램을 작성하시오.

```html
2
GCF
ACDEB
```

첫째 줄에 단어의 개수 N(1 ≤ N ≤ 10)이 주어진다. 둘째 줄부터 N개의 줄에 단어가 한 줄에 하나씩 주어진다. 단어는 알파벳 대문자로만 이루어져있다. 모든 단어에 포함되어 있는 알파벳은 최대 10개이고, 수의 최대 길이는 8이다. 서로 다른 문자는 서로 다른 숫자를 나타낸다.

```html
99437
```

첫째 줄에 주어진 단어의 합의 최댓값을 출력한다.

---

## 아이디어

- 가장 높은 자리의 수가 9, 그 다음 높은 자리의 수가 8 ... 이런 식으로 되어야 최댓값이 될 것이다.
- N개의 단어를 입력받아서 힙에 넣고, 그 중 **단어의 길이가 가장 긴 단어**를 선택한다. → **최대 힙**
- 해당 단어의 **0번째 글자**를 빼서 다음과 같이 처리한다.
  - 이미 지정된 글자라면, 지정된 숫자로 바꾼다.
  - 지정된 글자가 아닌 경우, num(초기값: 9)으로 지정하고, num을 1 줄인다.
- 길이가 줄어든 글자를 다시 힙에 넣고, 해당 과정을 반복한다.
- 모든 글자가 0~9로 지정이 완료되었다면, 이제 원본 단어를 하나씩 숫자로 바꾸고, 합을 구한다.

## 첫 번째 시도 - 실패

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());
        String[] words = new String[N];

        PriorityQueue<Word> pq = new PriorityQueue<>();
        Map<Character, Integer> map = new HashMap<>();

        for (int i = 0; i < N; i++) {
            String word = br.readLine();
            words[i] = word;
            pq.add(new Word(word));
        }

        int num = 9;
        while (!pq.isEmpty()) {
            String word = pq.poll().word;
            char c = word.charAt(0);
            if (!map.containsKey(c)) {
                map.put(c, num--);
            }
            if (word.length() > 1) {
                pq.add(new Word(word.substring(1)));
            }
        }

        int sum = 0;
        for (String word : words) {
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < word.length(); i++) {
                char c = word.charAt(i);
                Integer n = map.get(c);
                sb.append(n);
            }
            sum += Integer.parseInt(sb.toString());
        }

        System.out.println(sum);
    }

    static class Word implements Comparable<Word> {
        String word;

        Word(String word) {
            this.word = word;
        }

        public int compareTo(Word o) {
            return o.word.length() - this.word.length();
        }
    }
}
```

- 주어진 테스트 케이스는 통과했지만 숨겨진 테스트 케이스에서 틀렸다.
- 단순히 앞에 나오는 순서대로 높은 숫자를 지정하는 것은 오류가 있을 수 있다.
- 예를 들어 ABB, BAA, BAA에서 A를 9로 할 경우 2786이지만, B를 9로 할 경우 2875이다.
- 결국 모든 단어들을 다 고려해서 **총 가중치**로 계산을 해야 한다.
- 위에서 A는 100 + 10 + 1 + 10 + 1 = **122**, B는 10 + 1+ 100 + 100 = **211**이므로, B를 더 높은 숫자로 지정해야 한다.
- A = 122, B = 211 → **211\*9 + 122\*8 = 2875**

## 올바른 풀이

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        String[] words = new String[N];
        int[] weights = new int[26]; // A ~ Z까지의 가중치

        for (int i = 0; i < N; i++) {
            words[i] = br.readLine();
            int len = words[i].length();

            for (int j = 0; j < len; j++) {
                char c = words[i].charAt(j);
                int idx = c - 'A';
                weights[idx] += (int) Math.pow(10, len - j - 1);
            }
        }

        int num = 9, maxWeight = -1, maxIdx = 0, sum = 0;

        while (maxWeight != 0) {
            maxWeight = 0;

            // 가중치가 가장 큰 글자 찾기
            for (int i = 0; i < 26; i++) {
                if (maxWeight < weights[i]) {
                    maxWeight = weights[i];
                    maxIdx = i;
                }
            }

            // 가장 큰 가중치가 0이 아니라면
            if (maxWeight != 0) {
                sum += weights[maxIdx] * num--;
            }

            weights[maxIdx] = 0;
        }

        System.out.println(sum);
    }
}
```

- **알파벳 별 가중치를 계산!**
  - ABC의 경우 → A는 100, B는 10, C는 1
  - 인덱스 0인 A의 가중치 += (int) Math.pow(10, 단어길이(3) - 인덱스(0) - 1) → 즉, 10^2
- **가중치가 높은 순으로 9부터 차례대로 할당** → 가중치가 110인 A가 가장 크다면, sum += 110\*9
- **더해준 가중치는 0으로 초기화**

```java
10의 2승 = (int) Math.pow(10, 2) // 파라미터는 모두 double -> 결과도 double이므로 int로 형변환
```

> **그리디는 가중치를 고려해보자!!**

## 2025. 04. 26 복습 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine()); // 단어 개수

        int[] values = new int[26]; // 각 알파벳의 가중치

        for (int i = 0; i < N; i++) {
            String word = br.readLine();
            for (int j = 0; j < word.length(); j++) {
                char c = word.charAt(j);
                values[c - 'A'] += (int) Math.pow(10, word.length() - j - 1);
            }
        }

        Arrays.sort(values);

        int sum = 0;

        // 오름차순 정렬했으므로, 뒤에서부터 10개의 글자만 고르면 됨
        for (int i = values.length - 1, j = 9; i >= values.length - 10; i--, j--) {
            sum += j * values[i];
        }

        System.out.println(sum);
    }
}
```
