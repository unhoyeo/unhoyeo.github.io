<https://www.acmicpc.net/problem/12852>

정수 X에 사용할 수 있는 연산은 다음과 같이 세 가지이다.

1. X가 3으로 나누어 떨어지면, 3으로 나눈다.
2. X가 2로 나누어 떨어지면, 2로 나눈다.
3. 1을 뺀다.

정수 N이 주어졌을 때, 위와 같은 연산 세 개를 적절히 사용해서 1을 만들려고 한다. 연산을 사용하는 횟수의 최솟값을 출력하시오.

```java
10
```

첫째 줄에 1보다 크거나 같고, 106보다 작거나 같은 자연수 N이 주어진다.

```java
3
10 9 3 1
```

첫째 줄에 연산을 하는 횟수의 최솟값을 출력한다.

둘째 줄에는 N을 1로 만드는 방법에 포함되어 있는 수를 공백으로 구분해서 순서대로 출력한다. 정답이 여러 가지인 경우에는 아무거나 출력한다.

> **DP 풀이**

## 아이디어

- **dp[i] = i를 1로 만드는 데 필요한 최소 연산 횟수**
  - 초기값: **dp[1] = 0** (1을 1로 만들 때는 아무 연산도 필요하지 않음), **나머지는 INF**
- 2부터 N까지 다음 세 가지 연산 수행 후, 최소값으로 dp[i] 갱신
  - 모든 경우 → **dp[i] = min(dp[i], dp[i-1] + 1)**
  - 2로 나누어 떨어질 경우 → **dp[i] = min(dp[i], dp[i/2] + 1)**
  - 3으로 나누어 떨어질 경우 → **dp[i] = min(dp[i], dp[i/3] + 1)**
- **prev[i] = i로 오기 전의 값 저장 (i에서 연산한 결과)**
  - dp[i] 갱신 시, prev[i]도 해당 이전 값으로 갱신
- N에서부터 시작해서 prev 배열을 역추적하여 경로 출력

---

## 시간 복잡도

- DP 배열을 1부터 N까지 한 번 채우므로 **O(N)**
- 경로 복원은 최악의 경우 N번 이동하므로, **O(N)**
- 총 시간 복잡도: **O(N)**

---

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        // dp[i] = i를 1로 만드는 데 필요한 최소 연산 횟수
        int[] dp = new int[N + 1];
        int[] prev = new int[N + 1];

        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[1] = 0;

        for (int i = 2; i <= N; i++) {
            // 1 빼는 경우
            if (dp[i] > dp[i - 1] + 1) {
                dp[i] = dp[i - 1] + 1;
                prev[i] = i - 1;
            }
            // 2로 나누는 경우
            if (i % 2 == 0 && dp[i] > dp[i / 2] + 1) {
                dp[i] = dp[i / 2] + 1;
                prev[i] = i / 2;
            }
            // 3으로 나누는 경우
            if (i % 3 == 0 && dp[i] > dp[i / 3] + 1) {
                dp[i] = dp[i / 3] + 1;
                prev[i] = i / 3;
            }
        }

        StringBuilder sb = new StringBuilder();
        sb.append(dp[N]).append('\n');

        int cur = N;
        while (cur > 0) { // prev[1] = 0이므로, 0이 되면 종료
            sb.append(cur).append(' ');
            cur = prev[cur];
        }

        System.out.println(sb);
    }
}
```

> **BFS 풀이**

## 아이디어

- BFS는 시작 지점에서 **가까운 노드부터 탐색**하므로, **처음 도착한 시점이 곧 최소 연산 횟수**
- **dp[i]: N에서 i까지 도달하는 최소 연산 횟수**
- prev[i]: i로 오기 직전 숫자 저장
- 시작점을 N으로 두고, 1에 도착할 때까지 탐색
  - 세 가지 연산 중 가능한 연산을 수행하여, 해당 숫자를 방문하지 않았다면 방문
  - dp와 prev 배열을 갱신하고, 큐에 넣고 반복

---

## 시간 복잡도

- 각 숫자는 최대 1번만 방문하므로 **O(N)**
- 경로 복원은 DP 풀이와 동일

---

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        // dp[i] = N에서 i까지 도달하는 최소 연산 횟수
        int[] dp = new int[N + 1];
        int[] prev = new int[N + 1];

        Arrays.fill(dp, -1); // -1: 아직 방문하지 않음

        Queue<Integer> q = new ArrayDeque<>();
        q.add(N);
        dp[N] = 0;

        while (!q.isEmpty()) {
            int cur = q.poll();

            if (cur == 1) break;

            // 가능한 연산 결과들
            int[] nexts = {
                    cur - 1,
                    cur % 2 == 0 ? cur / 2 : -1,
                    cur % 3 == 0 ? cur / 3 : -1
            };

            // 가능한 연산 결과 중, 방문하지 않은 경우에만 갱신
            for (int next : nexts) {
                if (next > 0 && dp[next] == -1) {
                    dp[next] = dp[cur] + 1;
                    prev[next] = cur;
                    q.add(next);
                }
            }
        }

        StringBuilder sb = new StringBuilder();
        sb.append(dp[1]).append('\n');

        Deque<Integer> stack = new ArrayDeque<>();
        int cur = 1;

        while (true) {
            stack.push(cur);
            if (cur == N) break;
            cur = prev[cur];
        }

        while (!stack.isEmpty()) {
            sb.append(stack.pop()).append(' ');
        }

        System.out.println(sb);
    }
}
```

마지막 경로 추적 과정을 **Stack** 기반이 아닌, **List** 기반으로도 할 수도 있다.

```java
List<Integer> path = new ArrayList<>();

for (int cur = 1; cur != 0; cur = prev[cur]) {
    path.add(cur);
    if (cur == N) break;
}

Collections.reverse(path);

for (int num : path) {
    sb.append(num).append(' ');
}

System.out.println(sb);
```

경로를 List에 그대로 저장하므로, 역순뿐만 아니라 **정순으로도 활용**할 수 있다. 즉, 다른 용도로 재활용하기 편하다.

하지만 역순 출력 시 마지막에 <strong>Collections.reverse(list)</strong>를 해야 하므로, 순회를 한 번 더 한다는 단점이 존재한다.
