<https://www.acmicpc.net/problem/2263>

n개의 정점을 갖는 이진 트리의 정점에 1부터 n까지의 번호가 중복 없이 매겨져 있다. 이와 같은 이진 트리의 인오더와 포스트오더가 주어졌을 때, 프리오더를 구하는 프로그램을 작성하시오.

```java
3
1 2 3
1 3 2
```

첫째 줄에 n(1 ≤ n ≤ 100,000)이 주어진다. 다음 줄에는 인오더를 나타내는 n개의 자연수가 주어지고, 그 다음 줄에는 같은 식으로 포스트오더가 주어진다.

```java
2 1 3
```

첫째 줄에 프리오더를 출력한다.

---

**아이디어**

- **inorder(중위 순회), postorder(후위 순회) 배열**을 이용해 트리를 구성하지 않고도 **preorder(전위 순회)** 결과를 구해야 한다.
  - inorder: [왼쪽 서브트리]**[루트]**[오른쪽 서브트리]
  - postorder: [왼쪽 서브트리][오른쪽 서브트리]**[루트]**
  - preorder: **[루트]**[왼쪽 서브트리][오른쪽 서브트리]
- 각 순회 방식의 루트 위치를 잘 보자.
  - inorder → **루트 좌우로** 왼쪽 서브트리와 오른쪽 서브트리를 나눌 수 있다.
  - postorder → **항상 맨 마지막**에 루트가 있다.
  - preorder → **항상 첫 번째**에 루트가 있다.
- 따라서 **해당 구간을 inorder, postorder 모두에서 적절히 분할**하여, 재귀적으로 **루트 → 왼쪽 → 오른쪽** 순서로 출력하면 된다.
  - 단, inorder 배열에서 **루트의 인덱스**를 빠르게 찾기 위해 **Map**을 사용해야 한다.

---

⏱️ **시간 복잡도**

- 각 노드는 한 번만 방문: O(N)
- Map 조회: O(1)
- 전체 시간 복잡도: **O(N)**

---

**Java 코드**

```java
import java.io.*;
import java.util.*;

public class Main {
    static int[] inorder, postorder;
    static Map<Integer, Integer> inidx = new HashMap<>();
    static StringBuilder sb = new StringBuilder();

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());

        inorder = new int[n];
        postorder = new int[n];

        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            inorder[i] = Integer.parseInt(st.nextToken());
            inidx.put(inorder[i], i);
        }

        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            postorder[i] = Integer.parseInt(st.nextToken());
        }

        preorder(0, n - 1, 0, n - 1);

        System.out.println(sb);
    }

    static void preorder(int inL, int inR, int postL, int postR) {
        if (inL > inR || postL > postR) return;

        int root = postorder[postR];
        int rootIdx = inidx.get(root);
        int leftSize = rootIdx - inL;

        // 1. 루트 출력
        sb.append(root).append(' ');

        // 2. 왼쪽 서브트리 재귀 호출
        preorder(inL, rootIdx - 1, postL, postL + leftSize - 1);

        // 3. 오른쪽 서브트리 재귀 호출
        preorder(rootIdx + 1, inR, postL + leftSize, postR - 1);
    }
    // in: l -> m -> r, post: l -> r -> m
}
```
