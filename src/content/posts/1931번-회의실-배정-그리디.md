<https://www.acmicpc.net/problem/1931>

**한 개의 회의실**이 있는데 이를 사용하고자 하는 **N개의 회의**에 대하여 **회의실 사용표**를 만들려고 한다. 각 회의 I에 대해 시작시간과 끝나는 시간이 주어져 있고, 각 회의가 겹치지 않게 하면서 회의실을 사용할 수 있는 **회의의 최대 개수**를 찾아보자. 단, 회의는 한번 시작하면 중간에 중단될 수 없으며 한 회의가 끝나는 것과 동시에 다음 회의가 시작될 수 있다. **회의의 시작시간과 끝나는 시간이 같을 수도 있다.** 이 경우에는 시작하자마자 끝나는 것으로 생각하면 된다.

```java
11
1 4
3 5
0 6
5 7
3 8
5 9
6 10
8 11
8 12
2 13
12 14
```

첫째 줄에 회의의 수 N(1 ≤ N ≤ 100,000)이 주어진다. 둘째 줄부터 N+1 줄까지 각 회의의 정보가 주어지는데 이것은 공백을 사이에 두고 회의의 시작시간과 끝나는 시간이 주어진다. 시작 시간과 끝나는 시간은 2^31-1보다 작거나 같은 자연수 또는 0이다.

```java
4
```

첫째 줄에 최대 사용할 수 있는 회의의 최대 개수를 출력한다.

---

## ✅ 아이디어

- 회의를 **끝나는 시간 기준**으로 **오름차순 정렬**한다.
  - 끝나는 시간이 빠른 회의부터 선택하면 **다음 회의를 넣을 수 있는 가능성이 커지기 때문!**
  - 만약 끝나는 시간이 같다면, **시작 시간이 빠른 순서로 정렬!** (이유는 마지막에)
- 가장 빨리 끝나는 회의를 선택하고, 그 회의가 끝난 이후 시작할 수 있는 회의를 찾는다.
  - 이전 회의가 끝나는 시점보다 시작 시점이 빠르면 선택하지 않는다.

## ✅ 시간 복잡도

- **정렬**: O(N log N)
- **그리디 탐색**: O(N)
- **총 시간 복잡도**: **O(N log N)** = 10⁵ \* 20 < 2억 → 가능!

## ✅ 자바 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine()); // 회의 개수

        PriorityQueue<Meeting> pq = new PriorityQueue<>();
        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int start = Integer.parseInt(st.nextToken());
            int end = Integer.parseInt(st.nextToken());
            pq.add(new Meeting(start, end));
        }

        int result = 0, last = 0;
        while (!pq.isEmpty()) {
            Meeting cur = pq.poll();
            if (cur.start < last) continue;
            result++;
            last = cur.end;
        }

        System.out.println(result);
    }

    static class Meeting implements Comparable<Meeting> {
        int start, end;

        public Meeting(int start, int end) {
            this.start = start;
            this.end = end;
        }

        @Override
        public int compareTo(Meeting o) {
            if (this.end == o.end) {
                return this.start - o.start;
            }
            return this.end - o.end;
        }
    }
}
```

---

**끝나는 시간이 같을 때, 시작 시간을 기준으로 오름차순을 해야 하는 이유**는 뭘까? 다음 예시 입력을 보자.

```java
8 8
4 8
1 3
```

**끝나는 시간 기준으로만 정렬**하면 다음과 같이 정렬될 수 있다.

```java
1 3
8 8
4 8
```

- 위와 같이 정렬되면 (1, 3)이 선택되고 **last = 3**으로 바뀐다.
- 그다음 (8, 8)이 선택되면 **last = 8**로 바뀐다.
- 이렇게 되면 **(4, 8)은 선택할 수 없게 된다!**
- 하지만 이는 답이 아니다. 실제로는 **(1, 3), (4, 8), (8, 8) 모두 선택**되어야 한다.
- 따라서, 끝나는 시간이 같다면 **시작 시간을 기준으로 오름차순으로 정렬**해주어야 한다.
