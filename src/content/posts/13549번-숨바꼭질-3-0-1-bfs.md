<https://www.acmicpc.net/problem/13549>

수빈이는 동생과 숨바꼭질을 하고 있다. 수빈이는 현재 점 N(0 ≤ N ≤ 100,000)에 있고, 동생은 점 K(0 ≤ K ≤ 100,000)에 있다. 수빈이는 걷거나 순간이동을 할 수 있다. 만약, 수빈이의 위치가 X일 때 걷는다면 1초 후에 X-1 또는 X+1로 이동하게 된다. 순간이동을 하는 경우에는 0초 후에 2\*X의 위치로 이동하게 된다.

수빈이와 동생의 위치가 주어졌을 때, 수빈이가 동생을 찾을 수 있는 가장 빠른 시간이 몇 초 후인지 구하는 프로그램을 작성하시오.

```java
5 17
```

첫 번째 줄에 수빈이가 있는 위치 N과 동생이 있는 위치 K가 주어진다. N과 K는 정수이다.

```
2
```

수빈이가 동생을 찾는 가장 빠른 시간을 출력한다.

---

## 아이디어

- 순간이동의 비용은 0이고, 걷기의 비용은 1 → **가중치가 0 또는 1인 그래프**에서 최단 경로를 구하는 **0-1 BFS** 사용
- dist[i]는 i 위치까지 도달하는 데 걸린 최소 시간
  - 처음에는 **-1**로 초기화 (방문하지 않음)
  - 출발점은 0으로 설정
- 0초 걸리는 순간이동은 **addFirst**, 1초 걸리는 걷기는 **addLast**
- K 위치에 도달하면 dist[K] 출력

---

## 시간 복잡도

- 각 위치를 최대 1번만 방문하므로, **O(N)**

---

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    static final int MAX = 100_000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int K = Integer.parseInt(st.nextToken());

        System.out.println(bfs(N, K));
    }

    static int bfs(int start, int target) {
        Deque<Integer> dq = new ArrayDeque<>();
        dq.add(start);

        int[] dist = new int[MAX + 1];
        Arrays.fill(dist, -1);
        dist[start] = 0;

        while (!dq.isEmpty()) {
            int cur = dq.poll();

            if (cur == target) {
                return dist[cur];
            }

            int[] moves = {2 * cur, cur - 1, cur + 1};
            int[] costs = {0, 1, 1};

            for (int i = 0; i < 3; i++) {
                int next = moves[i];
                int cost = costs[i];

                if (isIn(next) && dist[next] == -1) {
                    dist[next] = dist[cur] + cost;
                    if (cost == 0) {
                        dq.addFirst(next);
                    } else {
                        dq.addLast(next);
                    }
                }
            }
        }

        return -1;
    }

    static boolean isIn(int pos) {
        return pos >= 0 && pos <= MAX;
    }
}
```
