<https://www.acmicpc.net/problem/2294>

N가지 종류의 동전이 있다. 이 동전들을 적당히 사용해서, 그 가치의 합이 K원이 되도록 하고 싶다. 그러면서 동전의 개수가 최소가 되도록 하려고 한다. 각각의 동전은 몇 개라도 사용할 수 있다.

```java
3 15
1
5
12
```

첫째 줄에 N, K가 주어진다. (1 ≤ N ≤ 100, 1 ≤ K ≤ 10,000) 다음 N개의 줄에는 각각의 동전의 가치가 주어진다. 동전의 가치는 100,000보다 작거나 같은 자연수이다. **가치가 같은 동전이 여러 번 주어질 수도 있다.**

```
3
```

첫째 줄에 **사용한 동전의 최소 개수**를 출력한다. **불가능한 경우에는 -1을 출력한다.**

---

## 아이디어

- 가치가 같은 동전이 여러 번 주어질 수도 있음 → **Set&lt;Integer> 사용!**
- dp[i] = i원을 만드는데 필요한 동전의 최소 개수
  - dp[0] = 0, 나머지는 모두 **INF로 초기화**
- coins에서 coin을 하나씩 꺼내서 다음 과정을 반복
  - **dp[i] = Math.min(dp[i], dp[i - coin] + 1)**
  - 기존 경우와 (i - coin)원을 만드는 최소 동전 개수에서 coin원을 1개 추가해서 i원을 만드는 경우 비교
  - i - coin ≥ 0 이어야 하므로 → i의 범위: **coin ~ K**
- dp[K]가 INF면 -1, 아니면 dp[K] 출력

```java
import java.io.*;
import java.util.*;

public class Main {
    static final int INF = 10_001;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int K = Integer.parseInt(st.nextToken());

        Set<Integer> coins = new HashSet<>();

        for (int i = 0; i < N; i++) {
            coins.add(Integer.parseInt(br.readLine()));
        }

        int[] dp = new int[K + 1]; // dp[i] = i원을 만드는데 필요한 동전의 최소 개수

        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int coin : coins) {
            for (int i = coin; i <= K; i++) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }

        System.out.println(dp[K] == INF ? -1 : dp[K]);
    }
}
```

## 경로 추적 (어떤 동전으로 구성되었는지)

- K원을 만들 때 어떤 동전들이 사용되었는지 알려면 DP 테이블과 함께 **prev 배열**을 함께 사용하면 된다.
- **prev[i] = i원을 만들기 위해 사용된 마지막 동전의 가치**
- 이를 통해 K → K - coin → K - coin - coin → ... → 0 형태로 거꾸로 추적할 수 있다.

```java
import java.io.*;
import java.util.*;

public class Main {
    static final int INF = 10_001;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int K = Integer.parseInt(st.nextToken());

        Set<Integer> coins = new HashSet<>();

        for (int i = 0; i < N; i++) {
            coins.add(Integer.parseInt(br.readLine()));
        }

        int[] dp = new int[K + 1];
        int[] prev = new int[K + 1]; // 경로 추적용

        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int coin : coins) {
            for (int i = coin; i <= K; i++) {
                if (dp[i] > dp[i - coin] + 1) {
                    dp[i] = dp[i - coin] + 1;
                    prev[i] = coin; // i원을 만들기 위해 사용된 마지막 동전
                }
            }
        }

        if (dp[K] == INF) {
            System.out.println(-1);
        } else {
            System.out.println(dp[K]);

            // 경로 추적
            Stack<Integer> path = new Stack<>();
            int cur = K;
            while (cur > 0) {
                path.push(prev[cur]); // cur원을 만들기 위해 사용된 마지막 동전
                cur -= prev[cur]; // 해당 동전의 가치만큼 빼기
            }

            StringBuilder sb = new StringBuilder();
            while (!path.isEmpty()) {
                sb.append(path.pop()).append(' ');
            }
            System.out.println(sb);
        }
    }
}
```
