서블릿만을 이용하여 **회원 등록, 회원 목록 조회** 기능을 가진 간단한 웹 애플리케이션을 만들어 보자.

---

## 도메인 회원 객체 – Member

```java
@Getter @Setter
public class Member {

    private Long id;
    private String username;
    private int age;

    public Member() {}

    public Member(String username, int age) {
        this.username = username;
        this.age = age;
    }
}
```

- id: 내부 저장소에서 부여
- username, age: 사용자가 입력한 정보

---

## 메모리 기반 회원 저장소 (싱글톤) – MemberRepository

```java
public class MemberRepository {

    private static Map<Long, Member> store = new HashMap<>();
    private static long sequence = 0L;

    private static final MemberRepository instance = new MemberRepository();

    private MemberRepository() {}

    public static MemberRepository getInstance() {
        return instance;
    }

    public Member save(Member member) {
        member.setId(++sequence);
        store.put(member.getId(), member);
        return member;
    }

    public Member findById(Long id) {
        return store.get(id);
    }

    public List<Member> findAll() {
        return new ArrayList<>(store.values());
    }

    public void clearStore() {
        store.clear();
    }
}
```

- Map.values()의 반환 타입은 Collection&lt;V>이므로, List가 필요하다면 new ArrayList<>(collection) 방식으로 명시적 변환 필요
- 멀티쓰레드 환경에서는 ConcurrentHashMap, AtomicLong 사용 권장
- 실무에서는 DB, 트랜잭션 처리, 동시성 고려 필요

## 회원 등록 폼 (정적 HTML) – form.html

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8"/>
    <title>회원 등록</title>
  </head>
  <body>

      이름: <input name="username" type="text"/>

    </form>
  </body>

```

- 사용자는 이름과 나이를 입력하여 회원 등록을 요청한다.
- POST 방식으로 /members/save로 전송됨

## 회원 등록 처리 서블릿 – MemberSaveServlet

```java
@WebServlet(name = "memberSaveServlet", urlPatterns = "/members/save")
public class MemberSaveServlet extends HttpServlet {

    private MemberRepository memberRepository = MemberRepository.getInstance();

    @Override
    protected void service(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {

        String username = request.getParameter("username");
        int age = Integer.parseInt(request.getParameter("age"));

        Member member = new Member(username, age);
        memberRepository.save(member);

        response.setContentType("text/html");
        response.setCharacterEncoding("UTF-8");

        PrintWriter w = response.getWriter();
        w.write("<html><body>");
        w.write("<h2>회원 등록 완료</h2>");
        w.write("id = " + member.getId() + "<br>");
        w.write("username = " + member.getUsername() + "<br>");
        w.write("age = " + member.getAge() + "<br>");
        w.write("<a href=\"/members\">회원 목록</a>");
        w.write("</body></html>");
    }
}
```

- HttpServletRequest로 요청 파라미터 추출
- 회원 저장소에 Member 객체 저장
- HTML 문자열을 자바 코드로 직접 생성 후 출력

## 회원 목록 조회 서블릿 – MemberListServlet

```java
@WebServlet(name = "memberListServlet", urlPatterns = "/members")
public class MemberListServlet extends HttpServlet {

    private MemberRepository memberRepository = MemberRepository.getInstance();

    @Override
    protected void service(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {

        List<Member> members = memberRepository.findAll();

        response.setContentType("text/html");
        response.setCharacterEncoding("UTF-8");

        PrintWriter w = response.getWriter();
        w.write("<html><body>");
        w.write("<h2>회원 목록</h2>");
        w.write("<table border='1'>");
        w.write("<thead><tr><th>id</th><th>username</th><th>age</th></tr></thead>");
        w.write("<tbody>");
        for (Member member : members) {
            w.write("<tr>");
            w.write("<td>" + member.getId() + "</td>");
            w.write("<td>" + member.getUsername() + "</td>");
            w.write("<td>" + member.getAge() + "</td>");
            w.write("</tr>");
        }
        w.write("</tbody>");
        w.write("</table>");
        w.write("</body></html>");
    }
}
```

- 전체 회원 목록을 HTML 테이블로 출력
- 역시 HTML을 자바 코드 내에서 직접 작성함

## HTML을 서블릿 코드로 생성하는 방식의 문제점

|  |  |
| --- | --- |
| **? 가독성 저하** | 자바 코드에 HTML이 뒤섞여 있어 이해하기 힘들다 |
| **? 유지보수 난이도 증가** | 디자인/UI 변경 시 자바 코드까지 수정해야 한다 |
| **? 협업 비효율** | 프론트엔드 개발자가 자바 코드를 건드릴 수 없다 |
| **? 재사용 불가** | HTML이 하드코딩되어 있어 공통 UI 구성이 불가능하다 |

이러한 단점은 규모가 커질수록 치명적으로 작용한다.

---

? **해결책: 템플릿 엔진의 도입**

템플릿 엔진은 **HTML의 정적 구조는 유지**하면서, **동적 데이터를 필요한 위치에만 삽입**할 수 있도록 해준다.

예시:

```html
<tr>
    <td>${member.id}</td>
    <td>${member.username}</td>
    <td>${member.age}</td>
</tr>
```

- HTML은 그대로 유지됨
- **${변수}** 표현식으로 동적 데이터만 바인딩

---

? **대표적인 템플릿 엔진**

|  |  |
| --- | --- |
| **JSP** | Java EE 표준, 서블릿으로 변환되어 실행됨 |
| **Thymeleaf** | HTML 친화적 문법, 스프링에서 가장 널리 사용 |
| **Freemarker** | 고급 구성과 확장성 제공 |
| **Velocity** | 과거에 널리 쓰였지만 현재는 드물게 사용 |

---

? **정리**

- 서블릿만으로도 기능 구현은 가능하지만, **HTML 생성이 어렵고 복잡하다.**
- 템플릿 엔진은 **UI와 비즈니스 로직을 분리**하고 유지보수를 용이하게 한다.
- 실무에서는 JSP, Thymeleaf 등 템플릿 기술과 MVC 패턴을 결합해 사용한다.
