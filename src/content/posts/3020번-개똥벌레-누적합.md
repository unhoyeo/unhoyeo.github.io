<https://www.acmicpc.net/problem/3020>

개똥벌레 한 마리가 장애물(석순과 종유석)로 가득찬 동굴에 들어갔다. 동굴의 길이는 N미터이고, 높이는 H미터이다. (N은 짝수) 첫 번째 장애물은 항상 석순이고, 그 다음에는 종유석과 석순이 번갈아가면서 등장한다.

아래 그림은 길이가 14미터이고 높이가 5미터인 동굴이다. (예제 그림)

![3020번 개똥벌레 – 누적합](/images/tistory/259/img.png)

이 개똥벌레는 장애물을 피하지 않는다. 자신이 지나갈 구간을 정한 다음 일직선으로 지나가면서 만나는 모든 장애물을 파괴한다.

위의 그림에서 4번째 구간으로 개똥벌레가 날아간다면 파괴해야하는 장애물의 수는 총 여덟개이다. (4번째 구간은 길이가 3인 석순과 길이가 4인 석순의 중간지점을 말한다)

![3020번 개똥벌레 – 누적합](/images/tistory/259/img_1.png)

하지만, 첫 번째 구간이나 다섯 번째 구간으로 날아간다면 개똥벌레는 장애물 일곱개만 파괴하면 된다.

동굴의 크기와 높이, 모든 장애물의 크기가 주어진다. 이때, 개똥벌레가 파괴해야하는 장애물의 최솟값과 그러한 구간이 총 몇 개 있는지 구하는 프로그램을 작성하시오.

```java
6 7
1
5
3
3
5
1
```

첫째 줄에 N과 H가 주어진다. N은 항상 짝수이다. (2 ≤ N ≤ 200,000, 2 ≤ H ≤ 500,000)

다음 N개 줄에는 장애물의 크기가 순서대로 주어진다. 장애물의 크기는 H보다 작은 양수이다.

```java
2 3
```

첫째 줄에 개똥벌레가 파괴해야 하는 장애물의 최솟값과 그러한 구간의 수를 공백으로 구분하여 출력한다.

---

## 아이디어

- **크기가 i인 석순 및 종유석의 개수**를 배열에 저장
  - 석순과 종유석은 번갈아 나옴 → **짝수번째는 석순, 홀수번째는 종유석**
- **크기가 i 이상인 석순 및 종유석의 개수**를 배열에 저장 (**누적합**)
  - **크기가 H**인 석순 및 종유석부터 시작 (해당 값이 가장 작으므로)
- 개똥벌레가 **높이 h**를 선택하면
  - 석순 중에서 **h 이상**인 것들은 충돌
  - 종유석 중에서 **(H - h + 1) 이상**인 것들은 충돌
- 최종적으로 **h = 1부터 H까지** 최소 충돌 횟수와 해당 구간의 개수를 구하면 됨

1. - 종유석 충돌 = upSum[H - h + 1]

---

## ⏱️ 시간 복잡도

- 크기가 i인 석순 및 종유석의 개수 배열: **O(N)**
- 크기가 i 이상인 석순 및 종유석의 개수 배열(누적합): **O(H)**
- 전체 탐색: **O(H)**
- 전체 시간 복잡도: **O(N + H)** → N ≤ 200,000, H ≤ 500,000 → 가능

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int H = Integer.parseInt(st.nextToken());

        // 크기가 i인 석순 및 종유석 개수
        int[] down = new int[H + 2];
        int[] up = new int[H + 2];

        for (int i = 0; i < N; i++) {
            int size = Integer.parseInt(br.readLine());
            if (i % 2 == 0) { // 석순
                down[size]++;
            } else { // 종유석
                up[size]++;
            }
        }

        // 크기가 i 이상인 석순 및 종유석 개수
        int[] downSum = new int[H + 2];
        int[] upSum = new int[H + 2];

        // 누적합 구하기
        for (int h = H; h >= 1; h--) {
            downSum[h] = downSum[h + 1] + down[h];
            upSum[h] = upSum[h + 1] + up[h];
        }

        int minBreakCnt = Integer.MAX_VALUE;
        int count = 0;

        // 각 높이에서 몇 번 부딪히는지 계산
        for (int h = 1; h <= H; h++) {
            int breakCnt = downSum[h] + upSum[H - h + 1];
            if (breakCnt < minBreakCnt) {
                minBreakCnt = breakCnt;
                count = 1;
            } else if (breakCnt == minBreakCnt) {
                count++;
            }
        }

        System.out.println(minBreakCnt + " " + count);
    }
}
```
