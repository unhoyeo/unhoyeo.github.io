<https://www.acmicpc.net/problem/12015>

수열 A가 주어졌을 때, 가장 긴 증가하는 부분 수열을 구하는 프로그램을 작성하시오.

예를 들어, A = {10, 20, 10, 30, 20, 50} 인 경우에 가장 긴 증가하는 부분 수열은 A = {**10**, **20**, 10, **30**, 20, **50**} 이고, 길이는 4이다.

```java
6
10 20 10 30 20 50
```

첫째 줄에 수열 A의 크기 N (1 ≤ N ≤ 1,000,000)이 주어진다.

둘째 줄에는 수열 A를 이루고 있는 Ai가 주어진다. (1 ≤ Ai ≤ 1,000,000)

```java
4
```

첫째 줄에 수열 A의 가장 긴 증가하는 부분 수열의 길이를 출력한다.

---

## 아이디어

- 가장 긴 증가하는 부분 수열(LIS) 문제는 2가지 방식으로 해결할 수 있다.
  - **DP → O(N^2)**
  - **이분(이진) 탐색 → O(N log N)**
- 이 문제는 **N ≤ 1,000,000**이므로 DP를 이용한 O(N^2) 방식은 시간 초과된다.

## ❌ 시간 초과하는 풀이

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int[] A = new int[N];

        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            A[i] = Integer.parseInt(st.nextToken());
        }

        int[] LIS = new int[N];

        for (int i = 0; i < N; i++) {
            LIS[i] = 1;
            for (int j = 0; j < i; j++) {
                if (A[i] > A[j]) {
                    LIS[i] = Math.max(LIS[i], LIS[j] + 1);
                }
            }
        }

        int maxLen = 0;
        for (int lis : LIS) {
            maxLen = Math.max(maxLen, lis);
        }

        System.out.println(maxLen);
    }
}
```

## ✅ 올바른 풀이

- **이분 탐색**을 이용한 **O(N log N)** 방식으로 해결하면 된다. (**10^6 ≈ 2^20** = 1,048,576)
- 주어진 수열의 각 수를 dp 배열에 넣을 때, **이분 탐색**을 사용하여 **적절한 위치에 삽입/교체**한다.
  - dp 배열은 실제 LIS를 구성하지는 않지만, 해당 길이의 LIS를 만들기 위해 **마지막 원소로 가능한 가장 작은 수**를 유지한다.
  - 실제 LIS를 구성하지 않고 **길이만 구하는 문제**이므로 이 방식이 적합하다.

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int[] A = new int[N];

        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            A[i] = Integer.parseInt(st.nextToken());
        }

        List<Integer> dp = new ArrayList<>(); // 현재까지 만들어진 LIS의 각 길이별 최소 마지막 값을 저장

        for (int i = 0; i < N; i++) {
            int idx = Collections.binarySearch(dp, A[i]);
            if (idx < 0) idx = -idx - 1;

            if (idx == dp.size()) dp.add(A[i]);
            else dp.set(idx, A[i]);
        }

        System.out.println(dp.size());
    }
}
```

## 왜 dp 배열은 실제 LIS가 아닐까?

```java
4
-5 2 2 -19
```

다음과 같은 입력이 들어올 경우, dp 배열은 다음과 같은 과정을 거친다.

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **i** | **A[i]** | **이분 탐색 결과 idx** | **삽입/교체 후 dp** | **설명** |
| 0 | -5 | 0 (idx == dp.size()) | [**-5**] | 맨 뒤에 삽입 |
| 1 | 2 | 1 (idx == dp.size()) | [-5, **2**] | 맨 뒤에 삽입 |
| 2 | 2 | 1 | [-5, **2**] | dp[1]을 교체 |
| 3 | -19 | 0 | [**-19**, 2] | dp[0]을 교체 |

**최종 dp 상태**

```java
[-19, 2]
```

- dp[i]는 길이가 (i + 1)인 증가 부분 수열에서 **마지막 원소로 가능한 가장 작은 수**를 저장한다.
  - dp[0] = -19는 길이가 1인 증가 부분 수열에서 마지막 원소로 가능한 가장 작은 수
  - dp[1] = 2는 길이가 2인 증가 부분 수열에서 마지막 원소로 가능한 가장 작은 수
- 따라서, dp 배열은 **실제 LIS가 아니지만, 길이는 LIS의 길이와 같다!**
  - 실제 LIS 배열은 <strong>[-5, 2]</strong>이다.
- 만약 실제 LIS를 복원하고 싶다면 다른 방법(**추적 배열** 활용)이 필요하다.

---

✅ **정리**

- dp는 LIS를 만드는 과정에서 각 길이에 해당하는 가장 작은 끝 값을 저장
- 이분 탐색으로 위치를 찾아 업데이트 → LIS의 길이만 구할 때 적합
- N ≤ 1,000,000 에도 **무리 없이 동작하는 최적 방식**
