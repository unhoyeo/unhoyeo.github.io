트리에서 리프 노드란, 자식의 개수가 0인 노드를 말한다. 트리가 주어졌을 때, 노드 하나를 지울 것이다. 그때, 남은 트리에서 리프 노드의 개수를 구하는 프로그램을 작성하시오. 노드를 지우면 그 노드와 노드의 모든 자손이 트리에서 제거된다.

예를 들어, 다음과 같은 트리가 있다고 하자.

![1068번 트리 - 트리, DFS](/images/tistory/126/img.png)

현재 리프 노드의 개수는 3개이다. (초록색 색칠된 노드) 이때, 1번을 지우면, 다음과 같이 변한다. 검은색으로 색칠된 노드가 트리에서 제거된 노드이다.

![1068번 트리 - 트리, DFS](/images/tistory/126/img_1.png)

이제 리프 노드의 개수는 1개이다.

```java
5
-1 0 0 1 1
2
```

첫째 줄에 트리의 노드의 개수 N이 주어진다. N은 50보다 작거나 같은 자연수이다. 둘째 줄에는 0번 노드부터 N-1번 노드까지, 각 노드의 부모가 주어진다. 만약 부모가 없다면 (루트) -1이 주어진다. 셋째 줄에는 지울 노드의 번호가 주어진다.

```java
2
```

첫째 줄에 입력으로 주어진 트리에서 입력으로 주어진 노드를 지웠을 때, 리프 노드의 개수를 출력한다.

## ❌ 틀린 아이디어

- 각 노드의 부모 정보를 통해 자식 리스트를 만든다.
- 루트부터 DFS 탐색을 하며, 삭제할 노드는 건너뛴다.
- 리프 노드 개수를 카운팅한다.

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, root, deletedNode, leaf = 0;
    static List<List<Integer>> tree = new ArrayList<>();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        N = Integer.parseInt(br.readLine());

        for (int i = 0; i < N; i++) {
            tree.add(new ArrayList<>());
        }

        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            int parent = Integer.parseInt(st.nextToken()); // i번 노드의 부모
            if (parent == -1) root = i;
            else tree.get(parent).add(i);
        }

        deletedNode = Integer.parseInt(br.readLine());

        dfs(root);
        System.out.println(leaf);
    }

    static void dfs(int node) {
        if (node == deletedNode) return;

        // 리프 노드인 경우
        if (tree.get(node).isEmpty()) {
            leaf++;
            return;
        }

        for (int child : tree.get(node)) {
            dfs(child);
        }
    }
}
```

3

## ☑️ 위 문제를 해결한 풀이

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, root, deletedNode, leaf = 0;
    static List<List<Integer>> tree = new ArrayList<>();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        N = Integer.parseInt(br.readLine());

        for (int i = 0; i < N; i++) {
            tree.add(new ArrayList<>());
        }

        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            int parent = Integer.parseInt(st.nextToken()); // i번 노드의 부모
            if (parent == -1) root = i;
            else tree.get(parent).add(i);
        }

        deletedNode = Integer.parseInt(br.readLine());

        dfs(root);
        System.out.println(leaf);
    }

    static boolean dfs(int node) {
        boolean hasDeletedNode = false;

        if (node == deletedNode) return true;

        // 리프 노드인 경우
        if (tree.get(node).isEmpty()) {
            leaf++;
            return false;
        }

        for (int child : tree.get(node)) {
            hasDeletedNode = dfs(child);
        }

        if (hasDeletedNode && tree.get(node).size() == 1) leaf++;
        return false;
    }
}
```

## ✅ 위 코드의 dfs()를 개선한 버전

```java
static void dfs(int node) {
    if (node == deletedNode) return;

    boolean isLeaf = true;
    for (int child : tree.get(node)) {
        if (child != deletedNode) {
            isLeaf = false;
            dfs(child);
        }
    }

    if (isLeaf) leafCount++;
}
```

- **자식 중에서 유효한 자식이 없는 경우 → 리프 노드!**
  - child가 없거나,
  - child가 deletedNode밖에 없으면 리프 노드다!
