<https://www.acmicpc.net/problem/2156>

효주는 포도주 시식회에 갔다. 그 곳에 갔더니, 테이블 위에 다양한 포도주가 들어있는 포도주 잔이 일렬로 놓여 있었다. 효주는 포도주 시식을 하려고 하는데, 여기에는 다음과 같은 두 가지 규칙이 있다.

1. 포도주 잔을 선택하면 그 잔에 들어있는 포도주는 모두 마셔야 하고, 마신 후에는 원래 위치에 다시 놓아야 한다.
2. 연속으로 놓여 있는 3잔을 모두 마실 수는 없다.

효주는 될 수 있는 대로 많은 양의 포도주를 맛보기 위해서 어떤 포도주 잔을 선택해야 할지 고민하고 있다. 1부터 n까지의 번호가 붙어 있는 n개의 포도주 잔이 순서대로 테이블 위에 놓여 있고, 각 포도주 잔에 들어있는 포도주의 양이 주어졌을 때, 효주를 도와 가장 많은 양의 포도주를 마실 수 있도록 하는 프로그램을 작성하시오.

예를 들어 6개의 포도주 잔이 있고, 각각의 잔에 순서대로 6, 10, 13, 9, 8, 1 만큼의 포도주가 들어 있을 때, 첫 번째, 두 번째, 네 번째, 다섯 번째 포도주 잔을 선택하면 총 포도주 양이 33으로 최대로 마실 수 있다.

```java
6
6
10
13
9
8
1
```

첫째 줄에 포도주 잔의 개수 n이 주어진다. (1 ≤ n ≤ 10,000) 둘째 줄부터 n+1번째 줄까지 포도주 잔에 들어있는 포도주의 양이 순서대로 주어진다. 포도주의 양은 1,000 이하의 음이 아닌 정수이다.

```java
33
```

첫째 줄에 최대로 마실 수 있는 포도주의 양을 출력한다.

---

## 아이디어

- dp[i] = i번째 포도주까지 고려했을 때 최대로 마실 수 있는 양
- 연속으로 3잔을 마실 수 없으므로, i번째까지 고려했을 때 **마실 수 있는 경우의 수**를 고려하자.

```java
i 마신다, i-1 마신다, i-2 안 마신다, i-3 마신다
i 마신다, i-1 안 마신다, i-2 마신다
i 안 마신다, i-1 마신다
```

- 각 경우는 **안 마시는 포도주**를 고려해야 하며, **마지막은 마시는 것**으로 끝나야 한다.
- 각 경우의 점화식은 다음과 같다.

```java
arr[i] + arr[i - 1] + dp[i - 3]
arr[i] + dp[i - 2]
dp[i - 1]
```

- dp[i - 3]이 있으므로, i는 3부터 시작
- 단, 배열의 인덱스를 0-based로 할 경우, dp[2]를 점화식으로 계산할 수 없어 수동으로 해야 한다.
- 따라서 배열의 인덱스는 **1-based**로 한다. (dp[3]의 첫 번째 점화식에서 i-3번째는 없으므로 자동으로 0으로 처리된다.)
- **⚠️** n이 1일 수 있으므로, dp[2] 초기화 시 **if (n >= 2)** 조건을 추가해야 한다.

---

## ⏱️ 시간 복잡도

- 각 i마다 O(1) 연산이므로, **O(N)**

---

## Java 코드

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());

        int[] arr = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            arr[i] = Integer.parseInt(br.readLine());
        }

        int[] dp = new int[n + 1];

        dp[1] = arr[1];
        if (n >= 2) dp[2] = arr[1] + arr[2];

        for (int i = 3; i <= n; i++) {
            int a = arr[i] + arr[i - 1] + dp[i - 3];
            int b = arr[i] + dp[i - 2];
            int c = dp[i - 1];
            dp[i] = Math.max(a, Math.max(b, c));
        }

        System.out.println(dp[n]);
    }
}
```

## ✅ 결론

- 이 문제는 **"이전 상태에 따른 선택 제약"**이 있는 DP 유형이다.
- **각각의 선택지로 나누어** max()로 갱신하면서 최적해를 구하면 된다.
- 초기값 설정과 경계 조건 예외 처리가 핵심이다.
