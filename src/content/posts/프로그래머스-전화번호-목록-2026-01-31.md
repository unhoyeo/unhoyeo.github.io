[프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/42577?language=java#)

이 문제는 <strong>정렬</strong>이나 <strong>해시</strong>를 사용해서 효율적으로 풀 수 있는 문제다. 전화번호가 최대 100만 개나 되기 때문에, 단순히 <strong>이중 반복문</strong>을 사용해 모든 경우를 비교하면 <strong>O(N²)</strong>의 시간 복잡도가 되어 효율성 테스트를 통과할 수 없다.

---

## 오답

```java
import java.util.*;

class Solution {
    public boolean solution(String[] phone_book) {
        Set<String> set = new HashSet<>();

        for (String p : phone_book) {
            for (int i = 1; i <= p.length(); i++) {
                String sub = p.substring(0, i);
                if (set.contains(sub)) {
                    return false;
                }
                set.add(sub);
            }
        }

        return true;
    }
}
```

## 오답인 이유

- "전화번호 그 자체"와 "전화번호의 일부(접두어)"를 구분하지 않고 모두 Set에 넣었기 때문이다.
- 즉, 실제 전화번호부에 없는 번호인데도 접두어로 오해해서 false를 반환하는 문제가 발생한다.
- 예를 들어 ["123", "124"]라고 가정해 보자.
- 위 코드는 "1", "12", "123"을 Set에 넣고, "124"의 "1"을 비교하는 순간 바로 false를 반환한다.
- 결국 실제로는 접두어가 없는데도, "123" 때문에 만들어진 가짜 접두어 "1"을 보고 접두어가 있다고 착각하게 된다.

✅ 정답

```java
import java.util.*;

class Solution {
    public boolean solution(String[] phone_book) {
        Set<String> set = new HashSet<>();

        // 1. 모든 "완전한" 전화번호만 먼저 Set에 넣음
        for (String p : phone_book) {
            set.add(p);
        }

        // 2. 다시 번호들을 꺼내서, 각 번호의 조각(substring)이 Set에 있는지 확인
        for (String p : phone_book) {
            for (int i = 1; i < p.length(); i++) {
                if (set.contains(p.substring(0, i))) {
                    return false; // 조각이 Set에 있다는 건, 그 조각이 실제 전화번호라는 뜻!
                }
            }
        }

        return true;
    }
}
```

## 정렬을 이용한 정답

- 전화번호 배열을 오름차순으로 정렬하면, 비슷한 숫자로 시작하는 번호들이 서로 이웃하게 된다.
- 예를 들어 ["119", "976", "119552"]를 정렬하면 ["119", "119552", "976"]이 된다.
- 정렬된 상태에서는 **바로 뒤에 오는 번호가 현재 번호로 시작하는지**만 확인하면 된다.

```java
import java.util.*;

class Solution {
    public boolean solution(String[] phone_book) {
        // 1. 전화번호부를 사전순으로 정렬
        Arrays.sort(phone_book);

        // 2. 인접한 두 번호만 비교 (현재 번호가 다음 번호의 접두어인지 확인)
        for (int i = 0; i < phone_book.length - 1; i++) {
            if (phone_book[i + 1].startsWith(phone_book[i])) {
                return false;
            }
        }

        return true;
    }
}
```

---

## 포인트

- 배열 정렬: **Arrays.sort(arr)**
- 객체 배열 내림차순 정렬: **Arrays.sort(arr, Collections.reverseOrder())**
- 접두어 체크: **str1.startsWith(str2)**
