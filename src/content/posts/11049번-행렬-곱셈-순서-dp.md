<https://www.acmicpc.net/problem/11049>

크기가 N×M인 행렬 A와 M×K인 B를 곱할 때 필요한 곱셈 연산의 수는 총 N×M×K번이다. 행렬 N개를 곱하는데 필요한 곱셈 연산의 수는 행렬을 곱하는 순서에 따라 달라지게 된다.

예를 들어, A의 크기가 5×3이고, B의 크기가 3×2, C의 크기가 2×6인 경우에 행렬의 곱 ABC를 구하는 경우를 생각해보자.

- AB를 먼저 곱하고 C를 곱하는 경우 (AB)C에 필요한 곱셈 연산의 수는 5×3×2 + 5×2×6 = 30 + 60 = 90번이다.
- BC를 먼저 곱하고 A를 곱하는 경우 A(BC)에 필요한 곱셈 연산의 수는 3×2×6 + 5×3×6 = 36 + 90 = 126번이다.

같은 곱셈이지만, 곱셈을 하는 순서에 따라서 곱셈 연산의 수가 달라진다.

행렬 N개의 크기가 주어졌을 때, 모든 행렬을 곱하는데 필요한 곱셈 연산 횟수의 최솟값을 구하는 프로그램을 작성하시오. 입력으로 주어진 행렬의 순서를 바꾸면 안 된다.

```java
3
5 3
3 2
2 6
```

첫째 줄에 행렬의 개수 N(1 ≤ N ≤ 500)이 주어진다.

둘째 줄부터 N개 줄에는 행렬의 크기 r과 c가 주어진다. (1 ≤ r, c ≤ 500)

항상 순서대로 곱셈을 할 수 있는 크기만 입력으로 주어진다.

```java
90
```

첫째 줄에 입력으로 주어진 행렬을 곱하는데 필요한 곱셈 연산의 최솟값을 출력한다. 정답은 2^31-1 보다 작거나 같은 자연수이다. 또한, 최악의 순서로 연산해도 연산 횟수가 2^31-1보다 작거나 같다.

---

## 아이디어

- 각 행렬의 크기를 **N×2 크기의 matrix[][]** 배열로 표현
  - 예: 5×3 크기의 0번째 행렬 → matrix[0][0] = 5, matrix[0][1] = 3
- dp[i][j] = i번째 행렬부터 j번째 행렬까지 곱할 때 필요한 최소 연산 수
- 이때, 괄호의 위치를 i ~ j 사이의 **중간 지점 k**를 기준으로 나눈다고 생각하자.
  - 즉, (Ai × ... × Ak) × (Ak+1 × ... × Aj)
    - Ai ~ Ak 곱한 결과는 matrix[i][0] × matrix[k][1] 크기의 행렬
    - Ak+1 ~ Aj 곱한 결과는 matrix[k+1][0] × matrix[j][1] 크기의 행렬
- **dp[i][j] = (Ai ~ Ak 곱하는 데 드는 최소 연산 수) + (Ak+1 ~ Aj 곱하는 데 드는 최소 연산 수) + (두 행렬을 곱하는 연산 수)**
  - Ai ~ Ak 곱하는 데 드는 최소 연산 수 → **dp[i][k]**
  - Ak+1 ~ Aj 곱하는 데 드는 최소 연산 수 → **dp[k+1][j]**
  - 두 행렬을 곱하는 연산 수 → **matrix[i][0] \* matrix[k][1] \* matrix[j][1]**
- 작은 구간부터 시작해서 점점 큰 구간까지 dp[i][j]를 채우고, 최종적으로 dp[0][N-1] 출력

---

## 시간 복잡도

- 3중 반복문: **O(N³)**
- N ≤ 500이므로, 최악의 경우 125 \* 10^6 → 가능

---

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int[][] matrix = new int[N][2];

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            matrix[i][0] = Integer.parseInt(st.nextToken());
            matrix[i][1] = Integer.parseInt(st.nextToken());
        }

        // dp[i][j] = i번째 행렬부터 j번째 행렬까지 곱할 때 필요한 최소 연산 횟수
        int[][] dp = new int[N][N];

        for (int len = 1; len < N; len++) {
            for (int i = 0; i < N - len; i++) {
                int j = i + len;
                dp[i][j] = Integer.MAX_VALUE;

                for (int k = i; k < j; k++) {
                    dp[i][j] = Math.min(dp[i][j], dp[i][k] + dp[k + 1][j]
                            + matrix[i][0] * matrix[k][1] * matrix[j][1]);
                }
            }
        }

        System.out.println(dp[0][N - 1]);
    }
}
```
