<https://www.acmicpc.net/problem/1463>

정수 X에 사용할 수 있는 연산은 다음과 같이 세 가지 이다.

1. X가 3으로 나누어 떨어지면, 3으로 나눈다.
2. X가 2로 나누어 떨어지면, 2로 나눈다.
3. 1을 뺀다.

정수 N이 주어졌을 때, 위와 같은 연산 세 개를 적절히 사용해서 1을 만들려고 한다. 연산을 사용하는 횟수의 최솟값을 출력하시오.

```java
10
```

첫째 줄에 1보다 크거나 같고, 106보다 작거나 같은 정수 N이 주어진다.

```java
3
```

첫째 줄에 연산을 하는 횟수의 최솟값을 출력한다.

---

## 1. 아이디어 (Bottom-Up DP)

- **dp[i] → 숫자 i를 1로 만들기 위한 최소 연산 횟수**
- **점화식을 세우기 위해 N = 10**인 경우를 생각해보자.
  - **1을 빼는 경우:** dp[10] = dp[9] + 1
  - **2로 나누는 경우:** dp[10] = dp[5] + 1
  - **3으로 나누는 경우:** 불가능 (10은 3으로 나누어 떨어지지 않음)
  - 결론: **dp[10] = Math.min(dp[9] + 1, dp[5] + 1)**
- 즉, 숫자 i에 대해 다음과 같다.
- 기본적으로 1을 빼는 연산을 수행하면 → **dp[i] = dp[i - 1] + 1**
- i가 2로 나누어 떨어진다면 → **dp[i] = Math.min(dp[i], dp[i / 2] + 1)**
- i가 3으로 나누어 떨어진다면 → **dp[i] = Math.min(dp[i], dp[i / 3] + 1)**

---

## 2. 시간 복잡도

- dp[i]를 1부터 N까지 채우므로 **O(N)**

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int[] dp = new int[N + 1];

        for (int i = 2; i <= N; i++) {
            dp[i] = dp[i - 1] + 1; // 1을 빼고 하는 연산

            if (i % 2 == 0) {
                dp[i] = Math.min(dp[i], dp[i / 2] + 1);
                // 1을 빼고 하는 연산과, 2를 나누고 하는 연산 중 적게 걸리는걸로
            }

            if (i % 3 == 0) {
                dp[i] = Math.min(dp[i], dp[i / 3] + 1);
                // 1을 빼고 하는 연산과, 3을 나누고 하는 연산 중 적게 걸리는걸로
            }
        }

        System.out.println(dp[N]);
    }
}
```
