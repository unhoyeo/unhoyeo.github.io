<https://www.acmicpc.net/problem/14003>

수열 A가 주어졌을 때, 가장 긴 증가하는 부분 수열을 구하는 프로그램을 작성하시오.

예를 들어, A = {10, 20, 10, 30, 20, 50} 인 경우에 가장 긴 증가하는 부분 수열은 A = {**10**, **20**, 10, **30**, 20, **50**} 이고, 길이는 4이다.

```java
6
10 20 10 30 20 50
```

첫째 줄에 수열 A의 크기 N (1 ≤ N ≤ 1,000,000)이 주어진다.

둘째 줄에는 수열 A를 이루고 있는 Ai가 주어진다. (-1,000,000,000 ≤ Ai ≤ 1,000,000,000)

```java
4
10 20 30 50
```

첫째 줄에 수열 A의 가장 긴 증가하는 부분 수열의 길이를 출력한다.

둘째 줄에는 정답이 될 수 있는 가장 긴 증가하는 부분 수열을 출력한다.

---

## 아이디어

- LIS 문제는 **DP를 이용한 O(N^2)** 방식과 **이분 탐색을 이용한 O(N log N)** 방식으로 풀 수 있다.
- 이 문제는 N ≤ 1,000,000이므로, DP 방식으로 풀면 시간초과된다.
- 따라서 이분 탐색 방식으로 풀되, **LIS 길이**뿐만 아니라 **LIS 수열**도 구해야 하므로 **역추적 과정**이 필요하다.
- **index[i]** = 각 A[i]가 LIS의 몇 번째 인덱스에 해당하는지를 기록한 값
- 뒤에서부터 **index[i] == 현재 위치**인 A[i]를 찾아 실제 LIS 배열에 채워 넣는다.

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int[] A = new int[N];

        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            A[i] = Integer.parseInt(st.nextToken());
        }

        List<Integer> dp = new ArrayList<>(); // 현재까지 만들어진 LIS의 각 길이별 최소 마지막 값을 저장
        int[] index = new int[N];

        for (int i = 0; i < N; i++) {
            int idx = Collections.binarySearch(dp, A[i]);
            if (idx < 0) idx = -idx - 1;

            if (idx == dp.size()) dp.add(A[i]);
            else dp.set(idx, A[i]);

            index[i] = idx; // A[i]가 LIS에서 위치하는 인덱스
        }

        int len = dp.size(); // LIS 길이
        System.out.println(len);

        int[] LIS = new int[len]; // 실제 LIS
        int cur = len - 1;

        // LIS의 뒤에서부터 해당 자리에 위치하는 A[i]를 찾음
        for (int i = N - 1; i >= 0; i--) {
            if (index[i] == cur) {
                LIS[cur] = A[i];
                cur--;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i : LIS) {
            sb.append(i).append(' ');
        }

        System.out.println(sb.toString().trim());
    }
}
```

> 이 방식은 **"하나의 가능한 LIS"**를 역추적하는 방식으로, **사전순 최소는 아닐 수 있다.**
