<https://www.acmicpc.net/problem/10026>

적록색약은 빨간색과 초록색의 차이를 거의 느끼지 못한다. 따라서, 적록색약인 사람이 보는 그림은 아닌 사람이 보는 그림과는 좀 다를 수 있다.

크기가 N×N인 그리드의 각 칸에 R(빨강), G(초록), B(파랑) 중 하나를 색칠한 그림이 있다. 그림은 몇 개의 구역으로 나뉘어져 있는데, 구역은 같은 색으로 이루어져 있다. 또, 같은 색상이 상하좌우로 인접해 있는 경우에 두 글자는 같은 구역에 속한다. (색상의 차이를 거의 느끼지 못하는 경우도 같은 색상이라 한다)

예를 들어, 그림이 아래와 같은 경우에

```java
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```

적록색약이 아닌 사람이 봤을 때 구역의 수는 총 4개이다. (빨강 2, 파랑 1, 초록 1) 하지만, 적록색약인 사람은 구역을 3개 볼 수 있다. (빨강-초록 2, 파랑 1)

그림이 입력으로 주어졌을 때, 적록색약인 사람이 봤을 때와 아닌 사람이 봤을 때 구역의 수를 구하는 프로그램을 작성하시오.

```java
5
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```

첫째 줄에 N이 주어진다. (1 ≤ N ≤ 100)

둘째 줄부터 N개 줄에는 그림이 주어진다.

```java
4 3
```

적록색약이 아닌 사람이 봤을 때의 구역의 개수와 적록색약인 사람이 봤을 때의 구역의 수를 공백으로 구분해 출력한다.

---

## 1. 아이디어

- **입력값을 2개의 2차원 배열에 저장**
  - **grid** → 일반적인 사람이 보는 그리드
  - **colorBlindGrid** → 적록색약이 보는 그리드 (R과 G를 동일한 색으로 취급)
- **DFS 또는 BFS로 구역 탐색**
  - 방문 여부를 확인하기 위해 **visited** 배열 사용
  - 네 방향(상, 하, 좌, 우)으로 이동하면서 **같은 색상이라면 방문**

## 2. 시간복잡도

- DFS 탐색의 시간 복잡도: **O(N × N)**
- N 최대값이 **100이므로 최대 10,000번 연산** → 충분히 빠르게 동작

```java
import java.io.*;

public class Main {
    static int N;
    static char[][] grid, colorBlindGrid;
    static boolean[][] visited;
    static int[] dr = {0, 1, 0, -1};
    static int[] dc = {1, 0, -1, 0};

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        N = Integer.parseInt(br.readLine());

        grid = new char[N][N];
        colorBlindGrid = new char[N][N];

        // 입력 받으면서 일반 그리드 & 적록색약 그리드 생성
        for (int i = 0; i < N; i++) {
            char[] line = br.readLine().toCharArray();
            for (int j = 0; j < N; j++) {
                grid[i][j] = line[j];
                // 적록색약 처리 (G를 R과 동일하게 취급)
                colorBlindGrid[i][j] = (line[j] == 'G') ? 'R' : line[j];
            }
        }

        // 일반인의 구역 개수 구하기
        visited = new boolean[N][N];
        int normalCount = 0;
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < N; j++) {
                if (!visited[i][j]) {
                    dfs(i, j, grid[i][j], grid);
                    normalCount++;
                }
            }
        }

        // 적록색약의 구역 개수 구하기
        visited = new boolean[N][N];
        int colorBlindCount = 0;
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < N; j++) {
                if (!visited[i][j]) {
                    dfs(i, j, colorBlindGrid[i][j], colorBlindGrid);
                    colorBlindCount++;
                }
            }
        }

        System.out.println(normalCount + " " + colorBlindCount);
    }

    static void dfs(int r, int c, char color, char[][] map) {
        visited[r][c] = true;

        for (int i = 0; i < 4; i++) {
            int nr = r + dr[i];
            int nc = c + dc[i];

            if (nr < 0 || nc < 0 || nr >= N || nc >= N) continue;
            if (!visited[nr][nc] && map[nr][nc] == color) {
                dfs(nr, nc, color, map);
            }
        }
    }
}
```
