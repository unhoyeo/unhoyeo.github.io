<https://www.acmicpc.net/problem/1715>

정렬된 두 묶음의 숫자 카드가 있다고 하자. 각 묶음의 카드의 수를 A, B라 하면 보통 두 묶음을 합쳐서 하나로 만드는 데에는 A+B 번의 비교를 해야 한다. 이를테면, 20장의 숫자 카드 묶음과 30장의 숫자 카드 묶음을 합치려면 50번의 비교가 필요하다.

매우 많은 숫자 카드 묶음이 책상 위에 놓여 있다. 이들을 두 묶음씩 골라 서로 합쳐나간다면, 고르는 순서에 따라서 비교 횟수가 매우 달라진다. 예를 들어 10장, 20장, 40장의 묶음이 있다면 10장과 20장을 합친 뒤, 합친 30장 묶음과 40장을 합친다면 (10 + 20) + (30 + 40) = 100번의 비교가 필요하다. 그러나 10장과 40장을 합친 뒤, 합친 50장 묶음과 20장을 합친다면 (10 + 40) + (50 + 20) = 120 번의 비교가 필요하므로 덜 효율적인 방법이다.

N개의 숫자 카드 묶음의 각각의 크기가 주어질 때, 최소한 몇 번의 비교가 필요한지를 구하는 프로그램을 작성하시오.

```java
3
10
20
40
```

첫째 줄에 N이 주어진다. (1 ≤ N ≤ 100,000) 이어서 N개의 줄에 걸쳐 숫자 카드 묶음의 각각의 크기가 주어진다. 숫자 카드 묶음의 크기는 1,000보다 작거나 같은 양의 정수이다.

```java
100
```

첫째 줄에 최소 비교 횟수를 출력한다.

## 틀린 아이디어

- 당연히 크기가 작은 카드 묶음부터 합치는 것이 비교 횟수가 가장 적을 것이다.
- 정렬 후 다음과 같은 점화식으로 결과를 구한다.
  - dp[0] = arr[0] + arr[1]
  - dp[1] = dp[0] + arr[2]
  - dp[2] = dp[1] + arr[3]
  - ...
  - **dp[i] = dp[i-1] + arr[i+1]**
- dp[0]부터 dp[N-2]까지 다 더하면 최종 결과가 나올 것이다.

## 틀린 코드

```java
import java.io.*;
import java.util.*;

class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());
        int[] arr = new int[N];

        for (int i = 0; i < N; i++) {
            arr[i] = Integer.parseInt(br.readLine());
        }

        Arrays.sort(arr);

        int[] dp = new int[N - 1];
        dp[0] = arr[0] + arr[1];
        int result = dp[0];

        for (int i = 1; i < N - 1; i++) {
            dp[i] = dp[i - 1] + arr[i + 1];
            result += dp[i];
        }

        System.out.println(result);
    }
}
```

- 이렇게 쉽게 풀릴 문제가 아니었다.
- 예를 들어, [7, 8, 9, 10]이 있다고 가정하자.
- 기존 로직은 7+8+15+9+26+10=**75**다.
- 하지만, **7과 8을 더한 15는 나머지 9와 10보다 큰 값이다.**
- 따라서 **7과 8을 더하고(15), 9와 10을 더하고(19), 15와 19를 더하면(34)** 7+8+9+10+15+19=68이 나와서 더 작은 값이 된다.
- 우리가 원하는 것은 **작은 값부터 더하는 것이다!**

## 올바른 풀이

- <strong>우선순위 큐(최소 힙)</strong>를 사용하여 항상 <strong>가장 작은 두 개의 카드 묶음을 먼저 합친다.</strong>
- 그리고 **합친 결과를 다시 힙에 넣는다.**
- 매번 **가장 작은 두 개를 합치는 것**이 최적해가 된다!

```java
import java.io.*;
import java.util.*;

class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PriorityQueue<Integer> pq = new PriorityQueue<>();

        int N = Integer.parseInt(br.readLine());
        for (int i = 0; i < N; i++) {
            pq.add(Integer.parseInt(br.readLine()));
        }

        int result = 0;

        while (pq.size() >= 2) { // 최소 두 개 이상 있을 때까지 반복
            int sum = pq.poll() + pq.poll(); // 가장 작은 묶음과 두 번째로 작은 묶음 꺼내서 합치기
            result += sum;
            pq.add(sum); // 합친 묶음을 다시 힙에 추가
        }

        System.out.println(result);
    }
}
```

## 시간 복잡도

- N개의 숫자를 힙에 넣고, N-1번 꺼내어 합치므로, **힙 연산(log N)이 N번 반복 → O(N log N)**

## 2025. 04. 26 복습

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine()); // 숫자 카드 묶음 개수

        PriorityQueue<Integer> pq = new PriorityQueue<>();

        for (int i = 0; i < N; i++) {
            pq.add(Integer.parseInt(br.readLine()));
        }

        int compareCount = 0;

        while (!pq.isEmpty()) {
            int first = pq.poll(); // 가장 작은 묶음
            if (!pq.isEmpty()) {
                int sum = first + pq.poll(); // 가장 작은 묶음과 두 번째로 작은 묶음 합치기
                compareCount += sum;
                pq.add(sum); // 합친 묶음을 다시 힙에 넣기
            }
        }

        System.out.println(compareCount);
    }
}
```
