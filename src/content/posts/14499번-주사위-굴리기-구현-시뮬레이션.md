<https://www.acmicpc.net/problem/14499>

크기가 N×M인 지도가 존재한다. 지도의 오른쪽은 동쪽, 위쪽은 북쪽이다. 이 지도의 위에 **주사위가 하나** 놓여져 있으며, 주사위의 전개도는 아래와 같다. **지도의 좌표는 (r, c)로 나타내며, r는 북쪽으로부터 떨어진 칸의 개수, c는 서쪽으로부터 떨어진 칸의 개수**이다.

```
  2
4 1 3
  5
  6
```

주사위는 지도 위에 **윗 면이 1이고, 동쪽을 바라보는 방향이 3인 상태로 놓여져 있으며**, **놓여져 있는 곳의 좌표는 (x, y)** 이다. **가장 처음에 주사위에는 모든 면에 0이 적혀져 있다.**

지도의 각 칸에는 정수가 하나씩 쓰여져 있다. 주사위를 굴렸을 때, **이동한 칸에 쓰여 있는 수가 0이면, 주사위의 바닥면에 쓰여 있는 수가 칸에 복사된다. 0이 아닌 경우**에는 **칸에 쓰여 있는 수가 주사위의 바닥면으로 복사**되며, **칸에 쓰여 있는 수는 0이 된다.**

**주사위를 놓은 곳의 좌표**와 **이동시키는 명령**이 주어졌을 때, 주사위가 **이동했을 때 마다 상단에 쓰여 있는 값**을 구하는 프로그램을 작성하시오.

**주사위는 지도의 바깥으로 이동시킬 수 없다.** 만약 바깥으로 이동시키려고 하는 경우에는 **해당 명령을 무시**해야 하며, 출력도 하면 안 된다.

```java
4 2 0 0 8
0 2
3 4
5 6
7 8
4 4 4 1 3 3 3 2
```

첫째 줄에 **지도의 세로 크기 N, 가로 크기 M** (1 ≤ N, M ≤ 20), **주사위를 놓은 곳의 좌표 x, y**(0 ≤ x ≤ N-1, 0 ≤ y ≤ M-1), 그리고 **명령의 개수 K** (1 ≤ K ≤ 1,000)가 주어진다.

둘째 줄부터 N개의 줄에 지도에 쓰여 있는 수가 **북쪽부터 남쪽으로, 각 줄은 서쪽부터 동쪽 순서대로** 주어진다. **주사위를 놓은 칸에 쓰여 있는 수는 항상 0**이다. 지도의 각 칸에 쓰여 있는 수는 10 미만의 자연수 또는 0이다.

**마지막 줄에는 이동하는 명령**이 순서대로 주어진다. **동쪽은 1, 서쪽은 2, 북쪽은 3, 남쪽은 4**로 주어진다.

```
0
0
3
0
0
8
6
3
```

이동할 때마다 **주사위의 윗 면에 쓰여 있는 수**를 출력한다. 만약 **바깥으로 이동시키려고 하는 경우에는 해당 명령을 무시해야 하며, 출력도 하면 안 된다.**

## 아이디어

- 주사위를 굴렸을 때, 이동한 칸에 쓰여 있는 수가
  - **0인 경우** → 주사위의 바닥면에 쓰여 있는 수가 **칸에 복사**된다.
  - **0이 아닌 경우** → 칸에 쓰여 있는 수가 주사위의 **바닥면으로 복사**되며, 칸에 쓰여 있는 수는 0이 된다.
- 주사위 이동 명령: **동쪽 1, 서쪽 2, 북쪽 3, 남쪽 4**
- 주사위를 **동-서** 방향으로 굴리면 **남-북 방향의 숫자는 변하지 않는다.**
- 반대로 주사위를 **남-북** 방향으로 굴리면 **동-서 방향의 숫자는 변하지 않는다.**

```java
  2        2
4 1 3    6 4 1  // 동-서 방향으로 주사위를 굴릴 때
  5        5
  6        3

  6
4 2 3  // 남-북 방향으로 주사위를 굴릴 때
  1
  5
```

- 동서남북으로 주사위를 굴리기 전에 굴린 위치가 맵을 벗어나는지 체크
- 벗어나지 않는다면 굴린 후, 윗면 출력

## 자바 코드

```java
import java.io.*;
import java.util.*;

class Main {
    static int N, M, r, c, K;
    static int[] dice = new int[7];
    static int[][] map;
    static StringBuilder result = new StringBuilder();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        M = Integer.parseInt(st.nextToken());
        r = Integer.parseInt(st.nextToken());
        c = Integer.parseInt(st.nextToken());
        K = Integer.parseInt(st.nextToken());
        map = new int[N][M];

        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                map[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < K; i++) {
            boolean isRolled = false;
            int cmd = Integer.parseInt(st.nextToken());
            if (cmd == 1) isRolled = rollDiceEast();
            if (cmd == 2) isRolled = rollDiceWest();
            if (cmd == 3) isRolled = rollDiceNorth();
            if (cmd == 4) isRolled = rollDiceSouth();

            if (isRolled) {
                if (map[r][c] == 0) {
                    map[r][c] = dice[6]; // 바닥면
                } else {
                    dice[6] = map[r][c];
                    map[r][c] = 0;
                }
                result.append(dice[1]).append('\n'); // 윗면 출력
            }
        }

        System.out.println(result);
    }

    static boolean rollDiceEast() {
        if (c + 1 >= M) return false;
        c++;
        int temp = dice[1];
        dice[1] = dice[4];
        dice[4] = dice[6];
        dice[6] = dice[3];
        dice[3] = temp;
        return true;
    }

    static boolean rollDiceWest() {
        if (c - 1 < 0) return false;
        c--;
        int temp = dice[1];
        dice[1] = dice[3];
        dice[3] = dice[6];
        dice[6] = dice[4];
        dice[4] = temp;
        return true;
    }

    static boolean rollDiceNorth() {
        if (r - 1 < 0) return false;
        r--;
        int temp = dice[1];
        dice[1] = dice[5];
        dice[5] = dice[6];
        dice[6] = dice[2];
        dice[2] = temp;
        return true;
    }

    static boolean rollDiceSouth() {
        if (r + 1 >= N) return false;
        r++;
        int temp = dice[1];
        dice[1] = dice[2];
        dice[2] = dice[6];
        dice[6] = dice[5];
        dice[5] = temp;
        return true;
    }

}
```

## 실수한 부분

- 코드를 짜면서 원하는 결과가 안 나오길래 시간을 꽤나 허비해버렸다.
- 알고보니 주사위를 굴리는 과정에서 temp 값을 활용하여 순차적으로 값을 swap해주는데, 그 swap을 하는 순서가 잘못 되었다.

```java
    static boolean rollDiceNorth() {
        if (r - 1 < 0) return false;
        r--;
        int temp = dice[1];
        dice[1] = dice[5];
        dice[2] = temp;
        dice[6] = dice[2];
        dice[5] = dice[6];
        return true;
    }
```

- 다음 코드에서 이상한 점을 찾아보자.
- temp에 1번을 넣고, 1번에 5번을 넣고, **2번**에 **temp**를 넣고, 6번에 **2번**을 넣고... **잠깐!**
- **2번에 temp를 넣었는데 이 2번을 다시 6번에 넣었다.**
- 이렇게 swap 연산을 할 때는 **이미 넣은 값은 그 다음 연산에 나오면 안 된다.**
- **또한 temp 값은 맨 마지막에 넣어줘야 한다.**
- 즉, 다음과 같이 swap 연산을 해줘야 의도한 대로 작동한다.

```java
    static boolean rollDiceNorth() {
        if (r - 1 < 0) return false;
        r--;
        int temp = dice[1];
        dice[1] = dice[5]; // temp가 나오면 안 된다.
        dice[5] = dice[6]; // 1, temp가 나오면 안 된다.
        dice[6] = dice[2]; // 1, 5, temp가 나오면 안 된다.
        dice[2] = temp; // temp는 맨 마지막에 넣어야 한다.
        return true;
    }
```
