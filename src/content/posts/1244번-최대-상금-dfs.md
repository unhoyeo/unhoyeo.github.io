퀴즈 대회에 참가해서 우승을 하게 되면 보너스 상금을 획득할 수 있는 기회를 부여받는다. 우승자는 주어진 숫자판들 중에 두 개를 선택에서 정해진 횟수만큼 서로의 자리를 위치를 교환할 수 있다.

예를 들어, 5개의 숫자판 3, 2, 8, 8, 8이 주어지고 교환 횟수는 2회라고 하자. 처음에는 첫번째 숫자판의 3과 네 번째 숫자판의 8을 교환해서 8, 2, 8, 3, 8이 되었다. 다음으로, 두 번째 숫자판 2와 마지막에 있는 8을 교환해서 8, 8, 8, 3, 2이 되었다.

정해진 횟수만큼 교환이 끝나면 숫자판의 위치에 부여된 가중치에 의해 상금이 계산된다. 숫자판의 오른쪽 끝에서부터 1원이고 왼쪽으로 한자리씩 갈수록 10의 배수만큼 커진다. 위의 예에서 최종적으로 숫자판이 8, 8, 8, 3, 2의 순서가 되면 88832원의 보너스 상금을 획득한다.

여기서 주의할 것은 반드시 횟수만큼 교환이 이루어져야 하고 동일한 위치의 교환이 중복되어도 된다. 예를 들어 94의 경우 1회의 교환 횟수가 주어졌을 때 반드시 1회 교환을 수행하므로 결과값은 49가 된다. 94의 경우 2회 교환하게 되면 원래의 94가 된다.
정해진 횟수만큼 숫자판을 교환했을 때 받을 수 있는 가장 큰 금액을 계산해보자.

```java
3
123 1
2737 1
32888 2
```

가장 첫 줄은 전체 테스트 케이스의 수이다. 최대 10개의 테스트 케이스가 표준 입력을 통하여 주어진다. 각 테스트 케이스에는 숫자판의 정보와 교환 횟수가 주어진다. 숫자판의 정보는 정수형 숫자로 주어지고 최대 자릿수는 6자리이며, 최대 교환 횟수는 10번이다.

```java
#1 321
#2 7732
#3 88832
```

각 테스트 케이스마다 첫 줄에는 "#C"를 출력해야 하는데 C는 케이스 번호이다. 같은 줄에 빈 칸을 하나 사이에 두고 교환 후 받을 수 있는 가장 큰 금액을 출력한다.퀴즈 대회에 참가해서 우승을 하게 되면 보너스 상금을 획득할 수 있는 기회를 부여받는다.

---

? **아이디어**

- 숫자판을 최대 K번까지 두 숫자를 교환할 수 있다.
- 목표는 교환을 정확히 K번 수행하여 만들 수 있는 최대 숫자를 만드는 것이다.
- **DFS(백트래킹)** 방식으로 탐색 → 각 단계에서 **모든 가능한 두 자리 교환을 시도**하면서 깊이를 1씩 늘려간다.
- 상태가 중복되는 것을 방지하기 위해 **(현재 숫자 문자열, 교환 횟수)를 Set으로 방문 체크한다.**
- DFS 종료 조건: **depth == K** → 이 경우 현재 숫자와 최대값을 비교하여 갱신

> 입력된 숫자에 중복된 숫자가 없고, K > 자릿수인 경우처럼, 같은 자리를 반복해서 바꾸는 게 최선인 상황도 있다.
> 이 경우에도 K번 교환을 정확히 맞춰야 하므로, DFS로 무조건 K단계까지 내려가야 한다.

⏱️ **시간 복잡도**

- DFS는 각 단계에서 가능한 모든 자리쌍을 선택해서 진행한다.
- 가능한 자리쌍은 nC2 = n(n - 1)/2
- 자릿수 n이 최대 6일 때: 6C2 = 15
- 교환 횟수 K가 최대 10이므로 깊이 최대 10까지 재귀 호출
- 따라서 최악의 경우, O(15^K) = O(15^10)

? **자바 코드**

```java
import java.io.*;
import java.util.*;

class Solution {
    static int K;
    static String max;
    static Set<String> visited;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine());

        StringBuilder sb = new StringBuilder();
        for (int tc = 1; tc <= T; tc++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            char[] arr = st.nextToken().toCharArray();
            K = Integer.parseInt(st.nextToken());

            max = "0";
            visited = new HashSet<>();

            dfs(arr, 0); // dfs 수행 후 max 갱신됨
            sb.append('#').append(tc).append(' ').append(max).append('\n');
        }

        System.out.println(sb);
    }

    static void dfs(char[] arr, int depth) {
        if (depth == K) {
            String result = new String(arr); // char[] → String
            if (max.compareTo(result) < 0) max = result; // max < result
            return;
        }

        String state = new String(arr) + "," + depth; // 상태 = 현재 숫자 문자열 + 교환 횟수
        if (visited.contains(state)) return; // 상태가 중복되는 경우
        visited.add(state);

        // 모든 가능한 두 자리 교환 시도
        int len = arr.length;
        for (int i = 0; i < len - 1; i++) {
            for (int j = i + 1; j < len; j++) {
                swap(arr, i, j); // 수행 후 arr 배열 변경됨
                dfs(arr, depth + 1); // 변경된 arr 배열에 대해서 재귀 수행
                swap(arr, i, j); // arr 배열 다시 원복 (백트래킹)
            }
        }
    }

    /**
     * 배열은 참조 타입(reference type)이기 때문에, 배열을 인자로 넘기면 참조(주소값)가 복사된다.
     * 즉, dfs 메서드 내에서 swap(arr, i, j)을 호출하여 arr 배열을 수정하면,
     * 이 변경은 원본 배열(arr)에도 그대로 반영된다.
     */
    static void swap(char[] arr, int i, int j) {
        char tmp = arr[i];
        arr[i] = arr[j];
        arr[j] = tmp;
    }
}
```
