<https://www.acmicpc.net/problem/4195>

민혁이는 소셜 네트워크 사이트에서 친구를 만드는 것을 좋아하는 친구이다. 우표를 모으는 취미가 있듯이, 민혁이는 소셜 네트워크 사이트에서 친구를 모으는 것이 취미이다.

어떤 사이트의 친구 관계가 생긴 순서대로 주어졌을 때, 두 사람의 친구 네트워크에 몇 명이 있는지 구하는 프로그램을 작성하시오.

친구 네트워크란 친구 관계만으로 이동할 수 있는 사이를 말한다.

```java
2
3
Fred Barney
Barney Betty
Betty Wilma
3
Fred Barney
Betty Wilma
Barney Betty
```

첫째 줄에 테스트 케이스의 개수가 주어진다. 각 테스트 케이스의 첫째 줄에는 친구 관계의 수 F가 주어지며, 이 값은 100,000을 넘지 않는다. 다음 F개의 줄에는 친구 관계가 생긴 순서대로 주어진다. 친구 관계는 두 사용자의 아이디로 이루어져 있으며, 알파벳 대문자 또는 소문자로만 이루어진 길이 20 이하의 문자열이다.

```java
2
3
4
2
2
4
```

친구 관계가 생길 때마다, 두 사람의 친구 네트워크에 몇 명이 있는지 구하는 프로그램을 작성하시오.

---

## 아이디어

- 각 사람마다 고유한 **int형 id**를 부여한다. (이유는 마지막에)
- **유니온 파인드** 자료구조를 이용한다.
  - 부모 노드 배열 → **parent[]**
  - 집합 크기 배열 → **size[]**
- 친구 관계가 생길 때마다 두 사람을 **같은 집합으로 묶고, 해당 집합의 크기를 출력**한다.

---

## 시간 복잡도

- 각 연산은 거의 **상수 시간**에 수행된다. (O(α(N)), 아커만 함수의 역함수)
- 전체 시간 복잡도는 **O(F × α(N))**

---

## 자바 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    static int[] parent;
    static int[] size;
    static Map<String, Integer> nameToId;
    static int id;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine());

        StringBuilder sb = new StringBuilder();
        while (T-- > 0) {
            int F = Integer.parseInt(br.readLine());

            parent = new int[F * 2]; // 최대 사람 수는 2F명
            size = new int[F * 2];

            nameToId = new HashMap<>();
            id = 0;

            for (int i = 0; i < F * 2; i++) {
                parent[i] = i;
                size[i] = 1;
            }

            for (int i = 0; i < F; i++) {
                StringTokenizer st = new StringTokenizer(br.readLine());
                String a = st.nextToken();
                String b = st.nextToken();

                int x = getId(a);
                int y = getId(b);

                sb.append(union(x, y)).append('\n');
            }
        }

        System.out.print(sb);
    }

    static int getId(String name) {
        return nameToId.computeIfAbsent(name, n -> id++);
    }

    static int find(int x) {
        if (x != parent[x]) parent[x] = find(parent[x]);
        return parent[x];
    }

    static int union(int x, int y) {
        int px = find(x);
        int py = find(y);

        if (px != py) {
            parent[px] = py;
            size[py] += size[px];
        }

        return size[find(x)];
    }
}
```

## Map.computeIfAbsent(key, mappingFunction)

- **Map에 해당 키가 없으면 값을 계산해서 넣고 반환, 있으면 기존 값을 반환**
- containsKey + put + get 구조를 한 줄로 처리
- 값 계산은 오직 키가 없을 때만 실행됨 → 불변성 보장
- 단일 호출로 처리되므로 빠르고 명확
- Java 8부터 추가된 메서드

## 메서드 시그니처

```java
V computeIfAbsent(K key, Function<? super K, ? extends V> mappingFunction);
```

- key: 찾고자 하는 키
- mappingFunction: 키가 없을 때 호출되어 값을 생성할 함수
- 반환값: 기존 값이 있으면 **기존 값**, 없으면 **새로 계산한 값**

## ︎ 주의 사항

- mappingFunction이 null을 반환하면 **NullPointerException** 발생
- 이미 키가 있으면 mappingFunction은 호출되지 않음
- 동시성 환경에서는 **ConcurrentHashMap**에서만 thread-safe하게 사용 가능

## 사용자 이름(String)을 정수 ID(int)로 변환하는 이유?

→ **효율적인 유니온 파인드** 자료구조를 사용하기 위해서!

## 1. 배열 기반 유니온 파인드 사용 가능

- 유니온 파인드에서 핵심은 **parent[], size[] 같은 배열**이다.
- Java에서 배열은 int 인덱스를 기준으로 접근한다.
- 즉, String을 그대로 인덱스로 쓸 수 없기 때문에, 고유한 int형 id로 매핑이 필요하다.

## 2. 빠른 연산 속도

- find(), union() 연산은 **매우 자주 호출**되므로, 속도가 중요하다.
- Map&lt;String, String>을 사용하면 **해시 연산**과 **문자열 비교**가 반복되어 입력이 많거나 문자열이 길수록 성능이 저하된다.
- 반면, int[] 배열은 단순한 **메모리 접근**만 수행하므로 O(1) 수준으로 빠르다.
- 배열은 메모리 상에 연속적으로 배치되므로 **캐시 적중률이 높고**, 이는 실제 실행 시간에 큰 영향을 미친다.

## 3. 문자열보다 비교가 간편

- String.equals()는 내부적으로 **문자의 길이만큼 비교**가 발생한다.
- 반면, int == int는 **한 번의 비교**로 끝난다.

---

## Map&lt;String, String> 사용 시 성능 저하 원인

- 자바에서 HashMap은 get(key)이나 put(key, value) 등의 연산이 단순히 한 번의 메모리 접근으로 끝나지 않는다.
- 내부적으로는 다음 과정을 거친다.
  1. **해시 코드 계산**
     - <strong>key.hashCode()</strong>를 호출하여 <strong>문자열의 해시 값</strong>을 계산한다.
     - 이 과정은 문자열의 **모든 문자**를 기반으로 계산된다. → **O(문자열 길이)** 시간 복잡도
     - 이 연산은 단순한 숫자 해시보다 훨씬 느리고, 문자열 길이가 길수록 해시 연산에 드는 시간이 커진다.
  2. **해시 충돌 처리**
     - **해시값이 같은 여러 키가 같은 해시 버킷에 저장**될 수 있기 때문에, 이 경우 **해시 충돌**이 발생한다.
     - 자바 8 이전에는 이 버킷이 <strong>LinkedList</strong>로, 이후에는 일정 조건 이상이면 <strong>Tree (Red-Black Tree)</strong>로 구성된다.
     - 충돌이 발생한 경우, 해당 버킷에 저장된 여러 키들과 **하나씩 equals()로 비교해야 한다**.
  3. **equals()를 통한 키 비교**
     - 충돌 처리 단계에서 equals()로 문자열을 직접 비교한다.
     - 이 비교는 문자열의 길이에 비례하는 비용이 들며, 특히 문자열이 길거나 비교 횟수가 많을 경우 매우 비효율적이다.
     - 특히 서로 다른 문자열이지만 해시 충돌이 있는 경우, **모든 문자를 끝까지 비교**해야 한다.
- 위 과정을 보면 문자열 기반 Map 연산은 O(1)이 아닌 <strong>평균 O(1), 최악 O(N)</strong>의 시간 복잡도를 가진다.
- 특히 입력 데이터가 많고 문자열이 긴 경우, 내부적으로 해시 충돌과 equals() 비교가 많아지므로 **연산 속도가 급격히 느려진다**.
- 반면, 정수 기반 배열 접근은 **단순한 인덱싱 연산**으로 매우 빠르며, 캐시 효율까지 고려하면 압도적으로 효율적이다.
- 따라서 성능이 중요한 문제에서는 Map&lt;String, Integer>로 **문자열을 정수로 매핑**한 후, int[] 기반 자료구조로 로직을 수행하는 것이 훨씬 바람직하다.
- 즉, 이 문제에서는 String을 int로 변환해야 유니온 파인드를 효율적으로 적용할 수 있고, **시간 제한을 맞출 수 있다.**

## 시간 초과한 풀이

```java
import java.io.*;
import java.util.*;

public class Main {
    static Map<String, String> map;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine());

        StringBuilder sb = new StringBuilder();
        while (T-- > 0) {
            map = new HashMap<>();
            int F = Integer.parseInt(br.readLine());

            for (int i = 0; i < F; i++) {
                StringTokenizer st = new StringTokenizer(br.readLine());
                String a = st.nextToken();
                String b = st.nextToken();

                if (!map.containsKey(a)) map.put(a, a);
                if (!map.containsKey(b)) map.put(b, b);

                union(a, b);

                // 두 사람의 친구 네트워크에 몇 명이 있는지 출력
                sb.append(countFriends(a)).append('\n');
            }
        }

        System.out.println(sb.toString().trim());
    }

    static String find(String x) {
        while (!x.equals(map.get(x))) {
            x = map.get(map.get(x));
        }
        return x;
    }

    static void union(String a, String b) {
        String pa = find(a);
        String pb = find(b);
        if (!pa.equals(pb)) map.replace(pa, pb);
    }

    static int countFriends(String a) {
        int count = 0;
        String pa = find(a);
        for (String key : map.keySet()) {
            if (find(key).equals(pa)) count++;
        }
        return count;
    }
}
```
