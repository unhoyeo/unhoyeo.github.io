## 개념

- 각 원소마다 모든 값을 순회해야 할 때(O(N^2)) "<strong>연속하다"</strong>는 특성을 이용해서 처리하는 방법 → <strong>시간복잡도: O(N)</strong>
- **두개의 포인터**(커서)가 움직이면서 계산
- 처음부터 생각하기는 어려우니 쉬운 방법부터 생각해보자. (완전 탐색 시도 → 시간 초과.. → 연속한가? → 투포인터!)

---

## 연습 문제 - 백준 2559번

```java
10 2
3 -2 -4 -9 0 3 7 13 8 -3
```

첫째 줄에는 두 개의 정수 N과 K가 한 개의 공백을 사이에 두고 순서대로 주어진다. 첫 번째 정수 N은 온도를 측정한 전체 날짜의 수이다. N은 2 이상 100,000 이하이다. 두 번째 정수 K는 합을 구하기 위한 연속적인 날짜의 수이다. K는 1과 N 사이의 정수이다. 둘째 줄에는 매일 측정한 온도를 나타내는 N개의 정수가 빈칸을 사이에 두고 주어진다. 이 수들은 모두 -100 이상 100 이하이다.

```
21
```

첫째 줄에는 입력되는 온도의 수열에서 연속적인 K일의 온도의 합이 최대가 되는 값을 출력한다.

![투 포인터](/images/tistory/27/img.png)

## 1. 처음 아이디어

- for문으로 각 숫자의 위치에서 이후 K개의 수를 더한다.
- 최대값을 갱신한다.

## 2. 처음 시간복잡도

- for문 → N
- 각 위치에서 K개의 수를 더함 → K
- 따라서 O(N \* K = 100000 ^ 2 = 10 ^ 10 > 2억) → 안됨!

---

## 1. 아이디어

- **투포인터** 이용
- for문으로 처음에 K개의 값을 더한 후 저장
- 다음 인덱스의 값을 더하고, 첫 인덱스의 값을 뺀다.
- 최댓값을 갱신한다.

## 2. 시간복잡도

- for문, 각 단계마다 2개의 연산(더하고 빼주기) → O(2N) → **O(N = 10^5 = 1e5) → 가능**

## 3. 자료구조

- 정수 배열 → 들어오는 값들은 모두 -100 이상 100 이하이므로 int 가능 → **int[]**
- K개 정수 합 → 값의 최댓값은 100, K의 최댓값은 10^5 → 100 \* 10^5 = 10^7 = 1e7 → **int 가능! (최대 약 20억)**

```java
import java.io.*;
import java.util.*;

class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int K = Integer.parseInt(st.nextToken());

        int[] arr = new int[N];

        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        int sum = 0;
        for (int i = 0; i < K; i++) {
            sum += arr[i];
        }

        int max = sum;
        for (int i = K; i < N; i++) {
            sum += arr[i];
            sum -= arr[i - K];
            max = Math.max(max, sum);
        }

        System.out.println(max);
    }
}
```

## 팁

- 처음부터 투포인터를 떠올리기는 힘들다.
- 따라서 처음엔 **쉬운 알고리즘**으로 먼저 생각해보고, **시간복잡도**를 계산해본다.
- 시간복잡도를 초과한다면, "**연속하다**"는 특성을 활용할 수 있는지 확인한다.
- for문 안에서 계산하는 값의 최댓값을 확인해서 int의 최댓값을 넘는지 확인한다.
- **일반적인 시간복잡도: O(N)**
- **정렬 후 시간복잡도: O(N logN)**

## 투포인터 종류

- 두 포인터 모두 왼쪽에서 시작
- 각각 왼쪽, 오른쪽에서 시작
- 다른 배열에서 포인터 시작
