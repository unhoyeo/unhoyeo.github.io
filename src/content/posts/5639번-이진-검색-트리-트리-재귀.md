<https://www.acmicpc.net/problem/5639>

이진 검색 트리는 다음과 같은 세 가지 조건을 만족하는 이진 트리이다.

- 노드의 왼쪽 서브트리에 있는 모든 노드의 키는 노드의 키보다 작다.
- 노드의 오른쪽 서브트리에 있는 모든 노드의 키는 노드의 키보다 크다.
- 왼쪽, 오른쪽 서브트리도 이진 검색 트리이다.

![5639번 이진 검색 트리 - 트리, 재귀](/images/tistory/158/img.png)

전위 순회 (루트-왼쪽-오른쪽)은 루트를 방문하고, 왼쪽 서브트리, 오른쪽 서브 트리를 순서대로 방문하면서 노드의 키를 출력한다. 후위 순회 (왼쪽-오른쪽-루트)는 왼쪽 서브트리, 오른쪽 서브트리, 루트 노드 순서대로 키를 출력한다. 예를 들어, 위의 이진 검색 트리의 전위 순회 결과는 50 30 24 5 28 45 98 52 60 이고, 후위 순회 결과는 5 28 24 45 30 60 52 98 50 이다.

이진 검색 트리를 전위 순회한 결과가 주어졌을 때, 이 트리를 후위 순회한 결과를 구하는 프로그램을 작성하시오.

```java
50
30
24
5
28
45
98
52
60
```

트리를 전위 순회한 결과가 주어진다. 노드에 들어있는 키의 값은 10^6보다 작은 양의 정수이다. 모든 값은 한 줄에 하나씩 주어지며, 노드의 수는 10,000개 이하이다. 같은 키를 가지는 노드는 없다.

```java
5
28
24
45
30
60
52
98
50
```

입력으로 주어진 이진 검색 트리를 후위 순회한 결과를 한 줄에 하나씩 출력한다.

---

**아이디어**

- **이진 검색 트리(BST)의 전위 순회 순서의 특성**을 활용해, 트리를 직접 구성하지 않고도 풀 수 있다.
  - 전위 순회 순서: [루트 → 왼쪽 → 오른쪽]
  - 후위 순회 순서: [왼쪽 → 오른쪽 → 루트]
- 전위 순회를 보면 **가장 처음 값은 루트**이고, 이후 값들 중 루트보다 작은 값들은 **왼쪽 서브트리**, 큰 값들은 **오른쪽 서브트리**다.
  - 이 규칙은 **왼쪽 서브트리, 오른쪽 서브트리 각각에서도 적용**된다!
- 이를 바탕으로, 전위 순회 배열에서 <strong>현재 루트보다 처음으로 큰 값이 나오는 지점(오른쪽 서브트리의 시작점)</strong>을 찾아서,
  - 왼쪽 서브트리는 **루트 뒤부터 그 지점 전까지**
  - 오른쪽 서브트리는 **그 지점부터 끝까지**
- 이 과정을 **재귀적으로 반복**하면 된다.

---

**예시**

```java
전위 순회: [50, 30, 24, 5, 28, 45, 98, 52, 60]
```

- **루트**: 50
- **왼쪽 서브트리**: [30, 24, 5, 28, 45] (50보다 작은 값)
  - **루트**: 30
  - **왼쪽 서브트리**: [24, 5, 28] (30보다 작은 값)
    - **루트**: 24
    - **왼쪽 서브트리**: [5] (24보다 작은 값)
    - **오른쪽 서브트리**: [28] (24보다 큰 값)
  - **오른쪽 서브트리**: [45] (30보다 큰 값)
- **오른쪽 서브트리**: [98, 52, 60] (50보다 큰 값)
  - **루트**: 98
  - **왼쪽 서브트리**: [52, 60] (98보다 작은 값)
    - **루트**: 52
    - **왼쪽 서브트리**: [] (52보다 작은 값)
    - **오른쪽 서브트리**: [60] (52보다 큰 값)
  - **오른쪽 서브트리**: [] (98보다 큰 값)

→ 이와 같은 방식으로 **왼쪽, 오른쪽을 계속 분할해 후위 순회로 출력**

---

⏱️ **시간 복잡도**

- 일반적으로 재귀 호출은 O(N)이지만, 최악의 경우 (편향 트리)에서는 O(N²)
- 그러나 전위 순회 배열을 잘 나누고 **start, end 인덱스 기반**으로 처리하면 O(N)으로 최적화 가능

---

**Java 코드**

```java
import java.io.*;
import java.util.*;

public class Main {
    static int[] preorder;
    static StringBuilder sb = new StringBuilder();

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // 리스트로 입력 받기
        List<Integer> inputs = new ArrayList<>();
        while (true) {
            String line = br.readLine();
            if (line == null) break;
            inputs.add(Integer.parseInt(line));
        }

        // 리스트를 int[] 배열로 변환
        preorder = new int[inputs.size()];
        for (int i = 0; i < inputs.size(); i++) {
            preorder[i] = inputs.get(i);
        }

        // 후위 순회 재귀 호출
        postorder(0, preorder.length - 1);

        System.out.println(sb);
    }

    // pre: m -> l -> r, post: l -> r -> m
    static void postorder(int inL, int inR) {
        if (inL > inR) return;

        int root = preorder[inL];

        // 오른쪽 서브트리의 시작점 찾기
        int rightStart = inL + 1;
        for (int i = inL + 1; i <= inR; i++) {
            if (preorder[i] > root) {
                rightStart = i;
                break;
            }
        }

        // 1. 왼쪽 서브트리
        postorder(inL + 1, rightStart - 1);

        // 2. 오른쪽 서브트리
        postorder(rightStart, inR);

        // 3. 루트
        sb.append(root).append('\n');
    }
}
```

---

## 입력 시 주의점

- 백준은 입력이 **파일**로 제공된다.
- br.readLine()은 입력 파일의 끝에서 null을 반환하므로, <strong>EOF(End Of File)</strong>까지 잘 읽고 종료된다.
- 하지만 IntelliJ는 표준 입력(System.in)을 **키보드**에서 받는다.
- 키보드 입력은 **EOF 신호**를 주지 않는 이상 **계속 대기**한다.
- 따라서 마지막에 **Cmd + D**를 입력해야 한다.
