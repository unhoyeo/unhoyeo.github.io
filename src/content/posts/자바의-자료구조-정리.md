## ArrayList의 메모리 증가 방식

Java의 ArrayList는 **동적 배열**(Dynamic Array) 기반으로 동작하며, 내부적으로 **기본 배열(Object[] elementData)을 사용**해 데이터를 저장해.

배열 크기가 초과되면 **기존 크기의 1.5배로 증가**하는 방식으로 동작해.

---

## 1️⃣ ArrayList의 내부 구조

Java의 ArrayList는 내부적으로 **배열(Object[] elementData)을 사용**해 데이터를 저장해.

- 처음 생성될 때는 **기본 크기**(default capacity)를 가짐 (보통 10).

- 데이터가 추가되다가 **배열이 꽉 차면 1.5배 크기의 새 배열을 생성**한 후 **기존 데이터를 복사**함.

---

## 2️⃣ ArrayList 크기 증가 과정

```arduino
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();

        for (int i = 1; i <= 20; i++) {
            list.add(i);
            System.out.println("Size: " + list.size() + ", Capacity: " + getCapacity(list));
        }
    }

    // 현재 ArrayList의 용량 확인 (리플렉션 활용)
    private static int getCapacity(ArrayList<?> list) {
        try {
            java.lang.reflect.Field field = ArrayList.class.getDeclaredField("elementData");
            field.setAccessible(true);
            return ((Object[]) field.get(list)).length;
        } catch (Exception e) {
            return -1;
        }
    }
}
```

## 출력 예시

```yaml
Size: 1, Capacity: 10
Size: 10, Capacity: 10
Size: 11, Capacity: 15  // 1.5배 증가
Size: 15, Capacity: 15
Size: 16, Capacity: 22  // 1.5배 증가
Size: 20, Capacity: 22
```

**초기 크기(default capacity)가 10이며, 초과 시 1.5배 증가하는 것을 확인 가능!**

## 3️⃣ ArrayList의 크기 증가 원리

```haxe
private void grow(int minCapacity) {
    int oldCapacity = elementData.length;
    int newCapacity = oldCapacity + (oldCapacity >> 1); // 기존 크기의 1.5배 증가
    if (newCapacity - minCapacity < 0)
        newCapacity = minCapacity;
    if (newCapacity - MAX_ARRAY_SIZE > 0)
        newCapacity = hugeCapacity(minCapacity);
    elementData = Arrays.copyOf(elementData, newCapacity);
}
```

## 크기 증가 과정

1. 기존 크기를 가져옴 (oldCapacity)

2. **1.5배 크기 증가 (newCapacity = oldCapacity + (oldCapacity >> 1))**

- 비트 연산 >> 1은 / 2와 같음 → 즉, oldCapacity \* 1.5

3. Arrays.copyOf()를 사용해 새로운 배열을 생성하고 기존 데이터를 복사함

---

## 4️⃣ 크기 증가 시 성능 문제

- **기존 배열을 새로운 배열로 복사해야 하므로 O(N)의 시간 복잡도가 발생**

- 너무 빈번하게 크기가 변경되면 **메모리 낭비와 성능 저하** 발생 가능

## 해결 방법:

- ArrayList의 크기를 미리 지정 (ArrayList<>(size))

- 예상 데이터 크기를 알고 있다면 미리 충분한 크기의 ArrayList를 생성하는 것이 성능에 유리

```lasso
ArrayList<Integer> list = new ArrayList<>(1000); // 초기 용량을 1000으로 설정
```

➡ **불필요한 크기 증가 연산을 방지하여 성능 향상 가능!** ?

자바에서 사용되는 주요 자료구조는 다음과 같이 분류할 수 있습니다.

---

## 1. 배열 (Array)

- 크기가 고정된 자료구조

- 인덱스를 기반으로 O(1) 시간 복잡도로 요소 접근 가능

- 단점: 크기 변경 불가, 삽입/삭제가 비효율적

## 사용법:

```
int[] arr = new int[5]; // 정수형 배열 선언
arr[0] = 10; // 값 할당
int x = arr[0]; // 값 접근
```

---

## 2. 리스트 (List)

- 동적으로 크기가 조정됨

- 순차적으로 데이터를 저장하는 자료구조

- **종류**:

- ArrayList (배열 기반, 인덱스 접근 O(1), 삽입/삭제 O(N))

- LinkedList (노드 기반, 삽입/삭제 O(1), 인덱스 접근 O(N))

- Vector (동기화 지원, ArrayList와 비슷)

## 사용법:

```
List<Integer> arrayList = new ArrayList<>();
arrayList.add(10); // 추가
arrayList.get(0);  // 접근
arrayList.remove(0); // 삭제
```

---

## 3. 스택 (Stack)

- LIFO(Last In First Out) 구조

- push(), pop(), peek() 연산 제공

- Deque 또는 Stack 클래스 사용 가능 (Deque가 더 추천됨)

## 사용법:

```arduino
Deque<Integer> stack = new ArrayDeque<>();
stack.push(10); // 요소 추가
int top = stack.pop(); // 요소 제거
int peek = stack.peek(); // 맨 위 요소 확인
```

---

## 4. 큐 (Queue)

- FIFO(First In First Out) 구조

- offer(), poll(), peek() 연산 제공

- LinkedList 또는 ArrayDeque 사용

## 사용법:

```arduino
Queue<Integer> queue = new LinkedList<>();
queue.offer(10); // 요소 추가
int front = queue.poll(); // 요소 제거
int peek = queue.peek(); // 맨 앞 요소 확인
```

---

## 5. 우선순위 큐 (PriorityQueue)

- 최소힙 또는 최대힙 기반의 정렬된 큐

- 요소를 정렬된 상태로 유지하며 poll() 시 최소값(기본값) 또는 최대값을 반환

- **Comparator**를 활용하여 정렬 순서 지정 가능

## 사용법:

```
PriorityQueue<Integer> pq = new PriorityQueue<>(); // 최소 힙
pq.offer(5);
pq.offer(1);
pq.offer(10);
int min = pq.poll(); // 1 반환

PriorityQueue<Integer> maxPq = new PriorityQueue<>(Collections.reverseOrder()); // 최대 힙
```

---

## 6. 덱 (Deque - Double Ended Queue)

- 양쪽 끝에서 삽입/삭제 가능

- ArrayDeque 추천 (LinkedList보다 성능 좋음)

## 사용법:

```cpp
Deque<Integer> deque = new ArrayDeque<>();
deque.addFirst(10);
deque.addLast(20);
int first = deque.removeFirst();
int last = deque.removeLast();
```

## 7. 해시맵 (HashMap) & 정렬맵 (TreeMap)

- **HashMap**: O(1) 탐색 속도, 키-값 저장, 순서 없음

- **TreeMap**: O(logN) 탐색 속도, 정렬된 키 유지

- **LinkedHashMap**: 입력 순서 유지

## 사용법:

```arduino
Map<String, Integer> hashMap = new HashMap<>();
hashMap.put("Alice", 25);
int age = hashMap.get("Alice");

TreeMap<String, Integer> treeMap = new TreeMap<>();
```

---

## 8. 해시셋 (HashSet) & 정렬셋 (TreeSet)

- **HashSet**: 중복 없는 집합, 순서 없음, O(1) 탐색

- **TreeSet**: 정렬된 집합, O(logN) 탐색

## 사용법:

```pgsql
Set<Integer> hashSet = new HashSet<>();
hashSet.add(10);
hashSet.add(20);
```

## 9. 트라이 (Trie)

- 문자열 탐색에 최적화된 자료구조

- 접두사 검색, 자동완성 기능 등에 사용

## 사용법 (기본 구현):

```
class TrieNode {
    Map<Character, TrieNode> children = new HashMap<>();
    boolean isEnd;
}
```

## 10. 그래프 (Graph)

- **인접 리스트** (LinkedList 활용)

- **인접 행렬** (2D 배열 활용)

- DFS, BFS, 다익스트라 등에서 활용

## 사용법:

```
List<List<Integer>> graph = new ArrayList<>();
graph.add(Arrays.asList(1, 2)); // 0번 노드의 연결 리스트
```

## 11. 힙 (Heap)

- 우선순위 큐 기반의 자료구조

- PriorityQueue 사용

## 사용법:

```
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
```

## 12. 유니온 파인드 (Disjoint Set)

- 그래프에서 사이클 판별 등에 사용

## 사용법 (기본 구현):

```zephir
class DisjointSet {
    int[] parent;

    DisjointSet(int n) {
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    int find(int x) {
        if (parent[x] == x) return x;
        return parent[x] = find(parent[x]);
    }

    void union(int a, int b) {
        int rootA = find(a);
        int rootB = find(b);
        if (rootA != rootB) parent[rootB] = rootA;
    }
}
```

## 13. 세그먼트 트리 (Segment Tree)

- 구간 합, 최소값/최대값 쿼리에 사용

## 사용법 (기본 구현):

```
class SegmentTree {
    int[] tree;

    SegmentTree(int n) {
        tree = new int[4 * n];
    }
}
```

## 14. 이진 탐색 트리 (Binary Search Tree - BST)

- 키 값이 정렬된 상태로 유지되는 트리

## 사용법:

```
class BST {
```
