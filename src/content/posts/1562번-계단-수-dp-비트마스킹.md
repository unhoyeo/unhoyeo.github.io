<https://www.acmicpc.net/problem/1562>

45656이란 수를 보자.

이 수는 인접한 모든 자리의 차이가 1이다. 이런 수를 계단 수라고 한다.

N이 주어질 때, 길이가 N이면서 0부터 9까지 숫자가 모두 등장하는 계단 수가 총 몇 개 있는지 구하는 프로그램을 작성하시오. 0으로 시작하는 수는 계단수가 아니다.

```java
10
```

첫째 줄에 N이 주어진다. N은 1보다 크거나 같고, 100보다 작거나 같은 자연수이다.

```java
1
```

첫째 줄에 정답을 1,000,000,000으로 나눈 나머지를 출력한다.

---

**아이디어**

- 조건:
  - 인접한 자리의 숫자 차이가 1이어야 함
  - **0 ~ 9가 모두 등장해야 함**
  - 단, 맨 앞이 0이면 안 됨
- 예를 들어,
  - 1 다음은 0 또는 2만 가능
  - 2 다음은 1 또는 3만 가능
  - 이런 식으로 계속 이어짐
  - 즉, <strong>"마지막 숫자"</strong>에 따라 다음 숫자가 정해진다!
  - 다음 숫자는 **(마지막 숫자 - 1)** 또는 **(마지막 숫자 + 1)**
- 0 ~ 9가 모두 등장해야 하므로, 지금까지 어떤 숫자들이 나왔는지를 함께 기록해야 함
  - 비트마스킹을 통해 0 ~ 9 숫자를 각각 비트 한 칸에 대응
- **dp[len][d][mask] = 길이가 len, 마지막 숫자가 d, 지금까지 쓴 숫자 집합이 mask일 때의 경우의 수**
  - 길이가 1일 때는 마지막 숫자가 0인 경우만 제외하고 dp[1][d][1<&lt;d] = 1
- 점화식:
  - **dp[len+1][nd][newMask] += dp[len][d][mask]**
    - nd = d-1 또는 d+1 (0 또는 9일 때의 경계 처리 필요)
    - newMask = mask | (1 << nd)
- 최종 답:
  - 길이가 N이면서, 모든 숫자가 등장한 상태 (마지막 숫자는 뭐든 상관 없음)
  - 즉, dp[N][d][111...111]인 경우를 모두 더한 값

---

## ⏱️ 시간 복잡도

- 길이: N (최대 100)
- 마지막 숫자: 0~9 (10개)
- mask 상태 수: 2^10 = 1024
- 따라서 **O(100 \* 10 \* 1024)** → 가능

---

## Java 코드

```java
import java.io.*;

public class Main {
    static final int MOD = 1_000_000_000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        // dp[len][d][mask]
        // 길이가 len인 계단 수 중, 마지막 숫자가 d, 지금까지 사용한 숫자 집합이 mask일 때 가능한 경우의 수
        int[][][] dp = new int[N + 1][10][1 << 10];
        final int ALL_MASKED = (1 << 10) - 1;

        for (int d = 1; d <= 9; d++) {
            dp[1][d][1 << d] = 1;
        }

        for (int len = 1; len < N; len++) {
            for (int d = 0; d <= 9; d++) {
                for (int mask = 0; mask <= ALL_MASKED; mask++) {
                    int cur = dp[len][d][mask];
                    if (cur == 0) continue; // 경우 없음

                    // 다음 숫자 선택
                    if (d > 0) {
                        int nd = d - 1;
                        int nextMask = mask | (1 << nd);
                        dp[len + 1][nd][nextMask] = (dp[len + 1][nd][nextMask] + cur) % MOD;
                    }
                    if (d < 9) {
                        int nd = d + 1;
                        int nextMask = mask | (1 << nd);
                        dp[len + 1][nd][nextMask] = (dp[len + 1][nd][nextMask] + cur) % MOD;
                    }
                }
            }
        }

        int result = 0;
        for (int d = 0; d <= 9; d++) {
            result = (result + dp[N][d][ALL_MASKED]) % MOD;
        }

        System.out.println(result);
    }
}
```
