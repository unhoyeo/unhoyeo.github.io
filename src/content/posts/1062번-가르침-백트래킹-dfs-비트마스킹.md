<https://www.acmicpc.net/problem/1062>

남극에 사는 김지민 선생님은 학생들이 되도록이면 많은 단어를 읽을 수 있도록 하려고 한다. 그러나 지구온난화로 인해 얼음이 녹아서 곧 학교가 무너지기 때문에, 김지민은 K개의 글자를 가르칠 시간 밖에 없다. 김지민이 가르치고 난 후에는, 학생들은 그 K개의 글자로만 이루어진 단어만을 읽을 수 있다. 김지민은 어떤 K개의 글자를 가르쳐야 학생들이 읽을 수 있는 단어의 개수가 최대가 되는지 고민에 빠졌다.

남극언어의 모든 단어는 "anta"로 시작되고, "tica"로 끝난다. 남극언어에 단어는 N개 밖에 없다고 가정한다. 학생들이 읽을 수 있는 단어의 최댓값을 구하는 프로그램을 작성하시오.

```java
3 6
antarctica
antahellotica
antacartica
```

첫째 줄에 단어의 개수 N과 K가 주어진다. N은 50보다 작거나 같은 자연수이고, K는 26보다 작거나 같은 자연수 또는 0이다. 둘째 줄부터 N개의 줄에 남극 언어의 단어가 주어진다. 단어는 영어 소문자로만 이루어져 있고, 길이가 8보다 크거나 같고, 15보다 작거나 같다. 모든 단어는 중복되지 않는다.

```java
2
```

첫째 줄에 김지민이 K개의 글자를 가르칠 때, 학생들이 읽을 수 있는 단어 개수의 최댓값을 출력한다.

---

## 아이디어

- 모든 단어는 "anta"로 시작하고 "tica"로 끝나므로, **5개 글자(a, n, t, i, c)는 반드시 배워야 한다.**
  - 만약 K가 5보다 작다면 아무 단어도 읽을 수 없다.
  - 또한 K가 26이라면 모든 단어를 읽을 수 있다.
- 즉, 나머지 21개 알파벳 중에서 **K-5개를 선택**하여 최대한 많은 단어를 읽을 수 있도록 하는 것이 이 문제의 목표다.
  - 어떤 알파벳을 배웠는지, 해당 단어를 읽을 수 있는지를 판단해야 한다.
- 우선 어떤 알파벳을 배웠는지는 **selected 비트마스크**로 관리하면 된다.
  - a, c, e를 배웠다면 ...10101로 표현한다.
- 단어를 읽을 수 있는지 여부는 <strong>"단어에 포함된 모든 알파벳을 배웠는가"</strong>로 판단하면 된다.
  - 각 단어를 **비트마스크로 변환**하여 selected와 **& 연산**을 하면, 배운 글자는 1, 배우지 않은 글자는 0이 된다.
  - 즉, **word & selected = word**라면 그 단어는 읽을 수 있는 것이다.
- 예를 들어,
  - "ace"라는 단어가 있고 → word = ...10101
  - a, b, c, d, e를 배웠다면 → selected = ...11111
  - **word & selected** = 10101 & 11111 = 10101 = **word**이므로, 이 단어는 읽을 수 있다.
- 따라서,
  - DFS로 알파벳 조합(Combination)을 만들고,
  - 매 조합마다 읽을 수 있는 단어 개수를 계산하여,
  - 그 최댓값을 구하면 된다.

---

## 시간 복잡도

- 21개 알파벳에서 배울 알파벳 K-5개 선택 → **(21)C(K-5)**
  - **nCr(조합)의 최댓값은 r이 n/2에 가까울수록 커짐** → 최댓값 = 21C10 = 352,716
- 각 조합마다 N개의 단어를 검사하므로, **O(조합수 × N)**
- 단어 검사는 비트마스킹을 사용해서 <strong>O(1)</strong>이므로, 전체 시간복잡도는 <strong>O(조합수 × N)</strong>

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, K;
    static int[] words;
    static char[] necessary = {'a', 'n', 't', 'i', 'c'};
    static int maxCount = 0;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        K = Integer.parseInt(st.nextToken());

        // 필수 알파벳(a, n, t, i, c)을 못 배우는 경우
        if (K < 5) {
            System.out.println(0);
            return;
        }

        // 모든 알파벳을 배우는 경우
        if (K == 26) {
            System.out.println(N);
            return;
        }

        words = new int[N];
        for (int i = 0; i < N; i++) {
            String word = br.readLine();
            for (char ch : word.toCharArray()) {
                words[i] |= (1 << (ch - 'a'));
            }
        }

        int selected = 0;
        for (char ch : necessary) {
            selected |= (1 << (ch - 'a'));
        }

        dfs(0, 0, selected);
        System.out.println(maxCount);
    }

    static void dfs(int depth, int start, int selected) {
        if (depth == K - 5) {
            int count = 0;
            for (int word : words) {
                if ((selected & word) == word) count++;
            }
            maxCount = Math.max(maxCount, count);
            return;
        }
        for (int i = start; i < 26; i++) {
            if ((selected & (1 << i)) != 0) continue;
            dfs(depth + 1, i + 1, selected | (1 << i));
        }
    }
}
```

## 동작 방식 요약

1. 각 단어를 **비트마스크**로 변환
2. 필수 알파벳 a, n, t, i, c는 미리 학습 처리
3. DFS로 나머지 21개 알파벳 중 **K-5개 선택**
4. 매 조합마다 **모든 단어 검사** → 읽을 수 있는 단어 수 최댓값 갱신
