## 개념

- **MST(최소 신장 트리)**: 모든 노드를 잇되 **총 간선 비용이 최소**인 **트리 구조** 생성 → 네트워크 전체를 연결할 때 유리
- **다익스트라(Dijkstra)**: **한 노드에서 다른 모든 노드까지 가는 최소 비용**을 구하는 알고리즘 → 단일 출발 최단 경로

다익스트라는 **가중치가 있는 방향 그래프**에서도 사용 가능하며, **음수 가중치가 없는 경우**에만 올바르게 작동한다.

---

## 문제 파악 포인트

다음과 같은 문장을 보면 다익스트라임을 빠르게 판단해야 한다.

- "한 정점에서 모든 정점으로의 최단 거리"
- "출발 노드 하나가 주어지고 모든 노드까지의 거리 구하기"
- "방향 그래프, 가중치 있음, 음수 없음"

---

## 알고리즘 동작 방식

1. 거리 배열을 모두 **무한대로 초기화** (distance[] = Integer.MAX\_VALUE)
2. **시작 노드의 거리는 0**으로 설정
3. **우선순위 큐**를 사용해 **항상 최소 거리 노드부터 처리**
4. 현재 노드의 인접 노드들에 대해
   - (현재 거리 + 간선 비용)이 저장된 거리보다 작을 경우, **더 짧은 거리로 갱신**
   - 갱신된 노드는 **우선순위 큐에 추가**

이렇게 하면 <strong>"최단 거리로 방문이 확정된 노드만 큐에서 꺼내는 구조"</strong>가 되어 <strong>그리디 방식</strong>으로 최적 경로가 보장된다.

## 다익스트라 흐름 예시

![다익스트라](/images/tistory/32/blob.jpg)

- 거리 배열 초기화: [INF, INF, INF, INF, INF, INF]
- 시작 노드: 1번
  - 시작 노드의 거리는 0 → [INF, **0**, INF, INF, INF, INF]
- 인접 노드: 2(가중치 2), 3(가중치 3)
  - 2번: 1번 거리(0) + 가중치(2) < INF → 2로 갱신
  - 3번: 1번 거리(0) + 가중치(3) < INF → 3으로 갱신
  - 갱신된 거리 배열: [INF, 0, **2, 3**, INF, INF]
  - **갱신된 노드는 큐에 추가: 2, 3**
- 다음 노드 2번
- 인접 노드: 3(가중치 4), 4(가중치 5)
  - 3번: 2번 거리(2) + 가중치(4) > 3 → 패스
  - 4번: 2번 거리(2) + 가중치(5) < INF → 7로 갱신
  - 갱신된 거리 배열: [INF, 0, 2, 3, **7,** INF]
  - 갱신된 4번만 큐에 추가: 3, 4
- 다음 노드 3번
- 인접 노드: 4(가중치 6)
  - 4번: 3번 거리(3) + 가중치(6) > 7 → 패스
- 다음 노드 4번 → 인접 노드 없으므로 패스
- 최종 거리 배열: **[INF, 0, 2, 3, 7, INF]**
  - 도달 불가능한 5번은 여전히 INF

## ⏱️ 시간 복잡도

- 우선순위 큐 기반 다익스트라의 시간 복잡도: **O(E log V)**

---

## 주요 자료구조

- **그래프 저장**: List&lt;List&lt;Edge>> 인접 리스트 방식
- **거리 배열**: int[] distance (1-based 인덱싱)
- **우선순위 큐**: PriorityQueue&lt;Edge> (가중치 기준 정렬)
- **Edge 클래스**: (목적지 노드, 가중치)를 표현하고 Comparable 구현

---

## 핵심 코드

```java
PriorityQueue<Edge> pq = new PriorityQueue<>();
pq.add(new Edge(start, 0)); // 시작 노드
distance[start] = 0; // 시작 노드의 거리는 0

while (!pq.isEmpty()) {
    Edge cur = pq.poll();
    int cn = cur.node;
    int cw = cur.weight;

    // 현재 노드로 가는 가중치가 기존 거리보다 더 크면 패스
    if (cw > distance[cn]) continue;

    // 인접 노드 탐색
    for (Edge e : graph.get(cn)) {
        int nn = e.node;
        int nw = cw + e.weight; // 현재 노드 가중치 + 다음 노드 가중치

        if (nw < distance[nn]) {
            distance[nn] = nw;
            pq.add(new Edge(nn, nw));
        }
    }
}
```

```java
static class Edge implements Comparable<Edge> {
    int node, weight;

    public Edge(int node, int weight) {
        this.node = node;
        this.weight = weight;
    }

    @Override
    public int compareTo(Edge o) {
        return this.weight - o.weight; // 최소 힙
    }
}
```

## 연습 문제: 1753번 최단 경로

<https://www.acmicpc.net/problem/1753>

방향그래프가 주어지면 주어진 시작점에서 다른 모든 정점으로의 최단 경로를 구하는 프로그램을 작성하시오. 단, 모든 간선의 가중치는 10 이하의 자연수이다.

```java
5 6
1
5 1 1
1 2 2
1 3 3
2 3 4
2 4 5
3 4 6
```

첫째 줄에 정점의 개수 V와 간선의 개수 E가 주어진다. (1 ≤ V ≤ 20,000, 1 ≤ E ≤ 300,000) 모든 정점에는 1부터 V까지 번호가 매겨져 있다고 가정한다. 둘째 줄에는 시작 정점의 번호 K(1 ≤ K ≤ V)가 주어진다. 셋째 줄부터 E개의 줄에 걸쳐 각 간선을 나타내는 세 개의 정수 (u, v, w)가 순서대로 주어진다. 이는 u에서 v로 가는 가중치 w인 간선이 존재한다는 뜻이다. u와 v는 서로 다르며 w는 10 이하의 자연수이다. 서로 다른 두 정점 사이에 여러 개의 간선이 존재할 수도 있음에 유의한다.

```java
0
2
3
7
INF
```

첫째 줄부터 V개의 줄에 걸쳐, i번째 줄에 i번 정점으로의 최단 경로의 경로값을 출력한다. 시작점 자신은 0으로 출력하고, 경로가 존재하지 않는 경우에는 INF를 출력하면 된다.

---

## 아이디어

- "주어진 시작점에서 다른 모든 정점으로의 최단 경로"를 구하는 문제이므로 다익스트라 알고리즘 사용
  - 거리 배열 INF로 초기화
  - 시작 노드의 거리는 0으로 설정
  - 현재 노드의 가중치가 현재 노드의 거리보다 크다면 패스
  - 인접 노드 탐색:
    - 현재 노드의 가중치 + 다음 노드의 가중치 < 다음 노드의 거리
    - 위 조건을 만족하는 경우에만 거리 갱신, 큐에 추가

---

## ⏱️ 시간 복잡도

- 다익스트라: **O(E log V)** = 300000 \* log 20000 → 가능

## Java 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    static final int INF = Integer.MAX_VALUE;
    static int[] dist;
    static List<List<Edge>> graph = new ArrayList<>();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int V = Integer.parseInt(st.nextToken());
        int E = Integer.parseInt(st.nextToken());

        dist = new int[V + 1];

        for (int i = 0; i <= V; i++) {
            dist[i] = INF;
            graph.add(new ArrayList<>());
        }

        int start = Integer.parseInt(br.readLine());

        for (int i = 0; i < E; i++) {
            st = new StringTokenizer(br.readLine());
            int from = Integer.parseInt(st.nextToken());
            int to = Integer.parseInt(st.nextToken());
            int weight = Integer.parseInt(st.nextToken());

            graph.get(from).add(new Edge(to, weight));
        }

        dijkstra(start);

        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= V; i++) {
            sb.append(dist[i] == INF ? "INF" : dist[i]).append('\n');
        }

        System.out.println(sb);
    }

    static void dijkstra(int start) {
        PriorityQueue<Edge> pq = new PriorityQueue<>();
        pq.add(new Edge(start, 0));
        dist[start] = 0;

        while (!pq.isEmpty()) {
            Edge cur = pq.poll();
            int cn = cur.node;
            int cw = cur.weight;

            if (cw > dist[cn]) continue;

            for (Edge e : graph.get(cn)) {
                int nn = e.node;
                int nw = cw + e.weight;

                if (nw < dist[nn]) {
                    dist[nn] = nw;
                    pq.add(new Edge(nn, nw));
                }
            }
        }
    }

    static class Edge implements Comparable<Edge> {
        int node, weight;

        public Edge(int node, int weight) {
            this.node = node;
            this.weight = weight;
        }

        @Override
        public int compareTo(Edge o) {
            return this.weight - o.weight;
        }
    }
}
```

## ✅ 결론

- **다익스트라는 외우는 게 빠르다!** (구조가 정형화돼 있음)
- 핵심은 **문제 유형을 빠르게 파악**하는 능력!
- **가중치가 있는 방향 그래프**에서 **"단일 출발 최단 거리"** → 다익스트라
- 음수 가중치가 있으면 다익스트라X → 벨만-포드 사용
