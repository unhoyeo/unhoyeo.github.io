<https://www.acmicpc.net/problem/1309>

어떤 동물원에 가로로 두칸 세로로 N칸인 아래와 같은 우리가 있다.

![1309번 동물원 – DP](/images/tistory/192/img.jpg)

이 동물원에는 사자들이 살고 있는데 사자들을 우리에 가둘 때, 가로로도 세로로도 붙어 있게 배치할 수는 없다. 이 동물원 조련사는 사자들의 배치 문제 때문에 골머리를 앓고 있다.

동물원 조련사의 머리가 아프지 않도록 우리가 2\*N 배열에 사자를 배치하는 경우의 수가 몇 가지인지를 알아내는 프로그램을 작성해 주도록 하자. 사자를 한 마리도 배치하지 않는 경우도 하나의 경우의 수로 친다고 가정한다.

```java
4
```

첫째 줄에 우리의 크기 N(1≤N≤100,000)이 주어진다.

```java
41
```

첫째 줄에 사자를 배치하는 경우의 수를 9901로 나눈 나머지를 출력하여라.

---

## 아이디어

- 사자가 가로/세로로 붙으면 안 되므로, **이전 행의 상태에 따라 배치 가능 여부가 달라진다.**
- dp[i][state] = i번째 행까지 배치했을 때의 경우의 수 (state: 현재 행의 사자 배치 상태)
  - dp[i][0] → 사자를 배치하지 않음
  - dp[i][1] → 왼쪽에만 배치
  - dp[i][2] → 오른쪽에만 배치
- 초기값:
  - dp[1][0~2] = 1 → 초기에는 모든 경우 가능

```java
dp[i][0] = dp[i-1][0] + dp[i-1][1] + dp[i-1][2] // 이전 행이 어떤 상태든 가능
dp[i][1] = dp[i-1][0] + dp[i-1][2] // 이전 행 왼쪽에 사자가 있으면 안 됨 (dp[i-1][1] 제외)
dp[i][2] = dp[i-1][0] + dp[i-1][1] // 이전 행 오른쪽에 사자가 있으면 안 됨 (dp[i-1][2] 제외)
```

- 최종 결과: (dp[N][0] + dp[N][1] + dp[N][2]) % 9901

---

## 시간복잡도

- 각 행마다 상수 시간 연산 → **O(N)**

---

## Java 코드

```java
import java.io.*;

public class Main {
    static final int MOD = 9901;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int[][] dp = new int[N + 1][3];

        dp[1][0] = 1;
        dp[1][1] = 1;
        dp[1][2] = 1;

        for (int i = 2; i <= N; i++) {
            dp[i][0] = (dp[i - 1][0] + dp[i - 1][1] + dp[i - 1][2]) % MOD;
            dp[i][1] = (dp[i - 1][0] + dp[i - 1][2]) % MOD;
            dp[i][2] = (dp[i - 1][0] + dp[i - 1][1]) % MOD;
        }

        int result = (dp[N][0] + dp[N][1] + dp[N][2]) % MOD;
        System.out.println(result);
    }
}
```

## 규칙을 이용한 간단한 풀이

- N=0 → 1
- N=1 → 3
- N=2 → 7 = **3 × 2 + 1**
- N=3 → 17 = **7 × 2 + 3**
- N=4 → 41 = **17 × 2 + 7**
- 따라서, 최종 정답은 **(현재 값 × 2 + 이전 값) % 9901**

```java
import java.io.*;

public class Main {
    static final int MOD = 9901;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        int prev = 1;
        int cur = 3;

        for (int i = 2; i <= N; i++) {
            int temp = (cur * 2 + prev) % MOD;
            prev = cur;
            cur = temp;
        }

        System.out.println(cur);
    }
}
```
